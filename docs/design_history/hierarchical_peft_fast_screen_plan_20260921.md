# 계층형 TSFM PEFT: 최소 직접 비교 설계안

작성일: 2026-09-21
상태: 계획 합의용. 새 학습·사용자 저장소 변경·자동 실행 승인이 아니다.
대상: 부분·전체의 합계 관계를 활용하는 PEFT 후보 하나. 변수 구성 변화/간헐수요/MAG는 이번 범위에 넣지 않는다.

## 1. 최상위 목표와 예상 결과

목표: 같은 실제 계층 데이터와 미래 정답을 사용하고, 예측의 합계도 모두 맞춘 상태에서, 실제 부모·자식 관계를 사용하는 작은 어댑터가 일반 적응 및 단순 정보 결합보다 예측을 개선하는지 판단한다.
소비처: 사용자·지도교수의 후속 방법론 개발 투자 결정. 이번 배치 자체로 신규성·논문 완성을 선언하지 않는다.

예상 지지 결과:
- HIER가 일반적인 정보 결합보다 정확하고, 그 차이가 최종 합계 조정 이후에도 남는다.
- 실제 관계를 섞은 대조보다 낫고, 강한 LoRA+조정 기준선과도 경쟁한다.

기대와 다른 결과:
- 합계만 맞아짐: 기존 조정법의 효과일 수 있으며 새 모듈의 근거가 아니다.
- GLOBAL/선형 보정으로 충분함: 계층형 비선형 모듈의 필요성이 약하다.
- 계층 효과는 있지만 LoRA+조정보다 나쁨: 제한된 정보 활용 신호이며 현재 실용적인 새 방법은 미확보다.
- 효과가 불확실함: 이번 자료·예산에 조건부인 미결론이다. 주제 전체의 불가능성으로 표현하지 않는다.

## 2. 선행 확인과 선택한 설계

[확인] MinT는 모든 수준의 기본 예측을 결합해 합계 제약을 만족시키는 표준적 조정법이다. 적은 표본의 공분산 추정에는 대각행렬 쪽으로 축소하는 MinT-shrink가 사용된다.
[확인] End-to-End Learning of Coherent Probabilistic Forecasts for Hierarchical Time Series(2021/ICML)는 조정을 학습 안에 넣었다.
[확인] End-to-End Probabilistic Framework for Learning with Hard Constraints(2026/ICLR)도 제약을 만족하는 미분 가능한 학습을 다룬다.
따라서 합계를 맞추거나 조정 연산을 미분 가능하게 만드는 것 자체를 새로운 기여라고 주장하지 않는다.

검토한 구현 방향:
A. LoRA에 합계 벌점만 추가: 가까운 선행이 강하고, 정보 공유의 추가 가치를 분리하기 어려워 주 후보로 선택하지 않는다.
B. 동결 TSFM의 계열별 표현을 실제 계층 이웃과 결합하는 작은 출력 잔차 어댑터: 이번 최소 비교로 선택한다.
C. 상위 집계를 교사로 삼아 하위 모듈을 증류: 교사 품질과 추가 정답 신호가 섞이므로 이번에는 하지 않는다.

[미검증] B의 효과와 신규성은 확인되지 않았다. 관계 기반 집계와 잔차 어댑터는 각각 기존 아이디어다. 이번은 고유 조합의 제한된 직접 검증이다.

## 3. 데이터: Labour 하나

공식 datasetsforecast의 Labour 배포판을 사용한다. 월별 호주 노동시장 계열과 집계행렬 S 및 수준별 태그가 함께 제공된다.
공식 loader는 2020-01-01 이후를 제외한다. 이번 개발 비교에서도 그 공개판을 그대로 사용하고, 코로나 기간 전체의 강건성을 검증했다고 하지 않는다.

이 응답에서 확인한 것은 공식 문서와 loader 코드다. 원본 ZIP을 이 환경에서 확보하지 못했으므로 노드 수·실제 전체 기간·현재 다운로드 가능성과 합계 오차는 로컬에서 확인해야 한다.

- 공개 S와 공개 계열 ID를 그대로 사용한다.
- 원본의 모든 계층 수준·모든 하위 계열을 사용한다. 임의로 유리한 네 계열을 뽑지 않는다.
- 루트/부모/자식은 S의 포함관계와 공개 태그로 복원한다. 이름 추측으로 연결하지 않는다.
- 원단위에서 실제 y와 S×bottom의 차이를 검산한다.
- 반올림 오차인지, 실제 비가법 자료인지 구분한다. 의미 있는 불일치를 몰래 재집계해 숨기지 않는다.
- 결측·음수·상수 계열·단위·주기·선택된 배포판을 기록한다.
- 과거의 연구 노출은 확인하되, 검색에서 찾지 못한 것을 미사용 증명으로 쓰지 않는다.
- 사전학습 모델의 이 벤치마크 노출 여부는 미확인이다. 새 독립 데이터라는 표현은 사용하지 않는다.
- 데이터가 안 맞으면 기술/자료 차단으로 기록한다. 모델 성능 실패로 처리하거나 성능이 좋은 자료로 자동 교체하지 않는다.

월합 감독과의 차이: 이번에는 상세·집계 학습 정답을 모두 사용한다. 상세 정답을 숨기고 합계만으로 복원하는 문제가 아니다.

## 4. 시계열 역할 분리

배포판의 공통 월별 길이를 T라 한다. 종료점 기준으로 아래 역할을 미리 고정한다.

- E: 마지막 60개월
- V_SELECT: E 직전 36개월
- V_COV: V_SELECT 직전 48개월
- TRAIN: 그 이전 모든 관측

입력 C=96개월, 예측 H=12개월. 각 역할의 정답 12개월 전체가 그 역할 내부에 있는 모든 월별 원점을 사용한다. 문맥은 원점 이전의 다른 역할 구간을 포함할 수 있다.

TRAIN에 96개월 문맥과 12개월 정답을 만들 수 없는 경우는 이 설정의 자료 부적합으로 기록한다. 검사 결과를 본 뒤 단기간을 보간/복제해 늘리지 않는다.

- TRAIN: 모든 학습·정규화·선형 대조 fitting.
- V_COV: 체크포인트별 예측오차 공분산과 사전 고정 조정법 fitting만.
- V_SELECT: LR/체크포인트/기존 조정법 선택만.
- E: 모든 선택을 고정한 뒤 평가.

분산 조건을 만들기 위해 임의 날짜 수를 요구하지 않는다. 매월 원점을 사용하고, 실질적인 평가 기간과 겹침을 보고한다. E 60개월이면 12개월 horizon의 합법적인 원점은 통상 49개이며, 이를 49개의 독립 실험으로 세지 않는다.

## 5. 기반 모델과 빠르게 만드는 방법

기반 모델: 저장소가 이미 사용하는 pinned Chronos-Bolt-small snapshot을 재사용한다.
LoRA 학습 가중치나 MAG 가중치는 가져오지 않는다.

이번 비교는 두 경로다.
1. F0를 동결하고 새로운 작은 어댑터만 학습.
2. 별도의 표준 LoRA를 F0부터 학습하는 대조.

LoRA 선행을 필수로 정하지 않으며, 2단계 적응의 필요성도 이번 질문이 아니다.

원래 wrapper의 입력512/출력64 하드코딩을 그대로 재사용하지 않는다.
- native 입력96 지원과 parity 확인.
- 직접 출력64 중 앞12개를 고정하여 사용.
- 이번은 점예측 비교다. 분위수들을 더해 결합분포의 합계가 맞는다고 주장하지 않는다.

F0에 대해서 각 원점·각 노드의:
- 원단위 점예측 f_i ∈ R^12 (기존 중앙 출력 채널)
- 마지막 encoder 표현의 패치 평균 z_i ∈ R^512
를 한 번 계산해 저장한다.

어댑터를 decoder 이후의 보정으로 두므로 F0 가중치에 gradient가 필요 없다. 저장된 표현으로 작은 모듈만 학습한다. LoRA 대조만 매번 backbone을 통과해 역전파한다.

※ 이 설계는 출력/표현의 캐시 재사용이 가능한 어댑터 실험이다. 입력 이전에 어댑터를 넣고도 이후 표현을 캐시하는 것은 잘못이며 금지한다.

## 6. 후보와 대조군

모든 방법은 동일한 실제 입력·TRAIN 정답·계층 S에 접근 가능하다. 다른 점은 정보를 결합하는 방식이다.

LORA: F0 attention q/v의 표준 rank8 LoRA. 다른 가중치는 고정. 현재 구성의 파라미터 수는 실제 생성 후 기록한다.
PLAIN: 자기 계열 표현만 사용하는 작은 잔차 어댑터.
GLOBAL: 자기 표현과 다른 모든 노드 표현의 평균을 사용하는 일반 정보 결합 어댑터.
HIER: 자기 표현과 실제 부모/자식 표현의 평균을 사용하는 어댑터. 유일한 연구 후보.
SHUFFLED_HIER: HIER와 같은 구조인데 관계만 사전 고정하여 섞은 대조.

비학습/저비용 기준:
- F0
- 계절 naive (12개월 전 관측)
- AutoETS: TRAIN에서 모형/계수를 정하고, 원점까지 공개된 관측으로 상태만 갱신. future 사용/평가 재선택 금지.
- 같은 HIER 특징을 쓰는 선형 ridge 잔차 대조. 비선형 구조가 필요한지 검사.

SHUFFLED_HIER는 학습 때부터 섞은 관계를 사용한다. 최종 합계 조정에서는 모든 방법이 진짜 S를 사용한다. 잘못된 S를 쓰도록 해 비교군을 일부러 불일치하게 만들지 않는다.

## 7. 작은 어댑터의 명세

s_i = TRAIN에서 계산한 해당 노드의 계절차분 RMS.
상수/계절적으로 정확히 같은 계열의 0분모는 사전 정한 작은 수치 floor로 처리하고 개수를 공개한다. 계열을 성능에 따라 제외하지 않는다.

자기 특징:
e_i = concatenate(z_i, f_i / s_i), 차원524.

관계 특징:
m_i = 연결된 다른 노드 e_k의 단순 평균.
- HIER: 공개 계층의 직접 부모 및 직접 자식. 같은 시각의 과거 표현만 사용.
- GLOBAL: 자신을 제외한 모든 노드.
- SHUFFLED_HIER: 고정된 잘못된 연결.

노드별 특징은 TRAIN 전체 원점으로만 표준화하고 모든 군에 동일 규칙을 적용한다. 원단위 부모와 자식의 예측을 크기 보정 없이 섞지 않는다.

PLAIN:
524 → 16 → 12, GELU, 출력층0 초기화: 8,604 params.

GLOBAL/HIER/SHUFFLED_HIER:
1048 → 8 → 12, GELU, 출력층0 초기화: 각각8,500 params.

u_i = f_i + s_i * adapter(features_i).

- 하나의 어댑터 가중치를 모든 노드에 공유한다.
- 출력층 weight/bias=0, 첫층은 같은 seed 규칙의 무작위 초기화.
- 초기 u=f가 모든 입력에서 같아야 한다.
- HIER/GLOBAL/SHUFFLED의 초기 파라미터와 개수는 정확히 같다.
- PLAIN은104개 더 많다. 완전히 같은 용량이라고 주장하지 않는다.
- HIER는 추가 raw 관측을 새로 얻는 것이 아니라, 공통으로 제공된 계층 계열의 결합 방식을 바꾼다.

관계 섞기:
동일 수준 안에서 seed로 노드 ID를 고정 순열한다. 가능한 경우 degree 그룹도 유지한다. 실제/섞은 연결의 degree 분포와 변경된 edge 비율을 공개한다. 그래프가 같아지는 퇴화 경우에는 해당 대조의 한계를 표시하며 예측 성능으로 순열을 선택하지 않는다.

선형 ridge:
HIER와 동일 특징·동일 잔차 타깃, 작은 정규화 후보 {0.1,1,10}, V_SELECT로 선택. feature scale은 TRAIN만. 이 대조를 별도 새 방법으로 세지 않는다.

## 8. 모든 방법에 강한 합계 조정을 적용

주 비교는 모든 방법 + MinT-shrink.
기본 예측이 u이면 P u를 최종 예측으로 한다.
P = S (S^T W^{-1} S)^{-1} S^T W^{-1}.

W는 각 방법/체크포인트의 V_COV 예측 오차에서 추정한다. E나 V_SELECT 정답으로 fitting하지 않는다.
- 기본 레시피: 합법 V_COV 원점의 한 시점 앞 오차를 사용.
- 작은 표본에서 공분산을 대각 쪽으로 shrink하는 공개 MinT 구현을 사용.
- 그 공통 horizon-covariance 근사와 표본 수를 기록한다.
- 각 모델의 W는 달라도 된다. 같은 알고리즘·잔차 표본·정보권한을 쓰는 것이지, 나빠진 공분산을 모든 모델에 강제로 고정하는 것이 아니다.
- singular/0 variance는 사전 수치 안정화만 적용하고 보정 강도를 E로 선택하지 않는다.

추가 학습 없이 Bottom-Up·WLS-variance도 계산하고, V_SELECT에서 고른 기존 조정법의 우승 결과를 함께 보고한다. HIER가 특정 MinT 설정만 이기고 더 간단한 기준선의 선택된 조정법을 못 넘는 경우를 숨기지 않는다.

필수 검사:
- P S ≈ S, P^2 ≈ P.
- 모든 최종 예측이 S×bottom과 수치 오차 안에서 같다.
- 원단위로 복원한 뒤 조정한다. 노드별 표준화 공간의 단순 합계는 틀린 제약이다.
- 음수 예측을 노드별로 독립 clipping하면 합계가 다시 깨질 수 있다. 이번에는 임의 clipping하지 않고 음수 비율을 기록한다.

수학적 함정:
후보가 단순히 (I-P)u 방향의 수정만 만든다면 P를 다시 적용할 때 그 수정은 사라진다. '합계 불일치만 보정하는 모듈'을 새로운 잔여 이득으로 착각하지 않는다. 실제 예측 변화가 최종 조정 뒤에도 남는지 확인한다.

## 9. 학습과 지표

점예측 목적을 고정한다. F0의 중앙 출력에서 시작하지만 MSE 학습 후 조건부 중앙값이라는 확률 의미를 보장하지 않는다.

공통 TRAIN loss:
각 노드의 squared error를 TRAIN 계절차분 평균제곱으로 나누고, 각 계층 수준 내부에서 평균한 다음 수준들 사이를 동일 가중 평균한다.

주 E metric:
노드별 RMSSE → 수준별 평균 → 수준들 평균.
보조:
- 수준별 RMSSE
- 최하위 수준의 RMSSE
- 수준별 raw MAE
- 합계 불일치 수치
- 학습 파라미터·실제 시간·추론 비용

합계 불일치 0은 방법 효과가 아니라 correctness 검사다.
노드가 많은 하위 수준이 주지표를 자동 지배하지 않게 한다. 동시에 전체 평균을 좋게 만들면서 특정 수준을 크게 악화시킨 결과를 숨기지 않는다.

## 10. 고정 예산

같은 원점에서 모든 계층 노드를 함께 다룬다. 미니배치는 원점 단위로 만든다.
- seeds: 2개, 모든 군에 동일 seed/원점 순서를 짝지음.
- LoRA LR: {1e-4,3e-4}.
- 캐시 어댑터 LR: {3e-4,1e-3}.
- 각 run 최대512 updates, checkpoint 0/128/256/512.
- early-stop로 불리한 군만 덜 돌리지 않는다.
- validation에서 두 seed 평균의 주지표로 공통 LR/step을 선택. seed별 점수도 공개.
- 비교군별로 같은 후보 수를 사용. 같은 LR 숫자가 모든 구조에서 최적이라는 주장은 하지 않는다.

학습량:
LoRA 1군×2LR×2seed =4회 = backbone 역전파2,048 updates.
캐시 어댑터4군×2LR×2seed =16회 = 작은 모듈8,192 updates.
합계20회 / 최대10,240 본학습updates.
실모델 smoke는 필요한 연결만 검사하고 별도 상한10updates를 설정한다.

CPU ridge/ETS/조정법 fitting과 feature cache 비용도 별도 기록한다. 캐시 모듈의 optimizer시간만 보고 전체 방법이 그만큼 빠르다고 하지 않는다.

최대step에서 V가 계속 개선 중이면 최적화 한계를 명시한다. 그 상태를 주제 전체의 반증으로 쓰지 않고 자동 연장도 하지 않는다.

## 11. 확인할 비교와 판정

핵심1: HIER+MinT 대 LoRA+MinT: 강한 PEFT+조정 기준선과 경쟁하는가?
핵심2: HIER+MinT 대 GLOBAL+MinT: 실제 계층 결합이 일반적인 다른 계열 정보보다 필요한가?
설명대조: HIER 대 PLAIN/SHUFFLED/선형 HIER.

결과를 네 종류로 보고한다.
- DEVELOPMENT_SIGNAL: 주 정확도에서 일관된 개선, 단순 대조로 전부 설명되지 않음. 다음 독립 확인에 투자할 후보.
- SIMPLE_CONTROL_SUFFICIENT: 일반 조정·평균 정보·선형 보정으로 충분. 현재 새 모듈 확장 중지.
- MECHANISM_SIGNAL_NOT_COMPETITIVE: 계층 관계의 좁은 효과는 있으나 LoRA/ETS+조정보다 못함. 현재 경쟁력 미확보.
- INCONCLUSIVE: 표본·seed·최적화 불확실성이 큼. 성공도 모든 계층형 PEFT의 실패도 아니다.

1% 같은 임의 효과 문턱을 새 법칙으로 만들지 않는다. 프로젝트 예산은20runs에서 끝낸다. 추가 graph depth/rank/LR/seed/dataset을 자동으로 늘리지 않는다.

E 불확실성:
- 12개월 원점 블록의 paired 재표집 2,000회.
- 모든 노드·horizon·seed를 같은 block으로 함께 옮긴다.
- 월별 horizon의 겹침과 마지막60개월 안의 제한된 연도 수를 공개한다.
- 49개 원점 또는 많은 계층 노드를 독립 사건으로 세지 않는다.
- 구간이0을 포함하면 동등성 또는 성능 실패의 증명으로 바꾸지 않는다.

## 12. 시작 전 실수 방지

1. 공개 계층·단위·주기와 S 및 bottom identity 확인.
2. 실제 y의 합계 정합성과 반올림 확인.
3. 노드 ID 순서를 shuffle해도 재정렬 후 결과가 같음.
4. 미래 정답을 바꿔도 과거 cache·관계·정규화는 불변.
5. 학습된 F0 특징을 각 optimizer step마다 다시 계산하지 않음.
6. LoRA가 없는 어댑터 모델의 trainable은 작은 모듈뿐.
7. 초기 출력층0, 첫 gradient/후속 gradient가 유한하며 실제 업데이트됨.
8. 한 원점의 모든 계층 자료가 같은 시각에 정렬됨.
9. MinT는 raw units, W는 V_COV만.
10. E를 보기 전에 모든 선택·조정법 고정.

합계 구조가 잘못된 경우는 데이터/구현 문제로 중지한다. 기본 F0가 이미 coherent하거나 LoRA가 F0보다 좋지 않다는 이유로 후보 실험을 막지는 않는다.

## 13. 보고서와 다음 단계

최종 보고서 첫 페이지는 다음 네 답으로 구성한다.
1. 합계를 맞춘 강한 기존 방법보다 실제 미래 오차가 줄었는가?
2. 일반적인 다른 계열 정보 결합/단순 선형 보정으로 충분한가?
3. 어떤 수준이 좋아졌고 어떤 수준이 나빠졌는가?
4. 현재 방법을 다음 자료에서 확인할 가치가 있는가?

필수 파일은 PROTOCOL, DATA_RECEIPT, SPLITS, cache manifest, model selections, RAW_SCORES, 비교표, 자원/검산, REPORT면 충분하다. 많은 상태 파일과 동일한 그래프를 만드는 것을 연구 진전으로 세지 않는다.

현재 단계에서 하지 않을 것:
- 확률적 계층 합계까지 해결했다고 주장.
- MinT 또는 기존 end-to-end 제약 학습을 재현한 것을 새로운 기여로 주장.
- 하나의 작은 구현이 안 됐다고 계층형 PEFT 분야 전체를 종료.
- 기존 MAG·간헐·관측 간격 실험 재개.
- 변수 구성 변화 후보를 같은 배치에 추가.
- 두 번째 데이터나 공식 선행 전체 실험을 자동 시작.
