계층형 시계열 PEFT — 빠른 직접 검증 설계안
작성일: 2026-09-21
상태: 계획 검토용. 이 문서 자체는 GPU 학습·저장소 변경·push 승인서가 아니다.
대상: 부분·전체 합계 관계를 활용하는 TSFM의 소형 적응 방법.
이번 범위에 포함하지 않음: MAG 재개, 간헐수요, 센서 지연, 변수집합 전이, 연속학습, 확률 계층 예측.

1. 목표와 기대 결과

목표: 같은 합계 조정을 받은 강한 기준선보다 계층 정보를 이용하는 작은 적응 모듈이 실제 미래 예측을 개선하는지, 한 데이터셋의 고정된 비교로 판정한다.
소비처: 사용자·지도교수의 방법론 주제 후속 투자 판단. 논문 채택 또는 전체 계층 연구의 가능/불가능 판정이 아니다.

핵심 질문:
- 일반 LoRA + MinT보다 더 좋은가?
- 비슷한 크기의 개별 계열 어댑터 + MinT보다 더 좋은가?
- 아무 관련 계열을 섞는 효과가 아니라, 실제 부모 관계를 쓰는 효과가 남는가?

예상 결과(미검증): 실제 부모의 표현을 쓰는 HIER가 LOCAL 및 잘못된 부모 관계 대조보다 좋고, 일반 LoRA + MinT 이상의 정확도 이득이 남는다.
반대 결과: MinT나 일반 어댑터로 충분하거나, 부모를 섞어도 같으면 현재의 작은 계층 모듈은 후속 개발 근거가 부족하다.
합계 일치는 정확도 개선의 증거가 아니다. 합계 조정 후 오차를 주 비교로 쓴다.

2. 선행 확인과 현재 설계의 위치

확인한 선행:
- Optimal Forecast Reconciliation for Hierarchical and Grouped Time Series Through Trace Minimization (2019/JASA): MinT.
- End-to-End Learning of Coherent Probabilistic Forecasts for Hierarchical Time Series (2021/ICML): 계층 전체의 공동 학습 및 학습 내 조정.
- HierarchicalForecast / datasetsforecast 공식 코드: 계층 데이터와 합계 행렬, MinTrace 구현 제공.

따라서 합계 제약, 계층 공동 학습, 조정층 자체는 새 원리가 아니다.
이번 HIER는 동결 TSFM의 표현에 부모 표현을 결합하는 작은 출력 잔차의 가능성 검사다.
이 구체적 구성이 새롭다는 주장은 미확인이다. 양성이어도 정식 방법론의 신규성이 확보된 것은 아니다.

설계 대안:
A. LoRA와 계층 모듈의 전 구간 공동 학습: 가능하지만 구현/디버깅 비용이 커 첫 검사에서 제외.
B. 동결 TSFM 특징을 저장하고 작은 계층 출력 어댑터만 학습: 이번 선택.
C. 실제 합계는 유지하고 부모 특징의 연결만 바꾸는 placebo: 후보가 아니라 설명 대조로 포함.

3. 데이터 — Labour 한 개로 첫 판정

확인: datasetsforecast 공식 Labour 정의는 월별, 계절 길이12이며,
국가/지역/성별/고용분류 계층과 합계 행렬을 제공한다.
공식 코드의 papers_horizon은12, 라이브러리 기본 horizon은8이므로 이번12개월 예측을 기본값이라고 부르지 않는다.
공식 loader는 Labour의 2020년 이전 자료만 사용한다. 이 표준 전처리를 보존하고 명시한다.

제안 설정:
- 과거 C=96개월, 미래 H=12개월.
- 제공된 전체 계층 노드 사용. '처음4개 계열' 임의 선택 금지.
- 월별 관측 그대로 사용. 보간으로 길이를 늘리거나 합성 변화/고장/0수요를 만들지 않는다.
- 상세·집계의 학습 정답을 모두 쓴다. 이전의 월합만 관측한 감독 문제와 다르다.
- 같은 달의 모든 노드는 같은 split에 속한다.

실행 전에 확인해야 하는 것(현재 원자료 다운로드/품질 검증은 미완료):
- 실제 T, 노드·최하위 수, 시각 정렬, 결측·중복, 단위, parent와 level 구조.
- S의 행/열 ID와 관측 배열의 순서 일치, bottom identity 부분, rank.
- 관측 합계 y_all = S y_bottom이 제공 자료에서 어느 오차까지 성립하는지.
- 불일치를 조용히 덮어쓰거나 미래값을 재구성해 가짜 정답을 만들지 않는다.
- 라이선스·원자료 hash, 기존 성능 노출/사전학습 중복 미확인 여부.

자료 미확보나 계약 불성립은 DATA/IMPLEMENTATION 문제다.
이를 새 방법의 성능 실패로 세거나 임의 데이터로 교체하지 않는다.

4. 시간 분할

T개의 공통 월별 시점을 정렬한 뒤 전체 시간축에서 고정:
- TRAIN: 처음60%.
- CALIBRATION: 다음10%.
- VALIDATION: 다음10%.
- TEST: 마지막20%.
실제 정수 경계와 날짜를 모델 실행 전에 기록한다.

TRAIN: 예측할12개월 전체가 TRAIN 안에 있고 과거96개월이 존재하는 모든 월별 원점.
VALIDATION/TEST: 미래12개월 전체가 해당 구간 안에 있는 모든 월별 원점.
CALIBRATION: 고정된 각 모델의 1개월 앞 예측오차를 추정하는 기간.
CAL의 1-step 정답만 covariance에 사용하며, CAL 밖 정답을 가져오지 않는다.
다음 원점에서 이미 관측된 과거값을 문맥으로 쓰는 rolling evaluation은 허용.
TEST에서 가중치/조정행렬 재학습 또는 재선택은 하지 않는다.

특정 phase/날짜를 잘 맞추려고 골라내지 않는다.
역할별 합법 원점과 계절 수를 먼저 보고한다.
원점이 겹치는 것은 허용하지만 독립 표본으로 세지 않는다.
실제 T가 이 설정을 지탱하지 못하면 구조를 몰래 변경하지 않고 계획으로 돌아온다.

5. 모델과 특징

- 현재 로컬에 검증된 amazon/chronos-bolt-small snapshot을 출발점 F0로 사용.
- 기존 Electricity/NESO용 B0, LoRA 가중치, MAG 모듈은 재사용하지 않는다.
- 기존 환경/다운로드/LoRA 부착 코드만 필요한 범위에서 재사용한다.
- 기존 MAG wrapper는512입력을 강제하므로 그대로 가져오지 않는다.
- 원 모델의96개월 입력/12개월 출력 슬라이스와 normalization, mask, encoder 동작을 검사한다.
- 첫 파일럿은 점예측만. F0의0.5 분위수 위치를 초기 점예측으로 사용한다.
- 학습/조정 후 분위수의 합이나 확률적 coherence가 성립한다고 주장하지 않는다.

동결 특징:
각 계열과 예측 원점에서 F0를 고정하여
(a) 유효 관측 패치의 encoder 출력 평균512차원(REG/패딩 제외),
(b) F0의 다음12개월 점예측을 얻는다.
전체524차원 특징을 TRAIN 통계로 정규화한다.
TEST에서 정규화 통계를 다시 추정하지 않는다.
공식 모델 hidden dimension과 API를 실제 snapshot에서 확인한다.

F0 특징과 예측은 입력만으로 한 번 계산해 저장한다.
LOCAL/HIER/SHUFFLE은 이를 공통 재사용하므로 backbone 역전파가 필요 없다.
이 캐시는 CAL/V/TEST의 미래 정답을 포함하지 않는다.

6. 비교군 — 학습4종

LORA:
- F0에서 q/v rank8 LoRA를 새로 학습.
- 전체 계층 노드에 공유된 가중치를 사용.
- 기존 구성대로라면 trainable294,912개, 실제 모듈과 수를 확인.
- 같은 TRAIN 정보와 아래의 점예측 손실을 사용.

LOCAL:
- F0 동결.
- 해당 계열의524차원 특징만 받아524→16→12 잔차를 예측.
- 예측 = F0 점예측 + 해당 계열 TRAIN scale × residual.
- 출력층0 초기화, 처음에는 F0 예측 유지.
- 조건부 계산상 trainable8,604개.

HIER (유일한 후보):
- F0 동결.
- 해당 계열의524차원 특징 + 같은 원점의 실제 직계 부모 특징524차원을 연결.
- 1048→8→12 잔차를 예측.
- 모든 노드에서 같은 어댑터 가중치 공유. 계열ID lookup table 없음.
- 루트의 부모 입력은 고정0과 명시된 root 처리 사용(추가 차원을 쓰면 파라미터 수 재계산).
- 원래 F0 경로 유지, 출력층0 초기화.
- 조건부 계산상 trainable8,500개.
- 부모의 과거와 부모의 현재 예측은 허용, 부모의 미래 실제 정답은 입력 금지.

SHUFFLE (대조):
- HIER와 같은 구조/파라미터/초기값.
- 부모 특징만 같은 계층 깊이의 다른 부모 것으로 사전 고정한 permutation으로 바꾼다.
- 가능한 깊이에서 derangement를 사용. singleton 루트는 그대로 두고 변경 불가 비율을 공개.
- 시간축·타깃·실제 합계 행렬 S는 바꾸지 않는다.
- 이 대조는 '틀린 합계에 맞추기'가 아니라 '정보 연결이 정말 중요했는가'를 본다.
- parent mapping은 정답 오차를 보기 전에1개만 고정한다.

LOCAL과HIER는 정확한 equal-parameter가 아니라 근접 예산(104개 차이)이다.
더 작은 HIER에 추가 이득이 있어도 parent relation의 필요성은 SHUFFLE과 함께 판단한다.
같은 update 수가 같은 연산비용을 뜻하지 않는다.

7. 신경망 새 학습 없이 둘 단순 대조

- SeasonalNaive: 매월 해당 계열의12개월 전 값을 예측. 전체 계층 평가.
- AutoETS: TRAIN만 모델 추정, 이후 상태 업데이트/재학습 정책을 사전에 고정.
  첫 파일럿에서는 선택된 파라미터 고정, 각 원점까지 관측된 값의 상태 필터링만 허용.
- F0 그대로.
- LINEAR_PARENT: F0 예측, 부모 F0 예측, 자신/부모 최근 관측을 사용한
  공유 선형 잔차 + ridge. 같은 계층 정보의 단순 선형 결합 대조.
  변수는 TRAIN scale로 정규화하고 미래 정답을 특징으로 주지 않는다.
  lambda 후보{0.001,1,1000}를 V에서만 선택. CPU fit 비용도 기록.

통계적 모델 추정과 ridge는 신경망16fits와 별도 비용으로 공개한다.

8. 합계 조정 — 모든 방법에 제공

Primary: 각 모델의 MinT-shrink 조정 후 점예측.
- 같은 실제 합계 행렬 S 사용.
- CAL의 1-step residual을 사용해 모델/체크포인트별 covariance를 추정.
- 작은 표본에서 단순 sample covariance 역행렬을 쓰지 않고 공식 shrinkage 구현 사용.
- horizon별 covariance가 비례한다는 표준 근사 아래 공통 MinT 행렬을 적용.
- 최종 체크포인트 선택은 조정 후 VALIDATION 점수로 수행.
- TEST 정답으로 covariance·shrinkage·bias·선택을 맞추지 않는다.

같은 '조정 알고리즘과 CAL 기회'를 주는 것이 원칙이다.
모델별 오차가 다르므로 추정되는 조정행렬은 같을 필요가 없다.
모든 모델에 F0 오차행렬 하나만 강제로 적용해 약한 baseline을 만들지 않는다.

보조: 같은 예측으로 BottomUp과OLS를 함께 보고한다.
민감도 확인용이며 TEST에서 가장 좋아 보이는 조정으로 primary를 바꾸지 않는다.

원래 단위에서 조정한다. 계열별 정규화 공간에서 S를 그대로 곱하지 않는다.
조정 뒤 노드별 음수 clipping으로 합계 일치를 깨뜨리지 않는다.
음수 예측 비율을 보고하고, 비음수 조정은 별도 연구 변경으로 다룬다.

9. 학습 목표와 평가

계열별 TRAIN seasonal scale:
s_i = sqrt(mean((y_i,t - y_i,t-12)^2)).
scale0 계열은 데이터 감사에서 공개하고 공통 수치 처리 정책을 봉인한다.
몰래 제외하거나 TEST 분모를 사용하지 않는다.

학습: 계층 수준별 동일 비중을 주는 scaled MSE.
모든 학습군에서 동일한 원점/계열 가중/정답/표본 순서 사용.
큰 합계 계열이나 수가 많은 bottom 계열 하나가 자동 지배하지 않도록 한다.
합계 조정은 이 첫 설계에서 학습 loss 안에 넣지 않는다(학습내조정은 별도 방법).

Primary:
- 계열별 RMSSE 계산 후, 수준 안의 계열 평균, 수준 사이 동일 비중 평균.
- 원점수는 낮을수록 좋다. F0를1로 정규화한 지표가 아니다.

반드시 함께:
- bottom 수준 RMSSE.
- 각 수준별 RMSSE와 원단위 MAE.
- 1~12개월 horizon별 오차.
- seasonal naive 대비 전체 비교.
- 합계 일치 오차/음수 비율.
- 파라미터/학습시간/추론비용(캐시 생성 포함).

Primary contrasts:
- HIER+MinT vs LORA+MinT.
- HIER+MinT vs LOCAL+MinT.
설명 대조:
- HIER+MinT vs SHUFFLE+MinT.
- HIER+MinT vs LINEAR_PARENT+MinT.

모든 방법이 합계를 맞추므로 coherence0 자체는 HIER의 성과가 아니다.

10. 예산과 순서

선택용 seed 92200, 반복용 seed92201/92202.
LORA LR 후보{0.0001,0.0003}.
LOCAL/HIER/SHUFFLE LR 후보{0.0003,0.001}.
모든 LR는 결과 전 고정. 모듈별LR 차이를 공개한다.
각 방법: 선택seed×2LR + 선택LR×반복2seed =4fits.
4방법×4fits =16개 본학습 경로.
각 경로 최대512updates; checkpoints0,128,256,512.
본학습 상한8192updates; 구조별2회씩 폐기하는 smoke 총8updates.
정상 유효 비교는 모두 완료하되, 데이터/코드 불성립에서 예산을 소진하지 않는다.

선택:
- CAL에서 모델별 MinT 추정.
- V의 조정 후 primary error로 LR 및 체크포인트 선택.
- exact tie는 smallerLR, earlierstep.
- 반복seed의 체크포인트도 같은V규칙 사용.
- TEST는 모든 설정/선택 고정 후 채점.

속도:
- LORA4fits만 TSFM 전체 역전파가 필요하다.
- 나머지12fits는 고정 특징에서 작은 head만 학습하므로 CPU 또는 작은GPU연산으로 가능.
- 새 지식은 계층정보의 추가효과에서 얻고 반복적인 특징 추출은 캐시로 줄인다.
- 기존 MAG512 wrapper를96개월 입력에 억지 padding/복제로 맞추지 않는다.

11. 정확성 검사(본학습 전 핵심만)

- S와nodeID/parentID/levelID 정렬 및 실제 관측 합계.
- TRAIN/CAL/V/TEST 시간 경계, 과거-only 특징, 동일시각 parent.
- 미래 정답만 바꿔도 입력 특징/parent feature가 동일.
- 초기 LOCAL/HIER/SHUFFLE = F0.
- 동결 backbone hash 불변, head 실제 gradient, 체크포인트 복원.
- MinT 원단위 연산, R S ≈ S, R^2 ≈ R, 조정 뒤 합계 일치.
- SHUFFLE에서는 relation feature만 바뀌고 정답 및 실제 S 불변.
- 합계 수준을 독립 새 표본으로 세지 않는다.

12. 불확실성과 판단

같은 월 원점의 모든 수준/노드/horizon을 묶어 paired 평가.
12개월 단위 시간블록 재표집2000회, 두seed는 각각효과와 평균효과를 별도공개.
노드와seed를 독립 날짜로 세지 않는다.
평가 블록 수가 적으면 CI가 불안정하다는 한계를 표시한다.
CI0포함을 '차이없음 증명'이나 자동FAIL로 바꾸지 않는다.
데이터가 표준공개벤치마크이므로 사전학습/이전탐색 독립확증이라고 주장하지 않는다.

계속 검토할 근거:
HIER가 주대조보다 개선되고, LOCAL/SHUFFLE/선형대조로 전부 설명되지 않으며,
bottom 희생만으로 전체평균을 좋게 만든 것이 아닌 경우.

현재 구현 보류/종료 근거:
- 합계 일치만 달라지고 정확도는 개선되지 않음.
- 일반 어댑터나 단순 부모선형보정으로 충분.
- 무관한 부모로도 같은 결과.
- 약한 F0는 넘지만 강한 LORA+MinT/통계기준선을 넘는 정확도 근거 없음.

이 판정은 이 작은 설계에 대한 다음 투자 판단이다.
실패하면 모든 계층형PEFT가 불가능하다고 쓰지 않는다.
양성이면 논문완성이라고 쓰지 않고, 다른 실제 계층/정식선행 대조에 투자할 근거로 남긴다.

숫자로 고정한 중단 범위:
- 후보1개, 데이터1개, 본학습16개, 경로당512updates.
- 추가seed/LR/구조/새데이터 자동0개.
- 결과가 불확실해도 같은 데이터에서 범위를 늘려 성공할 때까지 돌리지 않는다.
- 계층주제의 다음 연구와 변수집합전이 후보는 이 결과를 검토한 뒤 별도 결정.

13. 산출물 최소화

한 결과 보고서에 다음을 담는다:
1. 데이터와계층/분할 표1개.
2. 전체·bottom·각수준 정확도 및 비용 표1개.
3. HIER의 LORA/LOCAL/SHUFFLE/선형대조 대비 효과 표1개.
4. 날짜블록별 paired difference 그림1개(필요시).
5. VERIFIED 사실, 미검증 가설, 기술block, 성능관찰, 다음투자 판단 분리.

백본/원자료/checkpoint/prediction/hash는 재현 manifest에 남긴다.
논문 전체 원고,20종기전그림,새모듈,새topic은 이번범위가 아니다.
