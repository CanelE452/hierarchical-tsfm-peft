# LEVEL vs AdaPTS-style matched learned E/D — CLI 실행 계약
Date: 2026-10-06
Repo: CanelE452/hierarchical-tsfm-peft

[목적]
현재 fixed-PCA LEVEL의 핵심 선택을 직접 검증한다.

LEVEL:
  X -> fixed PCA E -> frozen Chronos-Bolt-small -> fixed D = b(X)
  r = X - D(E(X))
  Yhat = b(X) + last(r) + G(r-last(r))

대조:
  X -> learned E -> frozen Chronos-Bolt-small -> learned D -> Yhat

질문:
"압축 손실을 fixed E/D + residual G로 따로 보완할 이유가 있는가,
 아니면 같은 K에서 E/D 자체를 forecast loss로 학습하면 충분한가?"

이번 회차는 full AdaPTS probabilistic framework 재현이 아니다.
정확한 명칭은 `MATCHED_LEARNED_ED` 또는
`AdaPTS-style matched Linear E/D control`을 사용한다.
보고서에서 단순히 `AdaPTS`라고 쓰거나 `LEVEL beats AdaPTS`라고 주장하지 않는다.

1. 선행 source binding
================================================================================

공식 AdaPTS source를 pin하고 다음을 기록한다.

- ICML 2025 publication metadata
- official repository commit/revision
- LinearAutoEncoder:
    encoder = Linear(input_dim, n_components)
    decoder = Linear(n_components, input_dim)
- supervised adapter path:
    transform_torch -> frozen FM -> inverse_transform_torch
- deterministic prediction loss = MSE
- `coeff_reconstruction` 기본값 = 0.0

이번 primary arm은 reconstruction auxiliary loss 없이 final forecast MSE만 사용한다.

================================================================================
3. Primary arm — MATCHED_LEARNED_ED
================================================================================

구조:

  X [B,512,C]
    -> Encoder: Linear(C,K,bias=False)
    -> Z [B,512,K]
    -> frozen Chronos-Bolt-small; K latent series independently
    -> Zhat [B,48,K]
    -> Decoder: Linear(K,C,bias=False)
    -> Yhat [B,48,C]

초기화:
- E.weight = original LEVEL TRAIN PCA U^T
- D.weight = original LEVEL TRAIN PCA U
- basis bytes/hash literal identity 확인

학습:
- E,D만 trainable
- G 없음
- level persistence 없음
- RAW bypass 없음
- LoRA 없음
- reconstruction auxiliary loss 없음
- backbone weights `requires_grad=False`, `eval()`

중요:
Encoder까지 gradient가 가야 하므로 backbone forward를
`torch.no_grad()` 또는 `inference_mode()`로 감싸면 안 된다.
backbone weights는 frozen이지만 operations의 autograd graph는 유지한다.

예상 trainable parameter sanity:
- Robin: 170
- Peacock: 104
- Jena: 252
실제 enumeration을 source of truth로 기록한다.

4. Step-0 parity — 실패 시 즉시 STOP_DEBUG
================================================================================

학습 전 ED 함수는 기존 fixed PCA COMPRESS b와 같아야 한다.

각 dataset canonical VAL에서:

  MATCHED_LEARNED_ED(step0)
  vs
  existing COMPRESS b

검사:

- origin/channel order
- q=0.5
- max abs / relative error
- 기존 project parity tolerance

실패하면 학습/TEST 금지.

원인 후보:
- basis transpose/sign/order
- decoder orientation
- backbone wrapper
- quantile index
- channel ordering
- preprocessing
- revision/dtype

scientific contract를 바꿔 억지로 맞추지 않는다.

================================================================================
5. 학습 목적과 recipe
================================================================================

Loss:
기존 LEVEL과 동일한 observed-mask channel-macro MSE.

  L = mean_c [ SSE_c / observed_count_c ]

별도 future residual target 금지.
native quantile loss 금지.
TEST selection 금지.

Hyperparameter search는 historical learned E/D v1 범위만 재사용:

  lr ∈ {1e-3, 1e-4}
  seeds = {92601, 92602}
  max_epochs = 120

가능한 한 parent LEVEL recipe literal reuse:
- patience=6
- epoch_origins=512
- effective_batch_origins=4
- AdamW
- weight_decay=0
- clip_grad_norm=1
- ReduceLROnPlateau 기존 설정
- phase-balanced sampling
- same seed/epoch origin schedules

최대 신규 fit:
  3 datasets × 2 LRs × 2 seeds = 12

Run checkpoint:
- full VAL macro MSE 최소
- step0 포함
- exact tie = earliest

Dataset-level LR 선택:
- 각 LR의 두 seed best VAL loss 평균
- TEST 보기 전에 하나 선택
- exact tie는 기존 project tie rule 또는 first-listed LR
- 선택 LR의 두 seed checkpoint만 TEST 사용

prediction ensemble 금지.
최종 learned model score는 두 seed `loss` 평균.

================================================================================
6. OOM 규칙
================================================================================

ED는 frozen backbone weights를 학습하지 않아도
encoder까지 gradient가 지나가므로 LEVEL보다 activation memory가 클 수 있다.

microbatch=4 OOM이면:
  4 -> 2 -> 1
순서로만 감소.

단:
- gradient accumulation으로 effective batch=4 유지
- same sample order
- same optimizer update count
- scheduler semantics 동일

금지:
- K/L/H 감소
- dataset 축소
- AMP/quantization
- 한 arm에만 gradient checkpointing/offload
- TEST 보고 recipe 변경

microbatch1도 불가하면 STOP_RESOURCE.

================================================================================
9. same-session training-path cost probe
================================================================================

과거 LEVEL fit time과 새 ED fit time을 단순 비율로 비교하지 않는다.

각 dataset 동일 고정 batch에서 같은 새 session으로:

A. ORIGINAL_LEVEL training-path
- G trainable
- backbone/E/D frozen
- current LEVEL 방식대로 main path gradient retention 없음
- forward -> same MSE -> backward
- optimizer.step 없음

B. MATCHED_LEARNED_ED
- E/D trainable
- backbone weights frozen
- gradient through backbone
- forward -> same MSE -> backward
- optimizer.step 없음

공통:
- same input/target/mask bytes
- same batch/effective batch
- FP32/TF32 off
- warmup/repeats/blocks 고정
- state hash 전후 동일

기록:
- forward+backward ms/origin
- peak allocated MiB
- peak reserved MiB
- resident allocation after load
- trainable params
- deployed tensor bytes

이 probe는 gradient-path 비용 진단이며 convergence time 대체가 아니다.
실제 fit elapsed/updates/selected epoch/peak train memory도 별도 보존한다.

================================================================================
10. same-session inference cost
================================================================================

각 dataset selected ED 2 seeds와 ORIGINAL_LEVEL 2 seeds를 같은 회차에서 측정.

scope:
standardized CPU input
 -> encode
 -> GPU/Bolt
 -> decode
 -> LEVEL only: level + G
 -> [B,48,C] CPU output

- VAL first 24 chronological origins
- B1 latency
- B4 throughput
- warmup 10
- passes 10
- 3 rotated blocks

기록:
- ms/origin
- origins/s
- peak allocated/reserved
- resident allocated/reserved
- parameter/buffer/tensor bytes
- raw block ranges

작은 timing 차이는 drift/range가 겹치면 안정적 우위라고 쓰지 않는다.

12. 판정 규칙
================================================================================

Case A:
ED가 LEVEL보다 MSE가 낮고 interval excludes 0,
training cost도 유사/낮음
  -> `RESIDUAL_PATH_NOT_JUSTIFIED_BY_MATCHED_ED_CONTROL`

Case B:
ED가 더 정확하지만 TSFM-through backprop 때문에
training peak/time이 크게 높음
  -> `ACCURACY_VS_BACKPROP_COST_TRADEOFF`

Case C:
LEVEL이 MSE 우위 interval excludes 0이고 training cost도 낮음
  -> `FIXED_ED_EXTERNAL_RESIDUAL_SUPPORTED`

Case D:
dataset별 혼재 또는 주요 interval 0 포함
  -> `DATA_DEPENDENT_NO_GENERAL_WINNER`

3개 dataset 결과를 범용성 증명으로 부르지 않는다.

================================================================================
13. 반드시 보고할 반론
================================================================================

- full AdaPTS reproduction이 아니다.
- bias=False라 official LinearAutoEncoder와 완전히 동일하지 않다.
  이는 `train E/D vs fixed E/D+G`를 분리하는 matched structural control이다.
- ED trainable params(약 100~250)와 LEVEL G 17,920 params는 다르다.
  이번 질문은 parameter-matched contest가 아니라 압축 손실 처리 전략 비교다.
- ED의 backbone-through gradient 비용 차이는 불공정 요소가 아니라
  이 비교에서 측정하려는 핵심 tradeoff다.
- TEST는 이미 노출된 후속 control이다.
