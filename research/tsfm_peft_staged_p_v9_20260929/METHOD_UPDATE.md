# Staged P-Space Correction for Frozen LEVEL Residual PEFT — Method Update

This note updates the v9 manuscript text after the sealed accuracy evaluation, analysis run, and the same-dataset Jena cost measurement. The method contract is in [`PLAN.md`](PLAN.md), the prior-art boundary in [`PRIOR_ART.md`](PRIOR_ART.md), and the implementation in [`model_v9.py`](model_v9.py). The accuracy claims come from [`analysis01/role_scores.csv`](analysis01/role_scores.csv), [`analysis01/comparisons.csv`](analysis01/comparisons.csv), [`analysis01/space_scores.csv`](analysis01/space_scores.csv), [`analysis01/q_preservation.csv`](analysis01/q_preservation.csv), and [`analysis01/q_prediction_parity.csv`](analysis01/q_prediction_parity.csv). The cost claims are Jena-only same-session measurements from [`cost_jena_summary.json`](cost_jena_summary.json) and [`report_values.json`](report_values.json). Robin and Jena are exposed development evaluations, not independent confirmation sets, and all scores are mean seed losses rather than seed ensembles.

The v9 update treats the selected LEVEL residual PEFT model as a frozen parent. For an input window \(X\), let \(f^*(X)\) be the already selected trained LEVEL parent for the same dataset and seed. With TRAIN-fitted PCA basis \(U\), define \(P=UU^\top\) and \(Q=I-P\). The staged P correction is \(f^*(X)+\alpha H_P(D(E(X))-D(E(X))_{t=-1})\), where \(D(E(X))=XP\). The matched raw correction is \(f^*(X)+\alpha H_R(X-X_{t=-1})\). Both heads are channel-shared, bias-free 512→32→48 maps with 17,920 trainable parameters, zero-up initialization, and the same optimizer, seeds, and validation alpha grid \(\alpha\in\{0,0.25,0.5,0.75,1\}\). The parent TSFM, encoder, decoder, residual head, buffers, and statistics remain frozen.

The contribution is therefore a constrained staged update procedure rather than a new adapter family from scratch. It keeps the parent coefficient fixed at one, preserves the initial parent function, restricts one branch to the learned PCA reconstruction subspace, and uses a matched raw-input side head to test whether the P restriction adds value beyond adding another small residual head. This should not be written as proof that v8 failed because of pure P/Q gradient collision. V8 changed parent training, Q updates, head optimization, clipping, scheduler behavior, and checkpoint selection. V9 tests the narrower practical question of whether a frozen learned Q path plus a small P-side correction can be useful after the LEVEL parent has already been selected.

On Robin, the P branch did not produce a useful nonzero update. STAGED_P equaled the LEVEL parent at combined MSE 0.275196 and MAE 0.324593, and the alpha policy selected alpha zero for both seeds. It remained worse than F0, which had MSE 0.229095, and LoRA, which had MSE 0.223610; relative to LoRA, the remaining MSE loss was +23.07%. The matched raw head was not a supported improvement either: STAGED_RAW had MSE 0.276520, while STAGED_RAW_ALPHA had MSE 0.275487. The paired block interval for STAGED_P versus STAGED_RAW included zero, with delta MSE -0.001324 and interval [-0.003030, 0.000601]. Robin therefore supports no replacement of the LEVEL parent and no claim that staged P correction solves the known F0/LoRA gap.

On Jena, the same procedure gave a conditional signal. STAGED_P reached combined MSE 0.279884 and MAE 0.298963, a -13.71% relative change from the frozen LEVEL parent at MSE 0.324359, with paired block delta interval [-0.053305, -0.033137]. It also improved over the matched raw head, whose MSE was 0.286285, by -2.24% with interval [-0.007876, -0.005168]. Both STAGED_P_ALPHA seeds selected alpha one, so the auxiliary alpha policy did not change the Jena model. The improvement did not establish broad accuracy superiority: v8 JOINT_PQ was close at MSE 0.279714; STAGED_P differed by +0.000169, and the paired interval crossed zero. This is not evidence of equivalence. DIRECT_NLINEAR remained lower at 0.273984, and LoRA was substantially lower at 0.240590, leaving STAGED_P +16.33% worse than LoRA. F0 was worse than STAGED_P on MSE, 0.292300 versus 0.279884, but had lower MAE, 0.264758 versus 0.298963, so the practical comparison is metric-dependent.

The P/Q diagnostics explain the Jena signal without turning it into a causal proof. On the complete-target subset of 35,040 rows, STAGED_P reduced retained-space MSE from the parent’s 0.255840 to 0.211365 while preserving Q-space MSE at 0.068519. The Q prediction parity check passed for both Jena STAGED_P seeds, with maximum absolute Q prediction differences below 0.000001 and zero violations under the predeclared tolerance. The matched raw head also improved retained-space error, but had slightly worse P MSE, 0.212916, and increased Q MSE to 0.073369. Thus the observed Jena advantage over matched RAW is consistent with preserving the learned Q component while adding a P-space correction, but this statement is limited to the exposed Jena evaluation and the complete-target diagnostic subset.

The Jena cost run measured 29 configurations and 99 timing rows after a pre-timing checkpoint-replay failure was fixed by applying the same torch.no_grad context to model construction and forward for every comparison; numerical tolerances were not widened. STAGED_P used 47,754,108 deployed parameters and 191,016,432 parameter bytes when the frozen backbone, parent residual head, and new head are included. Only 17,920 parameters were newly trained in v9, and the cumulative fitted adapter count is 35,840. In the same Jena session, STAGED_P had batch-4 throughput 325.52 origins/s, peak allocated memory 217.97 MiB, peak reserved memory 238 MiB, and batch-1 latency 11.64 ms. The parent LEVEL was 342.78 origins/s with 217.90 MiB allocated, and v8 JOINT_PQ was 324.90 origins/s with 217.97 MiB allocated, so there is no stable speed advantage claim for STAGED_P over those TSFM paths. Full LoRA had lower throughput, 224.80 origins/s, and higher allocated memory, 281.44 MiB; the M24 LoRA deployment had 88.45 origins/s and 216.89 MiB. DIRECT_NLINEAR had far lower point cost, 21,249.73 origins/s and 9.56 MiB allocated, while also having lower Jena MSE at 0.273984.

The current decision is conditional retention as a secondary method ablation, not default replacement or a new main topic. Robin provides a direct counterexample where the method falls back to the parent and leaves the LoRA/F0 gap unresolved. Jena provides a positive signal over the LEVEL parent and matched RAW, but not over LoRA or DIRECT_NLINEAR, and not over v8 JOINT_PQ by a meaningful margin. The Jena cost result shows that the conditional P correction keeps TSFM-path memory near the parent and below full LoRA, but it does not create a stable throughput win over the parent or solve the simple DIRECT_NLINEAR tradeoff. The next decision is whether the paper retains this as an explicit deployment-constrained LEVEL+P diagnostic or pauses the main-method claim; no fresh dataset search, tuning round, or guaranteed topic-success claim follows from v9.
