# 고정 PCA 성분 교체 진단: 하나의 공통 병목으로 좁혀지지 않음

**[확인] 현재 부모의 P 또는 Q 한 성분을 미압축 모델의 대응 예측으로 바꾸는 고정 조합은, 네 자료 어디에서도 합산 MSE 점추정으로 FULL_MSE LoRA를 넘지 못했다.** 그러나 부모를 개선하는 성분은 자료마다 달랐다. 이 결과는 더 큰 G 하나, 내부 LoRA 하나, 또는 학습량 부족 하나로 반복된 외부 정확도 격차를 설명하기 어렵다는 근거다. 전체 TSFM PEFT의 불가능성이나 고정 K에서 가능한 모든 방법의 상한을 증명하지 않는다.

이번 분석은 기존 v14 평가 이후의 사후 개발 진단이다. [사전 분석 계약](POSTHOC_COMPONENT_PLAN.md)을 먼저 기록하고 네 자료의 저장 예측만 사용했다. 새 학습·계수 적합·optimizer update·모델 forward·GPU·benchmark·다운로드는 모두 0이다. 원래 v14의 48fit와 음성 판정은 바꾸지 않는다.

## 무엇을 바꿨는가

원래 TRAIN PCA의 U로 P=UU^T, Q=I-P를 만들었다. v13의 GROUP basis가 아니라 데이터 배열의 `pca_basis`다. 부모 R은 PCA_LEVEL 또는 내부 LoRA A, donor D는 미압축 F0 또는 FULL_MSE LoRA다. 같은 seed·원점에서 다음 두 조합을 계산했다.

```text
swapP(R,D) = D P + R Q
swapQ(R,D) = R P + D Q
```

두 조합 모두 과거 입력으로 만들어진 저장 예측의 고정 결합이다. 미래 정답으로 성분·계수를 고르는 oracle은 아니다. 다만 이를 배포하면 donor의 미압축 추론 비용이 필요하므로 저비용 새 모델이나 해결책으로 보고하지 않는다. 각 조합은 자기 부모 R와 donor D 모두에 비교했다. 한 자료의 좋은 조합을 고른 정책도 만들지 않았다.

F0는 원본 1개를 두 seed 대응에 재사용했다. A와 LEVEL의 Q는 네 자료에서 기록된 수치 허용오차 안에 같았고, 같은 donor의 swapP도 사실상 중복이다. 따라서 자료별 원본 7개와 조합 16개를 독립적인 23회 실험으로 세지 않는다. 평균은 seed별 손실 평균이며 예측 ensemble이 아니다.

## 원래 masked macro 점수에서의 결과

아래는 D=FULL_MSE, R=PCA_LEVEL의 사전 지정된 대응 예다. 전체 8개 조합 역할·두 seed·A/B 기간·채널별 결과는 [모델 CSV](component_swap01_models.csv), [채널 CSV](component_swap01_channels.csv), [비교와 조건부 구간](component_swap01_comparisons.csv)에 모두 남겼다. 기간별 SSE와 관측수를 채널별로 합친 뒤 채널 평균을 냈다. 자료 사이 원 MSE를 평균하지 않았다.

```text
dataset             LEVEL MSE   swapP MSE  swapQ MSE  FULL_MSE MSE
Robin                0.275196   0.251730   0.241980      0.218517
Jena                 0.324359   0.236170   0.321081      0.232892
Hog                  2.666809   2.655130   2.638370      2.625304
Peacock Education    0.203266   0.202519   0.198928      0.198176

dataset             LEVEL MAE   swapP MAE  swapQ MAE  FULL_MSE MAE
Robin                0.324593   0.302954   0.295546      0.258718
Jena                 0.320450   0.250140   0.317597      0.238943
Hog                  0.802649   0.761946   0.730812      0.623919
Peacock Education    0.315004   0.313776   0.302724      0.298839
```

**Robin: 두 성분 모두 연결된다.** FULL_MSE의 P 교체는 부모 MSE −8.527%, Q 교체는 −12.070%이며 합산 조건부 95% 상대 구간은 각각 [−17.487, −1.207]%, [−18.883, −6.040]%다. 양쪽 모두 개선 여지가 있지만 어느 하나만 교체해도 donor에는 미치지 못한다. F0 donor도 양쪽 교체가 부모를 개선하므로 이 양상 전부를 LoRA의 적응 효과로 돌릴 수 없다. 다만 P 교체의 test_a 변화 −1.274% 구간은 0을 포함하고, test_b −15.700%와 다르다. Q 교체는 두 기간 모두 개선 방향의 구간이다.

**Jena: 기존 LEVEL의 주경로가 큰 차이를 만든다.** FULL_MSE P 교체는 부모 MSE −27.189%, Q 교체는 −1.011%다. P 교체는 두 기간에서도 −33.295%/−15.786%이며 구간이 개선 방향이다. 원래 A가 Q를 유지하면서 개선한 결과와 일관되지만, 원인을 입력 정보 손실·정규화·Transformer 비선형성 중 하나로 분리하지는 못한다. A 자체의 MSE 0.253093에서 FULL_MSE Q만 교체하면 0.249815로 작은 개선이 남는다. P 교체 0.236170도 FULL_MSE보다 MSE +1.408%, MAE +4.686%이며 두 합산 구간은 악화 방향이다.

Jena의 반례를 보존한다. F0 P 교체는 0.282298로 원래 LEVEL과 F0의 MSE보다 낮지만, F0보다 MAE +6.120%이고 A보다 MSE가 높다. A에서는 두 기간 모두 악화하므로 기존 내부 적응 효과를 압축 자체의 실패라는 설명으로 지우면 안 된다. F0 Q 교체는 LEVEL의 MSE를 +3.084% 악화시킨다. 따라서 미압축 예측이면 어떤 성분이든 더 좋다거나, FULL_MSE donor의 개선이 순수한 압축 제거 효과라는 설명은 성립하지 않는다.

**Hog: 주 MSE의 성분 순위는 확정하기 어렵다.** FULL_MSE P/Q 교체의 부모 대비 MSE 점추정은 −0.438%/−1.066%지만 두 합산 구간은 0을 포함한다. 두 교체 모두 test_a에서는 악화, test_b에서는 개선 점추정으로 방향이 바뀐다. 반면 MAE는 각각 −5.071%/−8.950%이고 개선 방향의 구간이다. 여전히 FULL_MSE보다 MAE +22.123%/+17.133%다. A의 Q 교체도 donor 대비 MSE +0.160%의 불확실한 차이와 MAE +16.061%의 손해가 함께 남는다. A의 FULL_MSE P 교체는 seed 92601에서 개선하고 92602에서 악화하며, Q 교체는 seed 92602만 donor보다 MSE가 낮다. 작은 합산 MSE 차이만 보고 해소라고 부를 수 없다.

**Peacock Education: 상대적으로 Q 교체가 더 도움이 된다.** FULL_MSE Q 교체는 부모 대비 MSE −2.134%, MAE −3.898%로 합산 구간이 개선 방향이다. P 교체의 −0.368%/−0.390% 구간은 0을 포함한다. Q 교체 후에도 FULL_MSE보다 MSE +0.379%, MAE +1.300%의 점추정이 남지만 그 구간은 0을 포함하므로 확정된 열세 또는 동등성으로 쓰지 않는다. Q 교체의 test_b MSE 구간 역시 0을 포함한다. donor 대비 Q 교체 MSE는 test_a −0.750%, test_b +1.957%로 반전한다. P 교체 MSE는 부모 대비 test_a +0.740%, test_b −1.876%로 방향이 다르다.

## 결측과 부분공간 해석의 제한

완전관측 target 벡터의 공통 부분집합에서만 오류를 P/Q에 투영했다. 전체 coverage는 Robin 99.948%, Jena 100%, Hog 84.167%, Peacock 99.583%다. 결측 정답을 0으로 채워 투영하지 않았다. **Hog에서는 순위가 실제로 달라진다:** 완전관측 Euclidean MSE는 LEVEL 2.567753 < FULL_MSE 2.595677이지만, 원래 관측 mask의 macro MSE는 LEVEL 2.666809 > FULL_MSE 2.625304다. 완전관측 P/Q 에너지를 전체 주 지표의 원인 분해처럼 쓰면 잘못된 판단이 된다.

Jena의 완전관측 P 에너지는 LEVEL/A/FULL_MSE 각각 0.255840/0.184574/0.167651, Q 에너지는 0.068519/0.068519/0.065240이다. 이는 현재 부모들에서 남는 차이의 위치이지 같은 비용으로 그 차이를 복구할 수 있다는 보장이 아니다. 다른 자료의 에너지·coverage·부호오차는 [원본 JSON](component_swap01.json)에 보존한다.

모든 자료에서 LEVEL의 P 예측과 원채널 F0의 P 예측은 수치 오차보다 크게 다르다. 채널 혼합 뒤 native 문맥 scaling·비선형 forward·median 출력을 사용하는 경로와, 원채널 예측 후 투영하는 경로는 교환 가능하지 않다. 그러나 이 관찰만으로 어느 내부 연산이 손해를 유발했다고 특정하지 않는다.

## 다음 판단

**현재 고정 PCA·공유 시간 잔차 구조에 같은 head를 하나 더 붙이는 개발은 재개하지 않는다.** Jena 내부 적응의 기존 양성 결과는 유지하되, 그것을 Robin/Hog/Peacock의 정확도 회복이나 범용 해결로 확대하지 않는다. 이번 조합은 어느 한 성분 교체도 공통 외부 정확도 격차를 해결하지 못한다는 반례를 추가했다.

남은 연구 결정은 **현재 압축·정확도 목표를 함께 유지하면서, 기존 모듈 추가와 다른 구체적 변경이 어느 손해를 줄일지 검증 가능한 가설을 제시할 수 있는가**다. 지금 결과로 더 큰 G, 새 K, 새 자료, 입력별 routing을 자동 실행할 근거는 없다. 그런 가설·대조·자원 계약 없이 양성 결과가 나올 때까지 다음 버전을 만들지 않는다. 목표가 해결되었다거나 논문 주제가 확보되었다고 보고하지 않는다.

## 검산과 계산 범위

[검산 결과](component_swap_checks01.json)는 원본 28개·조합 64개, 전체/기간/채널 점수·기간 풀링·P/Q 대수·source hash·CSV 정합성을 확인했다. 420개 모델/평균·기간 행, 8,715개 채널 행, 384개 지표 대비 행을 보존했다. 원래 점수 replay 허용오차는 atol 1e-10/rtol 1e-9, Gram 상한 1e-5, 완전관측 score-unit 에너지 허용오차는 1e-6 + 1e-6 relative다. 모든 검산이 통과했으며 tolerance를 확대하지 않았다.

2,000회 paired block 구간은 기존 7원점/기상 42원점 규칙과 기간 경계를 유지했다. 선택된 노출 모델에 조건부이며 전체 방법 선택 불확실성을 포함하지 않는다. 별도 검사기는 점수·대수·출처·구간 형식/설정을 검산했고 bootstrap draw를 재실행하지 않았다. 자체 검산이며 독립 재현이 아니다. 분석 29.756초, 구문 검사 0.033초, 수치 검산 6.579초를 기존 v14 원장에 실행 전 예약 후 계상했다. 게시 검사는 별도로 같은 CPU 한도 안에 기록한다.
