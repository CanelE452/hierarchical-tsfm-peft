# v10 결정: ridge 보완으로 정확도 손해·범용성은 해결되지 않았다

승인한16개 적합과 두 자료의 고정 비교를 완료했다. **Robin에는 새 보정을 채택하지 않는다. Jena에는 부모와 RAW 대비 개선이 남지만, v8/v9를 대체할 추가 정확도 근거는 불충분하다.** 이번 보완은 제한된 절제 결과로 남기고, 같은 공유 선형 보정 계열의 추가 튜닝은 종료한다. 최상위 목표인 미압축 F0/LoRA 대비 손해 및 범용 선택 가치의 해결은 미달이다. 이 판정을 방법 구현 실패와 혼동하지 않는다.

## 무엇을 실제로 바꾸었나

각 자료·seed의 학습된 LEVEL 전체 f*와 TRAIN PCA P=UU^T를 고정했다. deltaX는 입력 마지막 관측값을 뺀 문맥이다.

    RIDGE_P(X)   = f*(X) + W_P deltaX P
    RIDGE_RAW(X) = f*(X) + W_R deltaX

공유·무편향 W는48×512의24,576개 계수이며 기존 rank32 인수분해 head를 대체한다. 전체 TRAIN의 관측 마스크·채널 동일가중 MSE에 lambda||W||²/48을 더해 CPU FP64로 직접 적합했다. 예측은 FP32다. 부모를 포함한 누적 적합 계수는42,496개이고, 적합 완료 후 requires_grad가0인 것을 학습 변수가 없었다고 보고하지 않는다. 전체 배포에는 TSFM이 여전히 필요하다.

P/RAW 모두 lambda={0.001,0.1}과 같은 두 부모를 제공했다. 자료·방법별 두 부모의 평균 VAL MSE로 한 lambda를 선택했고 모든 경우0.1이 선택됐다. Robin은 P/RAW 양쪽 VAL이 부모보다 나빠 정책상 부모 복귀이며, 보정한 후보의 불리한 평가도 모두 남겼다. Jena는 양쪽 보정이 VAL에서 선택됐다. 이 선택을 두 자료 모두 확정하고 온라인 복원을 검증한 뒤 평가를 열었다. 이후 fit/penalty/채널/기간을 바꾸지 않았다.

이 변화는 시간 rank, 규제, 적합 방식, 전체 TRAIN 사용을 함께 바꾼 실용 보완이다. 순수한 최적화 또는 rank의 인과 검정은 아니다. Ridge 자체는 표준 방법이며 신규 발명으로 주장하지 않는다. 이전 v9의 단일 alpha 축소와 달리 입력 공분산의 방향별로 규제하지만, 이것이 개선을 보장하지 않는다. [표준 목적식](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)

## 정확도: 확인된 두 seed 손실 평균

TRAIN 표준화 좌표의 관측된 미래에 대한 channel-macro MSE다. 예측 ensemble이 아니다. A/B는 채널별 오차합/관측수로 합치며 단순 기간 평균으로 대체하지 않았다. 원수치·분모·채널·seed는 [전체 JSON](comparison.json), [기간 CSV](metrics.csv), [seed CSV](seed_metrics.csv), [채널 CSV](channel_metrics.csv), [대응 차이·구간](comparisons.csv)에 있다.

```text
구성                  Robin MSE     Jena MSE
기존 LEVEL             0.275196     0.324359
v9 STAGED_P            0.275196     0.279884
v8 JOINT_PQ            0.279019     0.279714
v10 RIDGE_P            0.280218     0.279250
v10 RIDGE_RAW          0.281397     0.285022
직접 NLinear           0.327724     0.273984
미압축 F0              0.229095     0.292300
미압축 LoRA            0.223610     0.240590
```

Robin P는 부모 대비 MSE1.825% 악화했고 조건부95% 블록 구간은[+0.125%,+4.286%]다. 두 seed·두 기간 모두 MSE/MAE가 악화했다. RAW 대비0.419% 낮은 점추정의 구간은0을 포함하며, 이것이 부모 대비 악화를 상쇄하지 않는다. P의 LoRA 대비 손해는25.316%; VAL 정책대로 부모를 유지하면 기존23.069% 손해가 남는다. P의 A/B MSE는0.282849/0.277586, 부모는0.273677/0.276712다.

Jena P는 부모 대비 MSE13.907%, matched RAW 대비2.025% 낮으며 두 seed·두 기간에 개선이 남는다. 그러나 v9 대비는0.2265% 감소에 그치고 조건부95% 구간[-0.4611%,+0.0947%]가0을 포함한다. v8 대비0.1662% 감소도 구간이0을 포함한다. 새 ridge의 확실한 추가 우위나 동등성으로 해석하지 않는다. seed92602의 MAE는 v9보다 전체0.000126, TEST-B0.000490 높다.

Jena P의 LoRA 대비 MSE 손해16.069%, MAE 손해31.807%가 남으며 두 seed·두 기간 모두 불리하다. 직접 NLinear 대비 전체 MSE는1.922% 높고 구간[-0.898%,+4.716%]가0을 포함한다. NLinear 대비 A는4.127% 악화, B는1.469% 개선으로 방향이 반대이며 MAE는 양 기간 모두 악화했다. F0보다 MSE가4.465% 낮지만 MAE는 더 높다. A/B P MSE는0.345773/0.212726, MAE는0.344432/0.252877이다.

블록 구간은 기간 경계를 넘지 않는 Robin7/Jena42원점,2,000회 재표집이며 모든 채널과 비교군을 같이 움직였다. 고정된 두 부모 아래의 조건부 변동이다. 반복 VAL 사용, 방법 선택, 학습 불확실성 전체를 포함하지 않는다. Robin/Jena 모두 기존 노출 개발 자료이며 새로운 독립 확증이 아니다.

## 원인에 관해 더 좁힌 것

선행 진단에서는 Robin의 학습된 v9 head가 같은 TRAIN probe를 낮추지만 VAL을 악화함을 확인했다. [진단 결과](../tsfm_peft_followup_diagnosis_20260929/STATUS.md)

이번에는 전체 TRAIN에 대해 직접 푼 규제 선형 보정도 Robin의 VAL·평가 손해를 줄이지 못했다. 따라서 단순한 gradient 단절, rank32 인수분해 SGD만의 실패, 또는 더 많은 epoch가 필요했다는 설명만으로 현재 결과를 설명하기는 어렵다. 다만 두 penalty의 결과가 모든 공유 선형 보정의 최적 성능 상한을 증명하지는 않는다. 원인 하나가 완전히 식별됐다고 주장하지 않는다.

P 보정은 Q 예측을 유지하므로 Robin의 Q 손해를 직접 수정할 수 없다. 같은 적합 기회를 준 RAW도 실패했다. Jena의 P 보정 이득은 계속 재현되지만 LoRA/직접 선형 대조의 반례를 해소하지 못했다. 압축 잠재 계열에 동결 TSFM을 적용하는 경로와 원채널 TSFM 경로 사이의 차이는 여전히 남으며, 이번 실험이 그 차이를 순수하게 분리한 것은 아니다.

## 비용과 검증

[확인] Jena에 한해 조건부 비용 측정을 실행했다. 11개 모델 인스턴스의 전체 VAL 복원·B1/B4 출력 정합성과 LoRA 병합 검사를 통과했지만, 3블록의 예정78개 측정 중68개만 완료했다. 승인된 비용600초 상한을 넘기지 않도록 종료 여유를 두고 자기 작업만586.663초에서 중단했다. [종료 기록](cost_guard.json), [전체 부분 측정](cost_jena_jena_cost01_partial.json), [정합성 결과](cost_jena_jena_cost01_parity.json)를 보존한다. **최종 B4 처리량·B1 지연·메모리 우열은 미확정이다.** 부분 블록을 완성된 비교로 합치거나 유리한 측정만 선택하지 않았다. 느려진 원인은 특정하지 않았으며, 과거 v9 timing과 새 timing의 비율도 만들지 않는다. 정확도 비교는 이 비용 미완료와 별개로 유효하다. Robin은 새 후보가 VAL과 평가 모두 악화해 비용을 반복하지 않았다.

합성 optimizer0회, 실제 신경망 학습0회다. CPU 직접 적합도 실자료 attempt로16회 계상하며 각 fit의48개 내부 horizon solve는 별도 기록했다. 실제 두 형상의 P 보존·초기 부모 함수·직렬화, 직접 목적식과 정규방정식, FP64 적합과 FP32 예측의 점수 정합성,8개 선택 모델의 온라인 전체 VAL 복원을 확인했다. 이 실행팀 검산은 독립 재현이나 과학적 성공 인증이 아니다.

Jena 첫 평가의 원장 파일 교체 접근 오류는 실패·partial·예측을 보존하고 bounded retry로 수리했다. 두 번째 평가는 같은 봉인과 해시가 일치하는4개 기존 예측을 재사용했다. 재학습·재선택·허용오차 확대는 없었다. [수리 기록](REPAIRS.md)

## 다음 결정 한 가지

**이번 ridge를 정확도·범용성 해결책으로 채택하지 않는다.** Jena에서의 P 보정 효과와 표준 직접 적합 대조는 연구 근거로 남긴다. Robin의 기존 LEVEL, Jena의 기존 대조 결과를 새 방법의 성공으로 재명명하지 않는다.

이 목표를 계속 개발하려면, 같은 공유 선형 head의 추가 미세조정보다 **압축 TSFM 경로와 원채널 정보의 처리 범위 자체를 바꾸는 별도 설계를 승인할 것인지** 결정해야 한다. 그 방향이 성공한다는 보장은 없으며 이번 회차에서 자동으로 새 구조·자료·탐색을 추가하지 않았다.
