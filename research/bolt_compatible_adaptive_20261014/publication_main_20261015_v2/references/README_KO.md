## 미게시 역사자료 링크

이 절로 온 링크의 원 대상은 과거 캠페인의 추가 문서·코드·JSON·수치표 등으로, 이번 8파일 추가 게시 범위에 포함하지 않은 역사자료다. 파일이 로컬에 없다는 뜻이나 NPZ·모델 가중치라는 뜻이 아니다. 이미 Git에 게시된 의존성은 그 파일로 연결하고, 나머지는 여기서 범위를 설명한다. 원 링크와 대상은 수정 복사 기록의 reference_markdown_link_rewrites에 보존했다. 전체 의존성을 다시 가져오거나 실행하지 않았다.

원자료·NPZ·모델·checkpoint가 필요한 실제 실험 재현은 별도의 [로컬 전용 자산 안내](../CODE_AND_REPRODUCTION_KO.md#local-assets)를 따른다. 공개 참고 코드만으로 과거 캠페인 전체가 독립 재현됐다고 주장하지 않는다.
