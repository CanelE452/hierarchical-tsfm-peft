# Phase 1 실행 승인 요약

상태: **승인 대기 / 새 구현·학습·추론0**. [Phase 0 감사](PHASE0_AUDIT_KO.md)와 [상세 실행 계약](PHASE1_PLAN_KO.md)을 바탕으로 한다.

**목표:** 작은 K에 미래 예측 정보를 남길 필요가 있는지, 고정 Bolt를 거칠 추가 가치가 있는지, Raw와 동등한 보정 후에도 정확도·전체 비용 이득이 있는지를 판단한다. 기존 E/D·learned U·TS2Vec/GTConvAE·LEVEL 잔차를 새 방법으로 포장하지 않는다.

**첫 실험:** Robin C17·Beijing C11, 기존 FIT256/TUNE64/VAL30·노출 EVAL146, L512/H48, FIT 통계·창별 causal forward-fill·관측 마스크를 유지한다. 같은 현재값 anchor와 실제-Y innovation ridge로 자기 채널33요약(SELF33), 모든 채널의 같은 요약(JOINT33), 강한 자기 채널 전체512(SELF512)를 비교한다. 세 경로 모두 α7개를 전체 macro TUNE MSE로 선택하고 같은 PERSIST·FIT 평균 통제를 넣는다. Raw Bolt도 같은 origin의 실용 기준으로 둔다.

새 SELF 두 종류는28개 모델 묶음이다. 기존 JOINT14개 ridge 후보는 source/통계/원수치 검산 후 재사용하며 세 경로의9pool은 총54비교다. 기존 joint 선택을 덮지 않는다. 캐시 gate가 실패하면 해당 경로만 최대14개 새 모델로 대체한다. 채널별 하위 계수·rank·용량 차이와 결정적 모델의 seed 중복을 따로 기록한다.

**결과별 결정:** 다른 채널 유용성은 SELF33 대 JOINT33으로만 판단한다. TUNE MSE1% 이상 감소, MAE 악화1% 이내, 시간순4블록 중3개 이상에서 MSE 감소를 다음 자원 배분의 탐색 기준으로 고정한다. 유의성이나 독립 일반화 증거가 아니다. 아직 Raw/SELF512보다 나빠도 작은 K의 보존·비용 절충 가능성은1차 검사한다.

이득이 없고 FIT만 좋아지면 동일 FIT 구간에서 legal origins 최대512로 self/joint를 동시에 늘리는1회 진단만 추가한다. 계속 무이득이면 그 조건에서 공통 표현 근거 부족을 보고한다. gate가 지지하면 새 표현 계열은 ForeCA 원리 기반 projection과 표준 예측 목적 linear E/D 중 최대2개로 제한한다. 신경망은2seed·조건별600updates를 상한으로 둔다. 같은 E/D의 완료된 Bolt/native 비교를 재사용하고 필요할 때 채널별 native 선형 대조1계열만 추가한다.

결합의 질문이 남으면 공통 경로·PCA·Raw Bolt에 동일 RAW33C 잔차 보정을 적용한다. 기존84 MAIN 보정을 그대로 반복하지 않으며, 미실행 future-conditioned p49K는 이번 실행에서 제외한다. 긴 입력이 경쟁 설명이면 지원 자료의 Raw L512/1024/2048을 같은 origins로1회 비교하고, Robin FIT 내부 L2048은 불가능으로 기록한다. Jena C21·Appliances C26는 기존 계약의 조건부 후속 자료로만 사용한다.

다음 분기는 FIT/TUNE로 먼저 고정하고 새 개발 점수로 대표 자료·방법을 고르지 않는다. 같은 계열2회 무이득 또는 자원 상한에 닿으면 멈춘다. Raw·강한 self·Raw+동등 보정 대비 정확도와 whole 비용은 **별도 방법 채택 기준**이다. 실패·부분·불충분도 허용하며 좋은 점수가 나올 때까지 반복하지 않는다.

**신규 캠페인 상한안:** GPU process 누적90분, CPU process 누적120분, 전체 wall4시간, 새 저장6GiB, RSS8GiB, GPU reserved9GiB. CPU·메모리 상한은 원문에 빠져 이번 계획에서 보완했다. 승인 후 새 고정 시계를 활성화하고 이전 기록을 보존한다. 첫 진단부터 비용·검산·보고까지 약30–60분은 사전 추정이며 후속 분기는 상한 내 근거가 있을 때만 진행한다.

산출물은 실행 상태·6항목 결정 기록·동일 계약 비교 CSV·한국어 보고서·유효한 원수치 그림·교수님용5–7장 발표 스토리 MD다. 보호 TEST, 기존 job 중지, 큰 backbone 학습, 새 다운로드/설치, 원본 덮어쓰기, 자동 commit/push, 실제 PPT/논문 작성은 포함하지 않는다.
