이 작업은 CanelE452/hierarchical-tsfm-peft의 INFORMS 후속 실험 실행 요청이다.
동봉한 MASTER_PLAN.md를 전부 읽고 CAMPAIGN_CONTRACT.yaml을 초기 설정으로 사용해라.
둘은 기존에 실행된 코드가 아니라 이번에 작성한 실행 설계다. 실제 경로·스키마는 먼저 확인해라.

목표: 데이터·채널 수·K·학습량을 넓히고, G를 보존하는 결합, 시간 지연 압축,
여러 K 공동학습까지 최소 비교를 실제로 수행해 고정 Bolt의 추가 가치를 판단한다.
기존 c7a06e522e1cd8e100a3e2291a7f693dd3f7125f의 유효 결과는 보존한다.
새 범위와 계약이 다르면 옛 점수를 가져와 새로운 실험 결과로 쓰지 마라.

계획을 요약하고 끝내거나 README/감사 문서만 만든 뒤 완료라고 하지 마라.
실제 데이터 적합, 학습, 추론, 저장 예측의 별도 재채점, 비용 측정과 공개 묶음을 만들어라.
예측이 좋아지지 않아도 유효 결과와 반례를 모두 게시한다.
한 기준선이 나쁘다는 이유로 모든 새 방법의 최소 실험을 닫지 마라.
방법별 최소 실험 후에만 후속 규모를 증거에 따라 줄이거나 늘려라.

사용자가 이번 메시지로 요청한 범위에는 실험 결과·코드·검산 정보의 main 게시가 포함된다.
안전한 공개 목록만 commit하고 일반 fast-forward push로 origin/main에 게시해라.
force push, 보호 규칙 우회, 다른 작업 삭제, 원자료/토큰/상담 녹취 업로드는 허용하지 않는다.
브랜치 보호나 인증 때문에 main 게시가 안 되면 성공을 꾸미지 말고 차단 사유를 보고해라.

기본 자원 한도는 신규 GPU 사용 12시간, 전체 경과 48시간, 신규 로컬 저장 30GiB다.
12시간은 전체 수렴·완료 보장이 아니다. 짧은 실제 probe 후 전 실행 비용을 계산해라.
모든 핵심 가족을 먼저 얕게 덮고, 남는 예산을 충분 학습과 최종 검증에 배정해라.
초과가 예상되면 자동으로 예산을 늘리지 말고 재개 큐와 부분 결과를 main에 게시한다.
새 보호 TEST의 봉인을 몰래 열거나 공개 서비스 약관에 대신 동의하지 마라.

완료 보고에는 반드시 다음을 써라:
1) 실행한 데이터·K·모델·실제 업데이트/에포크와 학습 미해결 목록
2) Raw, G-only, G 동일정보 대조, B0, 병합 LoRA 대비 수치와 반례
3) 산술 재채점/체크포인트 재추론/전체 재학습 중 실제 검증한 범위
4) 원격에서 검증한 main commit SHA와 결과 파일 경로
5) 미실행·예산 중단·데이터 차단 항목과 정확한 재개 명령

MASTER_PLAN.md가 과학·공개 계약의 본문이며 YAML은 그 계약의 수치적 초기안이다.
둘이 충돌하면 임의로 유리한 쪽을 고르지 말고, 결과를 보기 전에 정합성을 맞춰 기록해라.
