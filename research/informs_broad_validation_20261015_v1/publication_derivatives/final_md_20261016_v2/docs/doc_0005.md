# A_fit 전용 채널 패턴과 그룹 오차

[확인] `channel_patterns.py`는 MASTER의 패턴 진단을 구현한다. 패턴과 low/high/NA 경계는 **해당 fold의 A_fit 50%만** 사용해 고정한다. M_cal·V_select·T_final 정답으로 패턴이나 임계값을 맞추지 않으며 그래프 학습·인과 추정·배포 selector를 만들지 않는다. 실제 fitting과 평가 모두 CPU에서 수행하며 원 자료·core·registry·SCORES·기존 그림을 수정하지 않는다.

```python
snapshot = fit_patterns(public_root, cache_root,
                        datasets=("beijing", "jena", "electricity", "pems08"),
                        fold="primary")
evaluation = evaluate_groups(public_root, cache_root, snapshot, split="V_select")
```

CLI는 `--public-root`, `--cache-root`, 선택적인 `--pattern-snapshot`, `--split`을 받는다. 이미 계산한 snapshot을 전달하면 A 패턴을 다시 적합하지 않고 현재 저장 예측만 평가한다. 실행은 `CUDA_VISIBLE_DEVICES=''`, `OPENBLAS_NUM_THREADS=2`, `MKL_NUM_THREADS=2`, `OMP_NUM_THREADS=2`로 수행했다. 입력 data SHA·A prefix/mask SHA·fit_end·source SHA·고정 임계값·실제 CPU 시간을 영수증에 기록한다.

## 고정한 네 지표

1. **상대 차분 변동성**: 원 시간축에서 서로 이웃하고 둘 다 관측된 값의 차분을 취해 `population std(diff) / population std(A_observed)`를 계산한다. 차분 pair가 2개 미만이거나 원 채널이 상수이면 NA다. 결측 구간을 건너뛰어 차분하지 않는다. 선형 추세는 차분 표준편차가 0일 수 있으므로 전체 변화 폭이나 비정상성의 직접 척도가 아니다.
2. **계절 상관**: 사전에 존재하는 `task.period`만 사용한다. period가 유효하지 않거나 관측 pair 30개 미만·pair 분산 0이면 NA다. 값은 **부호를 유지한 Pearson rho**다. 주기를 미래에서 선택하거나 절댓값을 계절성으로 바꾸지 않는다. 상관이 높아도 계절성만이 원인이라고 단정하지 않는다.
3. **지연 교차 채널 상관**: lag `{1,2,4,8,16,32}`에 대해 `source_j[t−lag] → target_i[t]` 방향의 pairwise-observed Pearson을 계산한다. 자기 채널을 제외하고 30 pair 이상에서 가장 큰 `|rho|`를 기록한다. winner source·lag·pair 수와 signed rho도 보존한다. `1e-12` 이내 수치적 동률은 작은 lag, 그다음 작은 source index를 우선한다. 음의 상관도 강도에는 들어가지만 부호를 숨기지 않는다.
4. **관측 exact-zero 비율**: 관측된 원 단위 값 중 `value == 0`인 비율이다. 결측의 채움값 0을 세지 않고, 작은 양수도 0으로 바꾸지 않는다. 모든 값을 관측하지 못한 채널은 NA다. 일정한 0 채널의 비율 1도 진짜 결과이며, 간헐 수요가 존재한다는 증명은 아니다.

자료별 각 지표의 유한값 중앙값을 고정해 `low <= median`, `high > median`, 나머지 NA로 나눈다. 동률이 많으면 low/high 채널 수가 같지 않다. 한 그룹이 비어 있어도 이를 합치거나 NA를 강제 분류하지 않는다.

큰 상수 offset의 raw-moment 취소 오차를 줄이기 위해 A 관측 채널 평균을 먼저 빼며, 그 뒤에도 **실제 pair별** count·sum·평균·분산을 계산한다. 반올림 불확실성이 있는 pair는 직접 다시 중심화하여 계산한다. 음의 수치 분산을 무조건 0으로 자르거나 양의 작은 분산을 제거하지 않는다. 결측 NaN은 곱셈 전에 마스크로 제거한다. 전체 C×C 행렬이나 원 시계열은 공개하지 않고 채널별 요약과 winner만 공개한다.

## 그룹별 오차와 대응 비교

실제 표준 prediction manifest와 독립 reference의 파일/배열 SHA·target/mask/origins/channel 순서를 검사한다. 학습 scorer를 재사용하지 않고 자체 FP64 계산으로 채널별 SSE·SAE·관측 count를 구한다. 각 그룹은 관측 target이 존재하는 채널의 `SSE/count` 또는 `SAE/count`를 **채널 균등 평균**한다. 모든 관측 cell을 한꺼번에 평균하는 방식과 다르다.

각 run·지표마다 low/high/NA 세 행을 항상 남긴다. 총 그룹 채널 수·active 채널 수·관측 0 채널 수·관측/가능 target cell 수·coverage를 공개한다. 그룹이 비어 있거나 관측 target이 없으면 오차는 NA이고 coverage는 명시한다. 지표는 현재 scorer와 같은 A 기준 정규화 원채널 척도이며 서로 다른 물리 단위를 합쳐 원 단위 평균이라고 부르지 않는다.

`PAIRED_GROUP_DIFFERENCES.csv`는 사전에 정의한 baseline·B2−B0·lag·결합 대조에서 같은 data/scaler/target/mask/origin/channel cohort만 연결한다. B2/B0·lag 계열은 같은 K·seed·실제 epoch schedule을 요구하고, H/과거 대조는 같은 frozen parents와 학습 예산을 요구한다. H/G와 Raw 보정은 실제 부모 run을 연결한다. 서로 다른 학습·추가 정답 정보량은 별도 budget 필드에 남긴다. 모든 유효한 명시적 pair를 보존하며 최선만 선택하지 않는다. 겹치는 pair·채널·시점은 독립 표본이 아니며 통계적 유의성이나 공정성·인과성을 자동 주장하지 않는다.

T 평가는 실제 `SELECTION_LOCK.json`과 해당 run/artifact 또는 portable-route SHA 허가가 있고 이미 존재하는 T 예측만 사용한다. 새 T 추론·모델 선택·사례 선택·패턴 재적합을 하지 않는다. 허용된 저장 T manifest가 없으면 실패한다. 현재 실제 실행은 V만 평가했다.

## 실제 실행 결과

[확인] [A 패턴 snapshot](doc_0092.md)과 [V 그룹 평가](doc_0093.md)를 생성했다.

```text
자료          채널   A_fit 끝   변동성 median   계절 rho median   최대 |지연 rho| median
Beijing        11      10519      0.297092          0.391345            0.747566
Jena           21      10482      0.078803          0.705524            0.953653
Electricity   321      12120      0.421408          0.934417            0.867384
PeMS08        170       8928      0.253909          0.855760            0.941620
```

[확인] 채널 요약 523행, 저장 V 예측 12개, 그룹 오차 144행, paired 그룹 차이 144행을 작성했고 제외 입력은 0개다. A 적합 CPU process 2.96875초, 평가 CPU process 0.28125초였다. 표의 median은 그룹 정의용 기술통계이며 자료 사이 연구 성능 순위가 아니다. 최대 상관은 C·lag 후보가 많을수록 큰 값이 나올 기회가 많으므로 다른 자료의 값을 필요 정보량으로 직접 비교하지 않는다.

Jena·Robin은 legacy FP32 inverse-normalization 계보 때문에 원 단위 exact zero가 완전히 보존된다고 보장할 수 없다. Jena의 exact-zero 그룹은 이 한계가 있는 기술 통계다. Robin은 이 4개 실제 snapshot에 포함하지 않았다. PeMS의 0은 결측으로 취급하지 않으며 원본에 달력 timestamp가 없어 lag는 5분 sample step 기준이다. 서로 다른 자료의 lag1이 같은 물리 시간을 뜻하지 않는다.

이번 평가 시 전체 registry reconcile은 별도 작업이었다. 자체 수치 검산 통과를 전체 metadata/registry 감사, 학습 재현 또는 독립 일반화 검증으로 바꾸어 말하지 않는다. 현재 12개는 CURRENT·SEASONAL_NAIVE·RAW_RIDGE baseline이며 neural/결합 대조를 완료했다는 뜻이 아니다. 향후 새 manifest가 생성되면 동일 frozen snapshot으로 `evaluate_groups`를 다시 실행하여 새 immutable 평가 디렉터리를 만든다.
