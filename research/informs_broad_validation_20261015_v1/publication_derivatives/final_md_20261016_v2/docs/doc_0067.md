# 제공 원본 공개 검산기의 실행 영수증

최종 점수표의 모든 행과 결속된 원 gzip을 바이트 그대로 임시 flat bundle에 복사한 뒤 제공 audit()를 수정 없이 호출했다. 임시 SCORES와 모든 통계 SHA를 flat manifest에 넣었다. 원본 파일은 보존했고 임시 폴더는 자동 정리한다. 원본 통계의 수치/coverage/SAE-SSE/manifest 검산과 source·registry·lock 사후검사를 구분한다. 이 결과는 원예측 검산·학습 재실행·추론·T 선택·비용 측정이 아니다. 제공3개 selftest는 별도 합성 준비 증거다.
