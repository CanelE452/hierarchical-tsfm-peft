# 최종 평가 종료와 남은 비용 자원 단계의 실제 증거

[실제 gate 결과](../../gzip_extra_aux_20261016_v1/files/item_0589.json.gz)는 `PASS_OFFICIAL_POSTFINAL_METADATA_GATE`다. [불변 증거](../../gzip_extra_aux_20261016_v1/files/item_0587.json.gz)는 T46과 기존 checkpoint B55의 실제 출력, 동일 owner safe-fields, 중앙 종료 영수증, 정확한 PID/create-time 집합을 연결한다. [입력 바인딩](../../gzip_extra_aux_20261016_v1/files/item_0588.json.gz)을 함께 읽는다.

공식 T46 batch는46 PASS·실패0·deferred0다. 기존 B55는55개 모두 실제 재추론·독립 FP64 재채점·저장 곡선 일치를 통과했다. B는 역사적 개발 구간이며 새로운 T 일반화나 독립 재학습으로 세지 않는다. 이 metadata gate도 전체 표준 저장 예측·최종 global SCORES의 별도 감사 자체를 대신하지 않는다.

[실제 proof 생성기](../../../diagnostics/postfinal_resource_evidence_1792097984410700800/proof_builder.py)의 SHA는 `db8b53a322aacf2c9010cea02b05844483ed40493bfe648fdd25daab5625df29`다. 기본 metadata와 필수 인자 거부·합성 경계를 확인한 뒤 ROOT가 전체 소스를 읽고 실제 생성·검증을 실행했다. 이 작업은 새 GPU owner·모델·배열·학습·T 추론을 만들지 않았다.

[중앙 종료 영수증의 안전 사본](../../../diagnostics/postfinal_resource_evidence_1792097984410700800/CENTRAL_CLOSURE_COPY.json)은 원 cache 영수증과 byte가 같다(SHA `08e14f7ffc9151b03af501d830ef89440bf2dca31d63bf8c64cfe0115e076ed8`). 인증 token/port는 포함하지 않는다. owner와 인증 child의 실제 종료를 확인했고 원 source39·registry·selection lock을 보존했다.

이후 비용은 기존 전체 GPU 누적43200초와48시간 상한 안의 잔여분만 사용한다. 이 종료 시점 누적은40252.18507933617초다. pre-final39600초를 새로 주거나 전체 예산을 초기화하지 않는다. 실제 비용 실행 상태는 별도 postfinal 영수증을 따른다. 전체 필수 학습 완료 또는 게시 완료를 주장하지 않는다.
