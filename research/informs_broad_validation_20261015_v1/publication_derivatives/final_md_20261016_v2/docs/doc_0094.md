## 무손실 압축 공개와 원본 복원

[확인] 이 CSV는 원시 센서값이나 예측·정답 배열이 아닌 저장 V의 채널별 SSE/SAE/count 및 그룹 오류 집계다. 기존 원문과 수치·행 순서는 보존했다. 원 CSV 11,185,185bytes는 파일당20MiB 이하이지만 전체 공개 증분250MiB 안에 최종 결과를 담기 위해 gzip 1,004,672bytes로 제공한다. 수치 재계산·반올림·표본추출·행 삭제는 하지 않았다.

원 CSV SHA256: `3c77b01c4806e47636c67d73bb4d2d2a123295a282bbcaba1a2f9490d22f83e0`

gzip SHA256: `d8ca8ed44f91f81c9150cc67615c2198f3b6b1b75ce44983e18cbe7c6bfb798a`

gzip은 mtime0·빈 filename으로 생성했다. 별도 private 파일로 실제 해제한 결과 원 CSV와 byte 크기·SHA가 정확히 같았다. 원 CSV와 원 README는 로컬에 그대로 보존하며 이 안내와 gzip을 공개 대체로 사용한다. [복원 증빙](../../gzip_extra_aux_20261016_v1/files/item_0995.json.gz).

같은 폴더에서 원본이 없는 새 위치에 복원한다. 아래 코드는 기존 파일을 덮지 않는다.

```python
import gzip, hashlib, shutil
from pathlib import Path
src = Path("CHANNEL_ERRORS.csv.gz")
dst = Path("CHANNEL_ERRORS.restored.csv")
with gzip.open(src, "rb") as inp, dst.open("xb") as out:
    shutil.copyfileobj(inp, out)
assert dst.stat().st_size == 11185185
assert hashlib.sha256(dst.read_bytes()).hexdigest() == "3c77b01c4806e47636c67d73bb4d2d2a123295a282bbcaba1a2f9490d22f83e0"
```
