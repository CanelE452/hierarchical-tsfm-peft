# 게시 통계 압축본 재사용과 증분 검증

기존 213개 통계의 원본 gzip SHA를 다시 대조하고 별도 임시 트리에 CSV·원 gzip byte를 복원했다. 새 표준 통계만 겹치지 않는 별도 pack으로 만들고 같은 검산을 수행했다. 원본을 덮거나 삭제하지 않았다.
