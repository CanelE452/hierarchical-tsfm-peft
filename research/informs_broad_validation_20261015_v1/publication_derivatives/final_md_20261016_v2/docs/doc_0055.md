## 실행·보존 범위

실제 process exit0, wall2.3828799724578857초, peak RSS509,431,808 bytes, CPU thread2, CUDA 비노출·미초기화였다. source18을 포함한 source30과 보조 API3개는 전후 SHA가 같았고 실행 중 registry byte도 같았다. 실제 initial+extension/current 과학 registry 계약 오류는0이었다. [artifact 실행만 위한 registry projection](../../gzip_aux95_1792094747124151400/files/item_0046.json.gz)은 새 진단에만 저장했으며 main registry는 수정하지 않았다.

원 manifest/reference/public statistics/private archives/frozen mean/std/source를 보존했다. protected TEST·T·GPU lease·모델 생성·foundation·학습·추론·Git 호출은0이었다. 정상화 statistics와 저장 prediction NPZ만 allow_pickle=False로 읽었고 모델 weights 읽기는 허용하지 않았다. 원 경로가 하나라도 맞지 않으면 해당 경로만 차단하도록 실행했으며 이번 capture에는 실패가 없었다.

이 결과는 저장 예측의 실제 독립 재채점과 보조 오류 분석이다. checkpoint 재추론·새 모델 학습·비용 timing·수렴·새 일반화·전체 campaign 완료로 확대하지 않는다. 실행 log·실제 종료코드·driver·입력 registry capture는 private cache에, 공개 상대경로/SHA는 [입력 목록](../../gzip_extra_aux_20261016_v1/files/item_0547.json.gz)에 보존했다.
