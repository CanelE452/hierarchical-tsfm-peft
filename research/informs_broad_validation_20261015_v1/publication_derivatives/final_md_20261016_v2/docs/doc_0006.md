# 메타데이터로 고정한 시간 블록의 대응 차이

[확인] `time_block_analysis.generate(public, cache, split='V_select')`는 실제 저장 예측의 대응 오차를 전체 cohort와 비중첩 시간 블록으로 나누어 계산한다. 새 학습·추론·T 선택·bootstrap·CI·유의성 검정은 하지 않는다. 기존 `channel_patterns.py`의 사전 비교 가족 목록·epoch/부모 조건을 읽어 사용하며 원 frozen 파일은 수정하지 않았다.

```text
python -X utf8 time_block_analysis.py --public-root <campaign> --cache-root <private-cache> --split V_select
```

## 블록을 정하는 시점과 규칙

`block_origins = ceil(max(task.period, H) / H)`를 사용한다. period/H는 기존 task 메타데이터이며 평가 오차를 보고 추정하거나 조정하지 않는다. `BLOCK_RULES_PRE_SCORE.json`을 **private prediction cache를 열기 전에** 작성한다. 그 뒤 봉인된 실제 origin 배열의 앞에서부터 해당 origin 수만큼 연속 블록을 만든다.

평가 원점은 정확히 strideH로 연속되어야 한다. 각 target `[origin, origin+H)`가 겹치지 않으며, 마지막 짧은 블록도 그대로 남긴다. 원점을 추가·중복·샘플링하지 않는다. `COHORT_BLOCKS.json`은 각 블록의 모든 index, 시작·마지막 origin, target 끝, 짧은 tail 여부를 기록한다.

period는 독립성을 증명하지 않는다. 블록들은 자기상관·공통 계절·동일 채널·모델·겹치는 과거 입력을 공유할 수 있어 IID 반복이라고 부르지 않는다. 다른 자료의 같은 origin 수가 같은 물리 시간을 뜻하지도 않는다.

## 자체 FP64 계산과 대응 조건

실제 manifest와 독립 reference의 identity·archive SHA·5개 배열 fingerprint를 검산한다. forecast/target은 **뺄셈 전에 FP64**로 바꾸고 원 관측 mask만 사용한다. 학습 scorer를 호출하지 않고 origin×channel SSE·SAE·count를 자체 계산하여 저장 manifest의 전체 점수와 대조한다.

각 블록의 관측수를 채널별로 합친 뒤 `SSE_c/count_c`, `SAE_c/count_c`를 관측 target이 있는 채널에 대해 균등 평균한다. 두 방법의 차이도 같은 채널·target·mask로 계산한다. 채널 0개 관측은 error에서 제외하되 coverage에 남긴다. 전체 cohort는 모든 원점의 채널별 분모로 **별도 재집계**한다. 블록마다 active 채널과 관측수가 다르므로 블록 평균을 전체 점수나 전체 차이로 대신하지 않는다.

`OVERALL_PAIRED.csv`와 `TIME_BLOCK_PAIRED.csv`에는 두 run ID·자료·fold·K·seed·실제 학습 budget, left/right MSE·MAE 및 delta, 원점 수·총/active/관측0 채널 수, 관측/가능 target 수·coverage를 기록한다. block 행은 시작·끝·tail을 포함한다. 음의 delta는 첫 번째 방법의 오차가 작은 경우다. 지표는 A 기준 정규화 원채널 척도다.

data/scaler/cohort·정확한 target/mask/channel/origin 배열이 모두 같아야 대응 비교한다. B2/B0·lag 대조는 K·seed·epoch schedule을 맞춘다. H/과거 대조는 같은 frozen parents·학습 budget을, H/G와 Raw 보정은 실제 부모 run을 요구한다. 기존 정의의 모든 유효한 pair를 보존하며 best K/seed·유리한 블록만 고르지 않는다. 다른 학습·추가 정답 정보량은 budget 필드로 보존하므로 같은 평가 정답이라는 이유만으로 공정성이나 인과성을 주장하지 않는다.

## 실제 현재 실행

[확인] [diagnostics/time_blocks_1792057997797618500](doc_0086.md)에 현재 baseline V 예측 12개의 결과를 만들었다. 대응 비교 12개·전체 행 12개·시간 블록 행 345개이며 제외 입력은 0개였다.

```text
자료          period/H      블록당 origins     cohort blocks    마지막 tail origins
Beijing        24/48              1                  43               1 (정규)
Electricity    24/48              1                  50               1 (정규)
Jena          144/48              3                  15               1 (짧음)
PeMS08        288/12             24                   7               4 (짧음)
```

예를 들어 전체 `RAW_RIDGE−CURRENT` normalized MSE 차이는 Beijing −0.5007269727, Electricity −1.1093543801, Jena −1.4055176417, PeMS08 +0.0772417863이다. 이는 고정 cohort의 기술적 차이이며 독립 일반화·통계적 유의성을 뜻하지 않는다. 모든 블록과 나머지 대응 차이는 원 CSV에 남아 있다. 현재 12개 baseline으로 neural/결합/lag 대조까지 수행했다고 표현하지 않는다. 없는 비교는 manifest의 `unmatched_or_unavailable`에 남긴다.

실제 CPU process 0.59375초·wall 약0.647초였고 CUDA 비노출·BLAS/OMP2 환경을 기록했다. source/output SHA와 origin index의 정확한 단일 partition을 검산했다. registry는 읽기만 했으며 전체 registry 감사를 했다고 주장하지 않는다. 새로운 예측이 생기면 같은 API를 호출해 별도 immutable 진단 디렉터리를 만든다.

T는 이미 존재하는 locked `SELECTION_LOCK`의 run/artifact 또는 portable-route 허가와 실제 봉인 T manifest가 있을 때만 평가한다. 새 T 추론·후보/사례 선택은 하지 않으며 허가된 자료가 없으면 거부한다. 이번 실제 실행은 V만 사용했다.
