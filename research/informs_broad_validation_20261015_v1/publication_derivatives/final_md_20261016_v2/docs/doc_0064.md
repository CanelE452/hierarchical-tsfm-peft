# 52쌍 보조표의 시점 표현 교정

모델·역할은 T 평가 전에 만든 기존 선택 잠금으로 고정했다. **52쌍의 보조표 연결 명세는 T 결과 관찰 뒤 보고 작업에서 정했다.** 따라서 이를 T 이전에 사전 등록한 52개 비교로 표현하지 않는다. 이번 보고에서는 고정된 구조 비교를 T 점수 순위에 따라 빼거나 바꾸지 않는다.

원 `locked_route_pairs.py`와 원 테스트·README·준비 근거는 이력으로 보존했다. 새 실행 파일은 [locked_route_pairs_scope_v2.py](../../../diagnostics/postfinal_locked_route_pairs_20261016_v1/locked_route_pairs_scope_v2.py)다. 변경은 module docstring의 `predeclared`를 `fixed structural`로 바꾸고, 출력 README의 첫 범위 설명을 위 구분으로 교체한 두 문자열뿐이다. [byte diff](../../../diagnostics/publication_safe_aux_views_20261016_v1/views/postfinal_locked_route_pairs_20261016_v1__SCOPE_V2.diff.txt), [AST 검증](../../../diagnostics/postfinal_locked_route_pairs_20261016_v1/SCOPE_V2_DIFF_PROOF.json)에 계산·비교 명세·경로·예외 처리의 동일성을 기록했다.

[새 준비 결과](../../gzip_extra_aux_20261016_v2/files/item_0005.json.gz)는 기존 테스트의 module loader 파일명만 메모리에서 새 실행 파일로 연결한 13/13 PASS와, 실제 공개 metadata의 52/52 READY·오류 0을 기록한다. metadata 검사 중 `gzip.open`을 차단했고 원 파일을 읽거나 수정하지 않았다. 테스트 함수 이름에 남은 `predeclared`는 보존한 원 테스트 이름이며 연구 비교가 T 전에 사전 등록됐다는 뜻이 아니다.

ROOT가 제공한 조건부 실행 trigger는 이 literal-only delta, AST 동일성, 13 PASS, metadata 52 READY·오류 0을 만족한 뒤 새 파일을 실행하도록 했다. 준비 시점까지 실제 충분통계 집계는 0이었다. 실제 실행 상태는 별도의 실행 영수증과 새 snapshot의 RESULT로 구분한다. 기존 14쌍과 새 52쌍을 독립 표본으로 합산하지 않는다.

실행은 기존 [명령 설명](../../../REPRODUCE.md)의 파일명만 `locked_route_pairs_scope_v2.py`로 바꾸고 `--execute-report`를 추가한다. 원 helper의 범위 문구를 새 근거로 인용하지 않는다.
