# 실제 K별 학습 노출과 F stream 장부

초기 E4의 Beijing·Electricity shared/max-only 및 독립 B0 세 K의 공개 stage RECEIPT 20개를 읽었다. BASE/ordered 요약에는 없던 K별 origin 노출이 실제 search/refit receipt에는 기록되어 있다. 이 장부는 해당 20개 stage의 sum(K×노출)이 실제 F_training_logical_streams와 정확히 같은지 검증한다. K별 update는 기록된 total updates와 training.py의 연속 cyclic 규칙에서 유도한 값이다. 별도로 측정한 update telemetry라고 하지 않는다. 단일 K가 빈 dict인 경우는 명시적 해당 K와 stage 총노출을 사용했다.

Beijing shared의 .25 검색 노출은 K3/6/11에 832/832/826, 새 refit은1008/1008/1000이다. Electricity shared 검색은 K81/161/321에971/960/960이며 선택 epoch0으로 refit 노출은 모두0이다. 독립 K별 전체 노출과 shared의 K별 노출은 같지 않으며, 총 update 일치가 각 K의 학습량 일치를 뜻하지 않는다. 새 epoch3 심화는 이 초기 장부에 포함하지 않았다. 모델·원자료·예측배열·GPU·T·학습을 열거나 실행하지 않았다.
