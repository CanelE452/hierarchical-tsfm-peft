# 고정 V 보조 분석의 입력 계약

이 작업은 이미 생성된 V_select 예측의 CPU 보조 분석이다. 학습·모델 추론·foundation 호출·T 또는 보호 TEST 접근을 수행하지 않는다. 과학 코드와 registry, 기존 분석 결과는 수정하지 않는다. 현재 campaign이 진행 중이므로 실행 시작에 고정한 목록만 분석하며 이후 추가 V는 자동 포함하지 않는다.

## 실제 API와 입력 공급

[physical_metrics.generate](../../../physical_metrics.py)는 `split='V_select'`와 `normalizations` 입력을 지원한다. 기본 normalization 탐색은 일부 경우 selected .pt를 torch.load로 읽으므로 사용하지 않았다. 현재 five primary datasets의 COMPLETE_VALID Ridge receipt가 선언한 frozen NPZ에서 mean/std/data_sha/canonical_A60_end 네 멤버만 읽고, `generate(projection, cache, split='V_select', normalizations=...)`에 공급한다. NPZ 전체 bytes의 SHA는 receipt와 대조하지만 coefficients나 다른 모델 멤버를 역직렬화하지 않는다. zip member guard가 이 네 멤버 외 읽기를 거부한다.

데이터 SHA, receipt의 실제 A60 fit_end, 공개 DATA_CONTRACT의 A_stop 끝점, mean/std의 FP32 scaler fingerprint, 모든 대상 manifest의 scaler SHA가 같아야 실행한다. mean/std 길이는 계약의 전체 channel 수와 대조하고, 실제 예측 channel order는 API가 DATA_CONTRACT.columns 전체와 직접 비교한다. data SHA에는 원 계약의 column identity도 포함된다. 통계 값을 새로 fit하거나 V target으로 추정하지 않는다.

secondary Beijing/Jena 두 V는 별도 A60 통계가 이 안전한 입력 형태로 없으므로 물리단위 분석을 실행하지 않는다. primary 통계를 재사용하지 않으며, 모델 .pt를 열거나 target에서 역추정하지 않는다.

[time_block_analysis.generate](../../../time_block_analysis.py)는 V_select를 지원하지만 기본 구현의 data.load_task 호출은 실제 raw task를 열 수 있다. API가 이 반환값에서 사용하는 것은 period/H/columns/data_sha256 네 metadata뿐이다. 호출 시에만 data.load_task를 metadata adapter로 공급한다. H/columns/data SHA는 동일 bytes로 고정한 DATA_CONTRACT에서, period는 SHA가 고정된 [data_contract.load_task](../../../data_contract.py)의 기존 규칙(PeMS=288, Jena=144, 나머지=24)에서 온다. 반환 dictionary에는 physical/observed/times가 없으며 raw loader fallback은 없다. 이는 계산·block 규칙 변경이 아니라 기존 API에 동일한 metadata를 공급하는 호출 방식이다.

## 시작 목록과 실행 guard

[INPUT_CAPTURE.json](../../gzip_aux95_1792094747124151400/files/item_0005.json.gz)은 관찰 시각에 있던 V_select 334개 manifest/reference SHA, private V archive의 선언 SHA·상대경로, public stats 상대경로, registry 과학 identity를 고정한다. [REGISTRY_CAPTURE.csv](../../gzip_aux95_1792094747124151400/files/item_0059.csv.gz)는 고정된 등록부 bytes다. mutable 원 registry를 분석 도중 다시 선택 기준으로 사용하지 않는다.

private metadata projection에는 이 고정 manifest/reference·관련 학습 recipe·receipt·public sufficient statistics만 동일 bytes로 복사한다. 원 public root 아래에 중복 manifest를 만들지 않는다. 분석 API는 이 projection의 고정 목록만 순회하고 private forecast는 원 cache의 정확한 V 경로를 읽는다. audit._load_arrays가 archive SHA와 모든 배열/reference fingerprint를 검증한다.

caller는 모델/GPU 모듈 import, .pt/.pth/.bin/.safetensors, T_final·보호 TEST 경로, 허용 목록 밖 NPZ를 차단한다. normalization fallback도 별도로 차단한다. 실제 caller의 cache 상대경로와 SHA는 STARTED/RESULT에 기록하고, 분석 및 frozen source SHA는 [SOURCE_CAPTURE.json](../../gzip_extra_aux_20261016_v1/files/item_0284.json.gz)에 기록한다. 기존 production source는 바꾸지 않는다.

CUDA_VISIBLE_DEVICES=-1, OMP/MKL/OPENBLAS=2, 순차 실행, RSS 8GiB, capture 후 15분 wall, C+R 30GiB와 pending 1GiB, 추가 저장 1GiB 조건을 적용한다. 메모리·wall은 주기적으로 확인하며 위반 시 부분 출력을 보존한 중단 영수증을 남긴다. 공개 새 snapshot의 실제 추가 bytes도 종료 검산한다.

## 해석과 출력 보존

원단위 MSE/MAE/RMSE는 원 normalized prediction error에 frozen A60 channel scale을 곱해 계산한다. normalized primary score를 변경하지 않는다. 이질적 센서의 단위를 하나의 물리량으로 해석하지 않으며 channel별 오차를 함께 제공한다. PeMS의 단위는 5분 sample의 flow counts이며 시간당 교통량으로 바꾸지 않는다. legacy 역정규화 자료의 FP32·원 normalization 계보 한계는 남는다.

시간블록은 기존 `ceil(max(period,H)/H)` 규칙으로 오차를 보기 전에 정한다. 모든 유효한 exact-cohort 비교와 마지막 짧은 block을 보존하고, 전체 cohort 오차는 관측수 전체로 별도 재집계한다. 블록은 IID 표본으로 가정하지 않는다. confidence interval, bootstrap, 유의성 검정은 수행하지 않는다. 결과는 시간에 따른 기술적 변동을 보여주며 실험 개선·independent unseen 일반화의 증거가 아니다.

API 원출력은 수정하지 않고 private 원본과 SHA가 같은 새 public snapshot으로 복사한다. 20MiB를 넘는 파일이 있으면 원본을 보존하고 별도 lossless gzip과 실제 복원 SHA를 준비한다. 원 CSV의 반올림·행/채널/원점 삭제는 하지 않는다. 최종 처리 수·기존 재계산·신규·미실행·실패·실행 시간은 RESULT와 종료 검산을 기준으로 읽어야 한다.
