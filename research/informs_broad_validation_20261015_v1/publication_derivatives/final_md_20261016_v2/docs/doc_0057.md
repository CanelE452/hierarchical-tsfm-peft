# 공개 통계 기반 그림의 실제 재생성 검산

기존 공개용 reproduce.py를 별도 새 출력 위치에서 CPU로 실제 실행했다. MSE/MAE PNG와 원수치 CSV가 게시할 원본과 byte가 같았다. 공개 코드와 그룹 통계·metadata만 사용했고 모델·예측 배열·T·GPU 추론은 사용하지 않았다. 이 검사는 학습·성능·일반화 재현이 아니다.

[개별 SHA와 비교 범위](../../gzip_extra_aux_20261016_v1/files/item_0562.json.gz) · [게시할 그림](doc_0058.md)

채널 오차 CSV gzip도 실제 해제하며 계산한 SHA가 보존된 원 CSV와 같았다. SVG는 timestamp를 포함할 수 있어 이번 byte 동일 판정의 대상에 포함하지 않았다.
