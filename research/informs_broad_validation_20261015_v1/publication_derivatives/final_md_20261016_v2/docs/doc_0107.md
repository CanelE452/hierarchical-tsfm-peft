ROOT가 새 측정을 고를 때 CSV의 new_measurement_eligible_now=true만 현재 실행 가능한 후보로 사용한다. 이는 실제 V metadata 존재와 범위 선정만 뜻하며 artifact 실행 검증 통과를 뜻하지 않는다. NOT_EXECUTABLE_ABSENT_V 행은 측정 목록에 넣지 않는다. REUSE_EXACT_EXISTING_COST와 ALPHA 부모 참조 행은 새 측정 건수로 세지 않는다. ALPHA05는 실제 G+B 경로이지만 기본 최소 신규 timing 목록에서 제외한 선택 사항이며, ALPHA_FIT 비용으로 이미 측정했다고 바꾸어 쓰지 않는다.

stage1은 강한 기준선, 같은 endpoint의 quarter B0/B2, B4 quarter/C, PCA quarter, 직접 예측·AdaPTS, 전역 ALPHA_FIT, H/B0/Raw/Gpast·추가 정보/잔차/bias 대조를 표시한다. E3/E4의 quarter는 원리의 첫 비용 관찰이며, 전체 K 완료는 stage2가 필요하다. 같은 행이 여러 비교를 지원하면 CSV에 한 번만 저장하고 stages를 합쳤다.

stage2는 B0/B2 등록된 다섯 K, 고정 PCA/B4의 실제 등록 K, 추가 ALPHA_FIT K, E3 두 encoder의 세 K, E4 shared/posthoc/nested의 세 K를 포함한다. E4 독립 K 대조는 실제 저장한 부모 family를 SOURCE_CONTRACT에서 읽어 같은 B0/B2 행에 추가 태그로 연결했다. MAXK 모델의 저장 부모와 posthoc C 추론을 새 독립 학습 두 개로 세지 않는다.

초기 E1의 실험 schedule 0.25와 선택 epoch 0/0.25는 구분한다. E2 head의 calibration 학습 schedule은 부모 endpoint와 별개이며, 이 문서는 head까지 모두 0.25로 맞았다고 주장하지 않는다. 기존 cost9 중 이미 측정한 PeMS G A+M e3만 예외로 그대로 남겼다. 그 밖의 새 __e checkpoint는 포함하지 않았다.

## 원 MASTER의 요구와 해석

민감한 상담 문단을 제거한 [공개 MASTER](../../../plan/MASTER_PLAN_PUBLIC.md)를 연결한다. 원본 MASTER의 비민감 비용 문구만 줄번호·문장 SHA로 CURRENT_MANIFEST_BINDINGS.json에 대조했다. 원본 본문이나 민감 문단은 복사하지 않았다.

- 원본 L308: 매 K 실제 F streams, P/E/D/G 파라미터, full pipeline 시간·메모리.
- 원본 L399: 실제 K행을 F에 전달해야 하며 Kmax 후 자르기를 작은 K 비용으로 쓰지 않음.
- 원본 L410: 동일 총 학습 예산과 각 K 독립 모델의 총 학습 비용을 구분.
- 원본 L466–474: B1/B8, 물리 입력부터 CPU 반환까지의 전체 경로, loading 분리, fresh process, memory, Raw 네 row 설정, 병합 LoRA, warmup10/실측20/balanced, general/exclusive 범위 보존.
- 원본 L661: 등록 K grid의 실제 비용 곡선이 부족하면 K 커버리지는 미완료.
- 원본 L33,35–37: 12 GPU시간은 모든 K·충분 수렴의 완료 예상이 아님. 상한 내 원리별 최소 비교 우선, 미완료는 PARTIAL과 재개 목록으로 보고.

모든 seed·모든 epoch checkpoint·모든 alpha endpoint를 각각 full cost하라는 별도 명문은 없다. L270,274–277은 학습·선별 단계 규칙이다. 적법하게 동일 부모 경로로 해석한 ALPHA0/1은 부모 비용을 연결할 수 있다. route_catalog.py L199–207에서 alpha0/1만 부모 Route로 반환하고, ALPHA_FIT/ALPHA05는 실제 G+B로 구성한다. ALPHA_FIT 계수가 0이어도 F를 생략한 것으로 세지 않는다.

대표 K만 측정한 상태를 전체 K 비용 완료로 쓰면 안 된다. 모든 V 수치를 보존하더라도 미측정 비용은 별도 미완료다. 이 문서의 stage 구분은 요구를 삭제하는 것이 아니라 자원 내 우선순위다.

## 기존 PeMS 9개: 정확한 재사용

[기존 비용 완료 receipt](../../gzip_extra_aux_20261016_v1/files/item_0184.json.gz)는 36 block을 모두 완료했다. 이는 상세 method/scope/batch 48행과 다른 집계다. 현재 V manifest/model/archive SHA 9/9, 명시 fit receipt SHA 5/5를 다시 대조해 일치했다. deployment.py와 measure_costs.py의 현재 SHA도 당시 receipt와 같다. 구체적인 9개 actual run ID는 CSV의 REUSE_EXACT_EXISTING_COST와 JSON에 그대로 적었다.

재사용 범위는 같은 PeMS·primary·L512/H12/C170·실제 물리 입력/mask·A60 normalization·device/dtype·row 설정·정확한 artifact/source의 기존 관찰이다. 같은 frozen backbone SHA만으로 다른 dataset/fold/K/새 checkpoint에 이전하지 않는다. 새 balanced group은 공존 모델·순서가 달라 기존 group과 별도 scope다.

이 문서에서는 NPZ/PT/safetensors를 열거나 다시 hash하지 않았다. archive/model/artifact SHA는 현재 manifest·fit/calibration receipt에서 읽은 값을 해당 metadata 파일 SHA에 결박했다. 별도 실제 재채점·checkpoint replay·비용 trial 검산과 구분한다.
