# 고정 기준선 예외와 남은 학습 우선순위

[확인] [가족별 endpoint 집계](../../gzip_extra_aux_20261016_v1/files/item_0664.csv.gz)의 PCA_FIXED_BOLT 19개 영수증은 요청 목록에0.25가 있어도 고정 PCA의 optimizer0회·선택 epoch0인 경로다. Raw·PCA·current·seasonal·닫힌형 ridge를 신경망3epoch 부족으로 세면 안 된다. SUMMARY의 전체 BASE receipt129개 endpoint 집계는 보존하되, 학습 미충족 판정에는 이19개를 제외한다. 실제 학습되는 BASE receipt는 primary108개+secondary2개이며 primary의3epoch 요청 receipt는0개다. E2의3epoch head/control 영수증은 별도 종류이며 이를 E1/E3/E4 기본 모델의3epoch로 대체하지 않는다.

primary 가족별 최대 요청 endpoint는 B0/B2/DIRECT_G가1, B4/LORA/LAG_CAUSAL/LAG_BIDIR/DIRECT_B2/DIRECT_B4/ADAPTS가0.25다. 이 목록은 Robin 부록도 포함한 가족별 합계이며, 자료별 최소 범위가 채워졌다는 뜻이 아니다. E4 ordered 파일럿은 별도 ORDERED_PILOT_RECEIPT의 요청0.25로 확인했다. 독립K·공유K·고정PCA prefix 여러 출력을 별도 학습 횟수로 부풀리지 않는다.

[판단] 원리별 학습량 질문을 먼저 줄이려면 아직3epoch가 없는 학습 가족의 대표자료를 같은 대조 조건에서 보강하고, 그 다음 등록 grid12/secondary10·추가seed/subset을 자원에 따라 처리할 수 있다. CPU F0 직접 예측기3epoch 보강도 실행조건을 새 ID로 명시하고 기존 GPU 결과와 분리한다. 실제 확보된 device·학습비용·remaining wall에 따라 ROOT가 순서를 정해야 하며 이번 감사는 새 학습을 실행하지 않았다.

대표 한 자료의 보강으로 다른 자료·K의 최소 학습 요구가 자동 면제되지는 않는다. 문언과 보수적 해석의 구분은 [별도 설명](../../../diagnostics/requirement_coverage_refresh_20261016T003622/MINIMUM_INTERPRETATION_KO.md)에 있다. 최종 선언은 전체최소학습 미완료를 명시한 PARTIAL이어야 한다.
