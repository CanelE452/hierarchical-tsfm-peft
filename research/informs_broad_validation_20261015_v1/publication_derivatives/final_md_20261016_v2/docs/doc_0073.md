# RawSmall + 동일 deep G 4개: 공개 재생성 recipe

실제로 실행한 private driver의 SHA는 `7bb467cbe577e5c7e113c82274e66386132382d7d02843d3cf532be489f43d99`다. [원 계획](../../gzip_extra_aux_20261016_v1/files/item_0609.json.gz), [실제 실행](../../gzip_extra_aux_20261016_v1/files/item_0604.json.gz), [종료 검토](../../gzip_extra_aux_20261016_v1/files/item_0418.json.gz)를 보존한다. 실제 실행 버전은 private 경로 상수를 사용했다. 아래는 공개한 기존 core API로 같은 과학 조건을 재생성하는 recipe이며, 실제 private script의 byte 동일 사본이나 실행 검증된 portable derivative라고 주장하지 않는다.

registry의 `Private ROOT-reviewed oneoff` 설명만으로 외부 재현이 충분하지 않아 이 구체 recipe를 남긴다. 새 실행기/알고리즘을 만들거나 frozen source를 바꾸지 않았다. private driver의 환경·경로/실행기 변경을 실제 검증한 것처럼 쓰지 않기 위해, 단순 경로 치환 사본 대신 원 API와 봉인 spec을 명시한다.

## 필요한 자산과 출력 보존

`INFORMS_PUBLIC_ROOT`, `INFORMS_CACHE_ROOT`, `INFORMS_ASSET_ROOT`는 재현자의 로컬 public campaign, private campaign cache, 원 asset repository를 가리킨다. 개인 절대경로를 코드에 넣지 않는다. 원 데이터·foundation·선택 checkpoint·전체 NPZ는 main에 배포하지 않았으므로 원 계약대로 직접 확보/재생성해야 한다. 공개 manifest의 SHA는 그 자산의 identity를 확인하는 정보이며 그 bytes를 제공한다는 뜻이 아니다.

source18/33, DATA_CONTRACT, 모델 Small의 기존 pinned revision, A50/A_stop/A60 및 main4의 원 채널·L512/H48(단 PeMS H12)을 유지한다. raw baseline은 BASE 없는 `RAW_BOLT_SMALL` 등록 행이고, 캐시 family는 `RAW / NO_TRAINING_FIXED_BASELINE`이다. G는 [SPECS_AND_BINDINGS.json](../../gzip_extra_aux_20261016_v1/files/item_0612.json.gz)의 정확한 run/artifact/receipt/source SHA와 NO_FOUNDATION/A-only role를 사용한다. CPU fresh G나 A+M G 또는 다른 endpoint로 자동 대체하지 않는다.

기존 원 4개 결과가 있는 checkout에서는 같은 ID로 다시 쓰지 않는다. ROOT가 새 replica ID `original_run_id + '__reproduction_' + <고정 tag>` 네 개를 명시적으로 사전등록하고 원 비교 조건을 보존한다. 원 registry와 원 결과를 삭제·reset하지 않는다. replica의 run_id 외 spec은 원문과 같아야 한다. 다른 G를 쓰면 이 recipe의 재현이 아닌 별도 조건이다.

## 정확한 API 순서

아래 코드는 ROOT가 자원과 새 4개 registry 행을 확인한 뒤 사용할 실행 순서다. 이 문서 작성에서는 이 코드를 실행하지 않았다. metadata만 확인할 때 runtime import·GPU lease·load_task부터 실행하지 않는다. 단순 코드 블록을 무조건 실행하는 shell 지시가 아니다.

```python
import copy, importlib, json, os, sys
from pathlib import Path

R = Path(os.environ['INFORMS_PUBLIC_ROOT']).resolve()
C = Path(os.environ['INFORMS_CACHE_ROOT']).resolve()
A = Path(os.environ['INFORMS_ASSET_ROOT']).resolve()
sys.path.insert(0, str(R))
plan = json.loads((R / 'diagnostics/raw_deep_g_control_ready_1792090190000000000_v2/PLAN.json').read_text(encoding='utf-8'))
bridge = importlib.import_module('extended_parent_e2')  # stdlib-only helper
bridge.require_unlocked(R)
for name, expected in plan['source_pins'].items():
    assert bridge.file_sha(R / name) == expected
bridge._storage(R, C)  # disjoint roots, combined 30 GiB, >=1 GiB headroom

# Before this block ROOT checks previous owners are terminal and preregisters
# the four explicit replica IDs with the same scientific registry conditions.
resources, reg = bridge._load_resources()
reg.require_pre_selection(R, 'explicit RawSmall/deep-G replica')
replica_tag = os.environ['INFORMS_REPRODUCTION_TAG']
assert replica_tag and replica_tag.replace('_', '').isalnum()
specs = []
for route in plan['routes']:
    spec = copy.deepcopy(route['spec'])
    spec['run_id'] += '__reproduction_' + replica_tag
    for key in spec:
        assert key == 'run_id' or spec[key] == route['spec'][key]
    assert not (C / 'combinations' / spec['run_id']).exists()
    assert not (R / 'combinations' / spec['run_id']).exists()
    assert not (R / 'predictions' / spec['run_id']).exists()
    specs.append((route, spec))

with resources.GPUReservation(C, total_gpu_seconds=43200,
        reserve_seconds=6000, wall_deadline=1792223150,
        purpose='training', kind='explicit_RawSmall_deepG_replica') as lease:
    runtime = bridge._load_runtime(R, C, A)
    for route, spec in specs:
        item = route['item']; g = item['parents']['DIRECT_G']
        # Re-check source/receipt/artifact bytes and row identity against the
        # published bindings before model loading, using the existing guards.
        _, rows = bridge._registry(R)
        rows = {row['experiment_id']: row for row in rows}
        asset = json.loads((R / 'DATA_CONTRACT.json').read_text())['assets'][route['dataset']]
        actual_g = bridge._parent(rows[g['run_id']], R, asset, 'DIRECT_G', 0)
        for key in g:
            if key != 'registry_template': assert actual_g[key] == g[key]
        assert bridge.file_sha(C / g['artifact_cache_relative_path']) == g['artifact_sha256']
        bridge._guard(R, C, {k: plan['source_pins'][k] for k in bridge.CORE_FILES}, lease, reg)
        task = runtime.data.load_task(route['dataset'])
        task = dict(task, split_ranges=runtime.data.split_ranges(task, 'primary'))
        assert task['data_sha256'] == item['data_sha']
        assert task['split_ranges']['A_stop'][1] == item['a60_fit_end']
        mean, std, _ = runtime.data.fit_statistics(task, item['a60_fit_end'])
        pool = runtime.postfit.ParentPool(task, fold='primary', deadline=lease.deadline-5)
        try:
            bm = pool.predict(spec['parent_run_id'], 'M_cal', True)
            bv = pool.predict(spec['parent_run_id'], 'V_select', False)
            gm = pool.predict(spec['g_run_id'], 'M_cal', True)
            gv = pool.predict(spec['g_run_id'], 'V_select', False)
            for value, split, dense in [(bm, 'M_cal', True), (bv, 'V_select', False)]:
                meta = value['metadata']; pin = route['raw_predictions'][split]['metadata']
                for key in pin:
                    if key != 'reused_prediction_cache': assert meta[key] == pin[key]
                assert meta['family'] == 'RAW'
                assert meta['training_source_sha'] == 'NO_TRAINING_FIXED_BASELINE'
            bridge._cache_metadata(gm, g, 'M_cal', True, item)
            bridge._cache_metadata(gv, g, 'V_select', False, item)
            runtime.combination.validate_parent_caches(task, bm, bv, gm, gv, mean, std)
            refs = runtime.audit.prepare_combination_reference(spec['run_id'],
                task, bv, gv, mean, std, C, R, spec=spec)
            bridge._guard(R, C, {k: plan['source_pins'][k] for k in bridge.CORE_FILES}, lease, reg)
            receipt = runtime.combination.fit_combination(spec, task,
                bm, bv, gm, gv, mean, std, C, R/'combinations', lease.deadline-5)
            if receipt['execution_status'] == 'COMPLETE_VALID':
                runtime.audit.wrap_combination_output(receipt, refs, C, R)
            # Preserve partial receipt/output. ROOT records the exact status;
            # never wrap incomplete output or call T/selection here.
        finally:
            pool.close()
```

원 worker는 경로별 오류를 독립적으로 보존하고 자원 종료 시 나머지 큐를 deferred로 남겼다. 위 블록은 과학 API 순서를 보이기 위한 recipe이므로 ROOT가 실제로 실행할 때 동일한 경로별 오류·source33/registry identity 전후 검산·STARTED/PID/exit/closed lease 장부를 갖춘 기존 실행 환경에 넣어야 한다. 원 driver의 전체 감독기·오류보존 코드까지 공개 실행 검증했다고 해석하지 않는다. GPU 비용·학습결과가 다른 하드웨어/라이브러리에서도 byte 동일하다는 보장은 없다.

원 실제 네 H는 conditional hidden32, seed92601, CUDA, lr0.001, effective16/micro4, 0.25/1/3 epoch이며 M_dense 적합/V_strideH checkpoint 선택이다. epoch3 완료와 선택 지점/미수렴은 별개다. 학습 F0는 cached 부모를 쓰는 H fit만의 사실이고 실제 배포 Raw의 B×C 비용을 포함하지 않는다. 재생성 후 새 selected artifact/V를 독립 FP64 감사와 실제 checkpoint replay로 검증해야 한다. 이 문서의 공개만으로 그 재실행 검증을 마쳤다고 쓰지 않는다.
