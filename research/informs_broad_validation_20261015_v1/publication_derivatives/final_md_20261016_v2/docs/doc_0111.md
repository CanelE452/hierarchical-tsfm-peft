P1은 **필수 K 보완**이다. 원리 최소만 끝났다고 전체 K 비용 완료로 바꾸지 않는다. B0/B2 최초 endpoint 40개, B4 quarter/C 8개, native 대조 12개, E3 Beijing/PeMS 두 방향×quarter/half/C 12개, E4 Beijing/Electricity shared/posthoc/nested 세 K 18개를 원 요구대로 유지했다. E4와 같은 family(B0)의 독립 K 6개는 B0 grid 행에 태그를 합쳤으며 새 실험·새 비용 행으로 중복 세지 않았다.

나머지 ALPHA_FIT K, 초기 부모 H/B0/B2/Hpast, 추가 PCA K, LR followup, A+M LoRA, 다른 자료 E3·subset 등은 optional 목록에 보존했다. 음성 결과를 이유로 삭제하지 않았으며 지금 필수 최소 완료로 세지 않는다. 비용·정확도 선택은 T를 보기 전에 수행하고, 실제 미측정 비용에 추정 우위를 부여하지 않는다.

## 새 E2와 planned 경계

현재 stdlib-only extended_parent_e2.build_plan의 actual metadata 결과는 Beijing/Jena/Electricity의 공통 요청 endpoint1 세 부모만 준비되어 **12 fits/21 registry outputs**가 exact ID로 고정된다. 해당 새 head fit·V·등록은 아직 실행되지 않아 지금 비용 CLI에 넣지 않는다. exact spec에는 실제 B0/B2/G ID와 artifact/source-contract SHA가 들어 있다.

PeMS는 현재 공통 .25만 있어 기존 E2 유지 상태다. 목표 추가 4 fits/7 outputs의 부모는 다음 실제 계획 ID다.

```text

primary_pems08_E1_B0_k43_s92601__e1
primary_pems08_E1_B2_k43_s92601__e1
```

새 suffix는 세 부모의 실제 artifact/source SHA를 포함한다. B0/B2 e1 COMPLETE artifact가 아직 없어 네 head의 exact ID는 **null/미확정**으로 두었다. 그럴듯한 suffix를 만들어 실행하지 않는다. P0의 미확정 네 logical slot은 측정 후보가 아니다. ROOT가 실제 부모 완료 뒤 계획을 다시 생성해야 총 목표16 fits/28 outputs의 나머지가 결박된다.

## 정확 비용 재사용과 alpha 참조

PeMS 기존 비용9는 별도 목록이며 현재 V manifest/model/archive/data/scaler SHA 및 해당 fit receipt, 당시 deployment/measure source가 일치함을 metadata로 다시 대조했다. 실제 artifact/NPZ bytes를 이 작업에서 다시 읽은 재검산은 아니다. 정확한 9 ID와 각 check는 JSON의 existing_exact_cost_reuse에 있다. dataset/fold/K/checkpoint/장치/row 조건을 바꾼 경로로 비용을 이전하지 않는다. 새 balanced group은 공존 모델·순서가 달라 과거 group과 별도 범위다.

ALPHA0/1은 private spec의 **명시적 단일 부모**로만 연결한다. ALPHA05는 단일 부모 alias가 아니라 두 부모 G+B를 계산하는 경로다. 최소 측정에서는 같은 ALPHA_FIT graph와 두 parent ID를 논리 참조하되 exact 실측값으로 복사하지 않는다. 별도 ALPHA05 실측을 주장하려면 optional 실제 timing이 필요하다. fitted alpha가 0이어도 F 비용을 생략하지 않는다. alpha family의 네 outputs는 fit 한 번이며 새 E2 28 rows를 28 fits라고 세지 않는다.

## portable route와 알려진 제한

CSV의 `SOURCE_BRANCH_AND_METADATA_AVAILABLE_RUNTIME_NOT_EXECUTED`는 실제 route_catalog 소스의 지원 branch와 JSON identity가 있다는 뜻이다. route builder는 checkpoint·NPZ를 읽으므로 이번에는 import하거나 호출하지 않았다. 실제 portability PASS, artifact hash 재검사, 모델 재추론·timing PASS를 뜻하지 않는다. manifest/receipt/부모가 없으면 planned/deferred로 남긴다. 구형 source6와 현재 source6의 차이도 exact old/current SHA로 기록했고 동일 모델이라고 추정하지 않는다.

secondary plain RAW 두 ID는 알려진 unsupported 상태를 보존했다. registry family가 `RAW`이면 route_catalog의 `RAW_BOLT_*` branch에 들어가지 않고 `_base`로 가는데 해당 fixed baseline의 BASE fit receipt가 없다. 자동 이름 변경이나 primary 경로 전용으로 우회하지 않았다. 이 제한은 main4 primary 필수 목록과 별도이며 secondary RAW 비용을 완료로 표시하면 안 된다.

## ROOT 실행 인계

private `mandatory_cost_priority_1792078770094934100/PLAN.json`에 dataset별 P0/P1/optional exact IDs, 재사용9, parent-ready E2 exact specs와 PeMS 미확정 slots, CLI argument vector를 저장했다. 실제 source의 CLI는 `python cost_campaign.py --dataset <ds> --run-id <id>` 반복과 `--reserve-final-seconds 3600`이다. 기본 Raw full/32/8/4, B1/B8, warmup10/timed20/stage20/fresh/balanced 계약을 유지한다. `--skip-raw-variants`로 첫 조건의 필수 Raw 비교를 생략하지 않는다.

cost CLI는 자체 central lease를 생성하므로 outer GPU lease 안에서 중첩 실행하지 않는다. 누적 전체43200초에서 final reserve3600초를 남기는 ceiling39600초이며 명령마다 새39600초를 주는 것이 아니다. CLI에는 old exact cost9만 fresh에서 skip하는 옵션이 없다. 새 ID만 넘긴 실행의 balanced group은 옛9 group과 다르게 보고하고, 모든 old/new를 같은 balanced scope에 넣으려면 ROOT가 실제 추가 측정 범위를 명시해야 한다.

remaining breadth→new E2 후에는 새·바뀐 immutable manifest/reference/receipt/private JSON spec을 다시 SHA 결박하고, registry의 과학 identity와 실제 V 존재를 대조한다. pending12나 새 E2를 생성·측정했다고 가정하지 않는다. 학습 종료·GPU 인계·자원 확인 후 실제 실행하며, 한도가 닿으면 정확한 미실행 조건을 남긴다. 이 문서는 T 잠금이나 최종 전체 비용 완료 영수증이 아니다.
