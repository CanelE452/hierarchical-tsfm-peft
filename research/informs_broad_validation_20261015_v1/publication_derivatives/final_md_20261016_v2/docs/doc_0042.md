# 기존71 V 채널 오차 표의 무손실 공개 파생

[실제 복원·SHA·제외/대체 경로](../../gzip_extra_aux_20261016_v1/files/item_0479.json.gz) · [원 파일 링크 호출자](../../../diagnostics/lossless_pattern_archive_20261016T005929/LINK_CALLERS.csv)

[확인] 원 CSV와 README를 포함한 기존5파일은 byte 불변이다. 새 gzip을 private 파일로 실제 해제해 원 byte 수와 SHA가 같음을 확인했다. 원 README 본문·숫자의 byte를 유지하고 CSV 링크 대상만 gzip으로 바꾼 별도 공개 안내에 복원법·용량 이유를 덧붙였다. 공개 계약에서 허용한 집계 채널 SSE/SAE/count이며 새 점수 계산이나 원시 센서 배열 접근이 아니다. 현재 candidate FILE_LIST와 PUBLIC_EXCLUSIONS는 편집하지 않았다. 원 CSV·원 README의 최종 제외 및 대체3파일 포함은 ROOT가 수행한다. CSV는 단일파일20MiB 이하이며 전체 payload 용량 절감이 목적이다. 원 README 자체 외 다른 후보/현재 R Markdown 호출자는 발견하지 않았다. 초기 text-mode 줄바꿈 비교 오류는 byte 비교로 확인했으며 원본을 수정하지 않았다.
