# 실제 52쌍 보조표의 판단 범위

T 관찰 뒤 보고용으로 고정한 52쌍을 모두 집계했다. 방법·역할·체크포인트는 기존 T 이전 선택 잠금을 사용했고 이번 표에서 다시 고르지 않았다. `RESULT.json`은 requested 52 / verified 52 / failures 0이다. 전체 52행, 시간 block 2,990행, horizon 156행, 패턴 그룹 624행을 보존했다. 원 API 14쌍과 겹칠 수 있으므로 독립 비교 수를 합산하지 않는다.

차이는 모두 **왼쪽 − 오른쪽**이며 음수이면 왼쪽 오차가 작다. 원수치는 [전체 비교](../../gzip_extra_aux_20261016_v2/files/item_0009.csv.gz), [구간별 비교](../../gzip_extra_aux_20261016_v2/files/item_0007.csv.gz), [시간 block](../../gzip_extra_aux_20261016_v2/files/item_0014.csv.gz), [A-only 채널 그룹](../../gzip_extra_aux_20261016_v2/files/item_0011.csv.gz)에 전 정밀도로 남아 있다. [기술 요약](../../gzip_extra_aux_20261016_v2/files/item_0006.csv.gz)은 전체 52쌍을 유지한 채 부호별 block 수와 horizon 차이를 붙인 파생 표다. 부호는 저장된 FP64 값의 정확한 0과 비교했으며 새 수치 허용오차나 유의성 기준을 만들지 않았다.

## 같은 G에 무엇을 더했는가

- Beijing: H_B2 MSE `0.6466421534061838`, 같은 G `0.6193076276262796`, 차이 `+0.02733452577990416`이다. Hpast는 `0.6053225002274458`로 G보다 `-0.013985127398833829` 낮다. H_B2는 Hpast보다 `+0.04131965317873799`, H_B0보다 `+0.005159339651261096`, AlphaFit보다 `+0.0233948285036066` 높다. 현재 조건에서 외부 B2 예측을 조건으로 주는 이점은 확인되지 않았고, 같은 용량의 과거 대조가 더 낫다.
- Jena: H_B0·H_B2·Hpast·G의 MSE는 `1.0507676762911233`으로 같다. 신경 head들은 실제 3 epoch·386 update를 수행했지만 이 세 조건의 선택 checkpoint는 update 0이다. 따라서 학습을 실행하지 않았다고 표현하거나, 시간 표현의 유효성을 확인했다고 표현하지 않는다. RawH는 update 129가 선택됐으며 plain RawSmall보다 MSE가 `-0.24372509324217018` 낮다. H_B2는 AlphaFit보다 `+0.06592515792854975`, LoRA보다 `+0.056949325224327725` 높다.
- Electricity: H_B2 MSE `0.12385566514128525`, G `0.13953899537018527`, 차이 `-0.015683330228900023`이다. Hpast보다도 `-0.00363248817263833` 낮지만 H_B0와는 정확히 같다. LoRA보다 `+0.02045025356032722` 높고, RawH는 plain RawSmall보다 `+0.00913111735803126` 높다. G 대비 보정 이득을 raw/강한 대조 대비 우위나 B2 고유 효과로 확장할 근거는 부족하다.
- PeMS08: H_B2 MSE `0.07450994657386961`, G `0.08612517213650793`, 차이 `-0.011615225562638321`이다. Hpast보다 `-0.0046821991780111585`, H_B0보다 `-0.0003889884408271092`, AlphaFit보다 `-0.0032888407981464802` 낮다. LoRA `0.07468222512162342`와의 차이는 `-0.000172278547753804`로 작다. 이 마지막 차이만으로 안정적인 우위나 일반화된 방법론 완성을 주장하지 않는다.

같은 head 용량·LR·학습 예산과 같은 선택 update는 다르다. [ROLE_RECIPES](../../gzip_extra_aux_20261016_v2/files/item_0013.csv.gz)에 이를 분리했다. Beijing은 총 388 update에서 Hpast 33, H_B0/H_B2/RawH 130을 선택했다. Jena는 총 386에서 H_B0/H_B2/Hpast 0, RawH 129를 선택했다. Electricity와 PeMS08은 각각 총 448/334 update가 선택됐다. AlphaFit은 closed-form이며 신경 head와 optimizer 예산이 같은 대조가 아니다. LoRA도 별도의 강한 대조다. 부모 G/B의 학습 노출 차이는 head 용량 일치만으로 없어지지 않는다.

## 시간·horizon·패턴을 나누면 무엇이 남는가

PeMS08의 H_B2−LoRA는 전체 MSE가 작지만 13개 시간 block 중 왼쪽이 작은 block은 5개, 큰 block은 8개다. 가까운 구간 차이는 `+0.0012387292125922902`, 중간 `+0.0003473128213435231`, 먼 구간 `-0.0011375781124755154`다. 관측이 있는 패턴 그룹도 8개 중 4개씩 방향이 갈린다. 전체 이득은 시간과 horizon 전반에 고르게 나타나는 이득으로 해석할 수 없다. block 수를 동일 가중 평균하거나 독립 표본으로 바꾸지 않았고, 전체 지표는 원 관측 count에 따른 채널 macro를 별도로 재집계했다.

PeMS08의 H_B2−H_B0도 전체 차이는 음수지만 가까운 구간은 `+0.00010810209250407843`이다. A-only delayed-crosschannel high 그룹은 `-0.0008978265423762329`, low 그룹은 `+0.00011984966072201445`다. 이 결과는 시간 의존성이 있는 채널에서 이득이 날 수 있다는 가설과 일관된 **사후 관찰**이다. 해당 그룹은 상관 기반 분류이고 다른 seasonality·intermittency 그룹과 겹치므로 time-delay 인과 효과나 학습된 graph의 필요성을 입증하지 않는다. 이 T 결과를 이용해 채널이나 방법을 다시 선택하지 않는다.

Beijing의 H_B2−G는 87 block 중 59개에서 오차가 더 크고, 가까움·중간·먼 구간이 모두 양수이며 먼 구간 차이가 `+0.05050022165137775`로 크다. 관측이 있는 8개 패턴 그룹에서도 모두 더 크다. 반면 Hpast−G는 모든 horizon과 관측 패턴 그룹에서 음수지만 87 block 중 40개는 양수다. 따라서 전체 이득과 모든 시간 구간의 이득은 구분해야 한다.

Jena RawH−RawSmall은 전체와 중간·먼 구간에서 개선되지만 가까운 구간은 `+0.03596681298700804`로 악화한다. Beijing RawH−RawSmall은 MSE가 `-0.00899408731894366` 낮은 반면 MAE는 `+0.01707545762615635` 높다. MSE 이득을 모든 오차 지표나 모든 horizon의 개선으로 바꾸어 말하지 않는다.

이 분해는 이미 생성된 공개 SSE/SAE/count를 다시 묶은 결과다. 원 target 값이나 예측 배열을 다시 독립 재채점하지 않았다. target/mask/channel/origin descriptor와 관측 count 일치를 확인했고, A-only 패턴 snapshot·metadata block 경계를 고정했다. 단일 seed·cutoff의 기술 분석이며 CI·유의성·block 독립성·추가 일반화를 주장하지 않는다. 기존 미달 학습·시간 전이·독립 seed 검증을 이 표의 완성으로 대체하지 않는다.
