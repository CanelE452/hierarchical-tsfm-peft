새 공개 execution_batches/final_cost_dispatch_<ns>와 private final_execution/final_cost_dispatch_<ns>를 만든다. 원 전체 group 계획, 각 admission·group 결과·exitcode·실제 cost output 경로·남은 조건을 보존한다. 최종 파일은 DISPATCH_RECEIPT.json이다. exit0만으로 완료하지 않고 실제 COST_CAMPAIGN_RECEIPT, candidate/condition plan, 각 execution exit, COMPLETE_PROTOCOL, B1/B8, trial-file SHA, accuracy binding을 확인한다. 이는 raw trial 재채점·타이머 재실행 또는 wholeaudit를 대신하지 않는다.
