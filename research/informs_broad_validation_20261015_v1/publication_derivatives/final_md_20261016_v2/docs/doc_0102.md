# 로컬 보존 자료의 공개 제외

원본과 실패 증거는 로컬에 보존한다. 아래 두 경로와 후술한 추가 제외를 최종 공개 파일 목록에서 제거한다. `--file-list`가 있으면 `--exclude-prefix`가 적용되지 않으므로 `PAYLOAD_FILES.txt` 자체를 필터링하고 그 명시 목록을 검사한다.

```text
diagnostics/initialization_anchor_1792059651372799700
execution_batches/cpu_V_checkpoint_replay_1792060139101125900.json
```

첫 진단은 FP32에서 이미 수행된 뺄셈을 FP64 잔차라고 표기한 초안이다. 실제 순수 FP64 계산과 입력 58개 SHA 재확인을 담은 [보정 진단](doc_0041.md)을 공개한다. 학습이나 기존 예측을 바꾼 수선이 아니다.

두 번째는 아직 V 예측이 없던 두 G 경로의 파일 부재 예외에 로컬 절대경로가 포함된 실행 기록이다. 원본 SHA와 성공·실패 상태를 유지하고 예외 문자열만 공개용 사유로 바꾼 [재추론 기록](../../gzip_extra_aux_20261016_v1/files/item_0701.json.gz)을 공개한다. Electricity G 1개와 단순 기준선 9개의 실제 CPU 재추론은 PASS이며, Beijing·PeMS G 2개는 이 실행 시점에 V manifest가 없어 미실행이다. 후속 GPU 재추론과 전체 검증 범위는 별도 기록으로 판단한다.

원문 상담 문단이 포함된 MASTER와 잘못된 초기 보고서 등 기존 기본 제외는 [게시 검사기](../../../publication_check.py)에 고정되어 있다. 제외는 실패를 성공으로 바꾸거나 숫자를 숨기는 수단이 아니다. 유효한 실패 상태·원인·수선·미실행 범위는 공개 보고서에 남긴다.


## 원문 보존과 공개용 파생 문서

아래4파일도 원문을 로컬 보존하고 최종 파일 목록에서 제외한다.

```text
SOURCE_PATCH_CONTROL_LR_METADATA.json
source_snapshots/CONTROL_LR_METADATA_ROOT_PYTEST_INCIDENT.json
source_snapshots/AUDIT_PROTOCOL_KO_before_legacy_namespace_675bcf808bd4.md
source_snapshots/COST_PROTOCOL_KO_before_cost_final_reserve_3100c3f435e3.md
```

첫2파일의 로컬 절대경로만 가린 [후처리 수정 증빙](../../../SOURCE_PATCH_CONTROL_LR_METADATA_PUBLIC.json)과 [실제 사고·복구 요약](doc_0019.md)을 공개한다. 오류·GPU 실행·과거 Labour 전체 자료 접근·결과 복구 사실은 숨기지 않는다. 원 명령의 원문과 before·after byte는 private에 보존한다.

과거 규약2개는 원문 SHA를 기록한 [감사 규약 사본](../../../source_snapshots/AUDIT_PROTOCOL_KO_before_legacy_namespace_675bcf808bd4_PUBLIC.md)과 [비용 규약 사본](../../../source_snapshots/COST_PROTOCOL_KO_before_cost_final_reserve_3100c3f435e3_PUBLIC.md)을 공개한다. 하위 폴더 복사로 깨진4개 링크의 기준만 상위 폴더로 바꾸었다. 파생 관계와 SHA는 [문서 파생 기록](../../../PUBLIC_DOCUMENT_DERIVATIONS.json)에 있다. 최종 전체 통계는 별도 pack·복원 색인으로 연결하며 중간 projection README를 최종 색인으로 쓰지 않는다.

## Robin 재개 명령 수정의 공개용 사본

`SOURCE_PATCH_REPORT_ROBIN_RESUME.json`은 실제 Python 실행 파일의 로컬 절대경로가 있어 원형을 로컬에 보존하고 공개 목록에서 제외한다. [공개 수정 증빙](../../../SOURCE_PATCH_REPORT_ROBIN_RESUME_PUBLIC.json)은 `/verification/python`의 asset root만 `<ASSET_ROOT>`로 치환했다. 그 한 필드를 원래 값으로 되돌리면 원 JSON과 모든 필드가 같음을 대조했다. 원문 SHA256은 `cf9fce1ff494a50e525ae6c9d8d3668771a147a2d996596165e4392c82579ba7`이며 사본에 원문 SHA·변경 JSON pointer·보존 범위를 기록했다. 학습·추론·검사 결과나 source SHA를 바꾼 처리가 아니다.

## E0 학습 영수증의 로컬 경로

`legacy_e0/fits/*.json`의 원본은 각각 로컬 절대경로 7개를 포함하므로 공개 파일 목록에서 제외한다. 수치 검산과 내부 source binding에는 보존된 원본을 사용한다. 공개용 사본은 별도 `publication_derivatives/legacy_e0/fits/`에 두며, 원본 상대경로·SHA·변경 JSON pointer를 함께 기록한다. 원본을 읽는 glob에 사본이 섞여 학습 건수가 두 번 집계되지 않도록 경로를 분리했다.

첫 [8개 영수증의 실제 파생·대조 결과](doc_0108.md)는 경로 필드 외 모든 값이 같고, 원래 경로를 되돌린 JSON이 원본과 같음을 확인했다. [해당 10개 파일과 9개 링크의 공개 검사](../../gzip_extra_aux_20261016_v1/files/item_0477.json.gz)도 통과했다. 이 기록은 작성 시점의 범위이며, 이후 추가 영수증을 포함한 최종 게시 검사를 대신하지 않는다. 실행·실패·수렴 상태와 체크포인트 해시는 변경하지 않는다.

E0 연장 구간의 자연 종료 후 [완결 영수증 9개 전체를 다시 대조한 목록](doc_0109.md)을 추가했다. 기존 사본 8개는 byte가 같음을 확인해 재사용했고 신규 사본 1개를 만들었다. 예산 중단 1개와 미시작 18개를 완료로 바꾼 처리가 아니다.

## 큰 채널 오차 표의 무손실 공개

다음 두 원 파일은 로컬에 보존하고 최종 공개 목록에서 제외한다.

```text
patterns/snapshot_20261015T093749Z_1792057069715991800/evaluation_20261015T145939Z_1792076379333866900/CHANNEL_ERRORS.csv
patterns/snapshot_20261015T093749Z_1792057069715991800/evaluation_20261015T145939Z_1792076379333866900/README_KO.md
```

CSV는 21,299,939 bytes로 공개 파일당 20MiB 상한을 넘는다. [공개용 안내와 전체 CSV의 gzip](doc_0118.md)을 사용한다. gzip은 1,875,979 bytes이며 실제로 풀어 원 CSV byte SHA가 같음을 확인했다. 수치 반올림이나 행 삭제는 하지 않았다. 원 API README는 공개하지 않는 CSV를 직접 링크하므로 보존된 원문과 별도로 만든 공개 안내를 연결한다.


## 기존 71 V 표의 무손실 용량 절감

다음 원본 두 개도 로컬 보존하고 최종 명시 게시 목록에서 제외한다.

```text
patterns/snapshot_20261015T093749Z_1792057069715991800/evaluation_20261015T104217Z_1792060937381529800/CHANNEL_ERRORS.csv
patterns/snapshot_20261015T093749Z_1792057069715991800/evaluation_20261015T104217Z_1792060937381529800/README_KO.md
```

[공개용 안내와 전체 표 gzip](doc_0094.md)을 포함한다. 원 표 11,185,185 bytes를 gzip 1,004,672 bytes로 보존해 숫자·행·정밀도를 바꾸지 않고 CSV 기준 10,180,513 bytes를 절감한다. [실제 private 파일 복원 검산](doc_0042.md)과 [ROOT의 별도 해제·원본 SHA 대조](../../../diagnostics/lossless_pattern_archive_20261016T005929/ROOT_ROUNDTRIP_CHECK.json)가 통과했다. 원 API 안내와 나머지 기존 5파일은 그대로 보존한다. 위 제외와 대체 포함은 최종 FILE_LIST에 실제 적용해야 하며 이 문서 작성 자체는 게시 완료가 아니다.
