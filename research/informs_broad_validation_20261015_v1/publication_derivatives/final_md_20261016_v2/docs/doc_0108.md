# 기존 E0 학습 기록의 공개용 경로 파생 사본

완결 endpoint 영수증에 포함된 로컬 절대경로 7개만 placeholder로 바꾸었다. 원본 byte와 실패·수렴 상태는 로컬에 보존한다. 각 공개 사본은 원본 상대경로·SHA·변경 JSON pointer를 포함한다. 원래 경로를 private에서 되돌렸을 때 원 JSON과 같고, 나머지 모든 scalar/list/dict 필드가 같음을 실제 대조했다.

이 작업은 학습·체크포인트 추론·B 재채점·수렴 검증을 실행한 것이 아니다. 작성 시점에 존재하는 endpoint만 포함하며 이후 추가 endpoint는 후속 목록에 포함한다.
