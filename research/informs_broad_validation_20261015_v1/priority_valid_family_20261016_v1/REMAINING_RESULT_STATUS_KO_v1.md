# 남은 두 family 조건의 실제 완료 상태

이번 범위의 Jena AdaPTS 원리 이식과 Beijing B4는 실제 학습, 선택 체크포인트의 full-V FP64 재채점, CPU6 재추론, CPU2 단독 B1/B8 전체 비용 측정, 독립 검산, MD·CSV·그림 생성까지 완료했다. 전체 MASTER 실험은 미완료이며 B2를 주 후보로 유지한다. 아래 수치는 반복 개발 V의 한 seed 결과로, 독립 일반화 검증이나 수렴 입증을 뜻하지 않는다.

## 지금 판단할 수 있는 것

- Jena C=21, K=6, L=512, H=48, V=43, seed=92601에서 AdaPTS 원리 이식의 정규화 MSE는 **0.7368189848**, 기존 B2는 **0.6834428964**였다. 이번 이식은 개선하지 못했다. LoRA R=8의 **0.5639229417**보다도 컸다. AdaPTS 원리 이식은 pointwise affine LinearPort이며 원 논문의 전체 재현이나 인코더 하나만 바꾼 통제 비교가 아니다.
- Beijing C=K=11의 B4 MSE는 **0.7651871786**, B2는 **0.7800566838**로 약 **1.91%** 작았다. B8 전체 추론 시간은 **0.5948873500초/배치**, B2는 **0.5728798499초/배치**로 약 **3.84%** 늘었다. K=C이므로 이 조건에서 채널 압축 효과를 주장할 수 없다.
- 두 조건은 제한된 학습량과 반복 사용한 개발 V에 의존한다. 학습 충분성·다른 seed·다른 데이터 일반화는 미확정이다. 이 묶음만으로 Bolt의 필요성이나 새 방법의 우월성을 주장하지 않는다.

## 실행·검증 범위

두 신규 fit과 기존에 완료한 동조건 비교값을 구분했다. 저장된 예측의 FP64 재채점과 체크포인트의 실제 재추론을 별도로 수행했다. 네 비용 조건은 학습 종료와 실제 프로세스 자원 반환을 확인한 뒤 CPU2에서 순차 실행했다. 비용은 캐시된 예측의 재생 시간이 아니라 전처리부터 복원까지의 실제 경로다. 비용 worker의 사전 검증용 파일 읽기와 timed trial의 예측 캐시 사용 여부를 구분한다.

독립 검산은 입력 169개, SSE/SAE 원수치 4,128행, 비용 trial 200행과 요약 8행, 수치 일치 40항목을 검사했다. 원 체크포인트와 중간 결과는 로컬에 보존한다. 보호 T는 새로 평가하거나 수치 파싱하지 않았다.

보고서 첫 생성은 기존 B2 비용 CSV의 메모리 결측 표기 `NA`를 읽는 단계에서 실패했다. 기존 CSV·producer·실패 기록을 보존하고, 결측값만 처리하는 v2 producer로 최초 정상 보고서와 그림을 생성했다. 메모리 결측값을 0으로 바꾸지 않았다. 이는 모델 학습 실패와 별개인 보고서 연결 문제다.
