# PeMS08 C32: Raw Bolt와 직접 G의 현재 판단

**같은 개발 V에서는 직접 G가 더 정확하고 빨랐다.** Raw Bolt의 정규화 MSE는 **0.09051378996**, 직접 G는 **0.08146537281**로 약 10% 낮았다. MAE도 **0.19521148987 → 0.18577497674**로 낮았다. CPU2의 B8 전체 추론 중앙값은 Raw **1.70108235초/배치**, G **0.00037005초/배치**였다. 이 비교만으로 B2나 압축의 효과, Bolt의 필요성을 확정하지 않는다.

## 무엇을 같게 맞췄는가

PeMS08 부모 170채널에서 성능값을 쓰지 않고 채널 ID의 SHA 순서로 고른 **C32**, L512/H12, seed92601, A60 scaler, V148 origin, target·관측 mask를 같게 맞췄다. 두 경로 모두 실제 관측 label 56,832개, 활성 채널 32개를 사용했다. 보호 T의 새 숫자 평가·파싱이나 T를 이용한 선택은 하지 않았다. C32의 새 결과와 과거 C170의 결과는 학습량까지 같은 대조가 아니므로 합쳐 순위를 만들지 않는다.

Raw는 각 채널을 동결 Chronos-Bolt로 예측한다. G는 각 채널의 과거 512개 값에 같은 가중치의 512→32→12 GELU MLP를 적용하고 현재값 anchor를 더한다. G에는 foundation model이 없다. 두 경로는 입력·평가 계약은 같지만 모델 구조와 학습량이 다르다.

Raw는 optimizer update 0이고 훈련 adapter checkpoint가 없다. G는 A50에서 0/.25/1/3 epoch를 비교한 뒤 3 epoch를 선택해 A60에서 새로 refit했다. search 1,577 update/25,215 exposure, refit 1,911 update/30,570 exposure다. 기록된 학습 상태는 `UNDERTRAINED_OR_BUDGET_LIMIT`이며 수렴이나 충분한 학습을 입증한 결과가 아니다.

## 실제로 검산한 범위

저장된 전체 V 예측의 FP64 재채점 두 조건, 저장점에서 새로 계산한 CPU6(4+2) 재추론 두 조건, Raw full/row128의 B1/B8 출력 일치 검사 두 조건, CPU2 단독 B1/B8 실제 전체 비용 네 조건을 순차 실행했다. 학습과 비용 측정은 겹치지 않았다. 비용은 실제 입력의 전처리부터 예측·FP64 역변환·CPU 반환까지이며 저장 forecast를 재생한 시간이 아니다. cold model load는 warm whole 시간 밖에서 별도로 기록한다.

독립 감사는 SSE·SAE·count 충분통계 **28,416행**, 비용 trial **200행**과 원 요약값을 재집계하고 실제 11개 guard/12개 worker의 실행·종료·자원 반환을 대사했다. 충분통계 행 수는 관측 label 수와 다르다. CPU6 재추론을 전체 V의 독립 재추론이라고 부르지 않는다. 전처리 계보의 upstream 미래 보간 여부는 `UNKNOWN`이며 이번 prefix 검사로 그 불확실성이 사라지지 않는다.

## 다음에 확인할 것

이번 결과는 Raw 연결만으로 Bolt를 유지할 추가 가치를 보여주지 못했다. 다음은 같은 C32·L512/H12·scaler·origin·mask에서 B0/B2 K8을 학습하고, 직접 G 및 Raw와 정확도·학습량·실제 전체 비용을 비교하는 것이다. B2가 시간·채널 처리와 압축을 통해 어느 추가 가치를 주는지 확인해야 한다. 이 문서 생성 시 B0/B2의 실제 추가 학습은 아직 시작하지 않았다.

한 seed·반복 개발 V·제한 학습의 결과이며 독립 일반화 검증이 아니다. 기존 B2 주 후보와 전체 MASTER의 미완료 상태를 유지한다. 이 범위의 완료를 전체 연구 완료로 바꾸어 말하지 않는다. 원격 게시 상태는 별도 main SHA·트리·파일 바이트 검증 영수증을 따른다.
