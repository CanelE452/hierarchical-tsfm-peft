# 잠금된 T route의 공개 충분통계 비교

52쌍은 T 관찰 뒤 수행한 보고용 구조 분해다. 방법과 역할은 기존 선택 잠금에 고정됐으며 이번 보조표에서 점수 순위로 비교를 빼거나 바꾸지 않았다. 기존 target/mask/channel/origin descriptor와 공개 SSE/SAE/count를 확인했으며 원 target 값이나 NPZ를 다시 검산하지 않았다. 시간 block은 원 metadata plan을 그대로 사용하고, 패턴 그룹은 frozen A-only 분류를 재적합하지 않았다. 채널 macro를 사용하며 block 또는 band 평균을 전체 오차로 대체하지 않는다. Hpast는 b route가 없는 대조다. 동일 head 용량·요청 학습 예산과 선택 update가 같은 것은 다르다. AlphaFit은 closed-form이고 LoRA는 별도의 강한 대조이므로 동일 head 학습으로 주장하지 않는다. 기존 14쌍과 겹칠 수 있어 독립 표본으로 합산하지 않는다. CI·유의성·추가 선택은 수행하지 않았다.
