# 이전 자동 보고서의 여섯 그림 미리보기

이전 자동 report가 참조한 6장의 **역사적 미리보기**다. 최신 v3 123개 그림은 [PUBLIC_FIGURES_KO.md](../../PUBLIC_FIGURES_KO.md)를 따른다. 여기의 이전 V_select snapshot은 당시328개 저장 예측·47stem의 부분 결과이며 최신 V405/T46 또는 필수 학습 완료로 다시 표시하지 않는다.

PNG/SVG는 같은 generation manifest의 원 byte SHA와 원수치 CSV binding을 확인한 뒤 파일 byte가 작은 형식 하나만 선택했다. 동률이면 PNG다. 원 그림·CSV·두 형식은 로컬 보존하고 재렌더·최신 데이터 대체·조건/정밀도 변경을 하지 않았다. 원 snapshot 전체 그림을 추가 게시하는 색인이 아니다.

[그림별 원본·원수치 결속](FIGURE_BINDINGS.json), [format-only alias](ALIAS_ROWS.json), [기존 목록 membership 근거](LIST_MEMBERSHIP_PROOF.json)를 확인한다. 정확한 trace 원자료 배열은 열거나 게시하지 않았으며 metadata의 기존 SHA 결속만 유지한다.
