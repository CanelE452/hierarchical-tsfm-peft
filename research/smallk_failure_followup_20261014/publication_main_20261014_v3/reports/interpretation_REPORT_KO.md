# MAIN 보존 잔차 보정에서 확인한 것과 남은 문제

[실제 보고서·그림 6개](../../report_main_residual_v1/REPORT_KO.md), [오차 기여 분해](../../report_main_residual_error_diagnosis_v1/REPORT_KO.md), [최종 집계 검산 v2](../../validation_v1/MAIN_ERROR_DIAGNOSIS_FINAL_VERIFICATION_v2.json)를 함께 읽는다. 네 원 조건의 실제 84개 ridge 후보·108개 비교·36개 선택 예측 및 24개 whole 추론 비용 측정을 완료했다. 저장 예측·CSV 보고서 검산 3,856개와 오차 기여 CSV 검산 8,573개는 실패 0이다. 이는 새로운 자료에서 성능을 입증한 결과가 아니다.

## 무엇이 해결됐는가

[확인] MAIN을 버리고 현재값에서 예측을 다시 만드는 readout과, MAIN을 유지하며 추가로 보정하는 readout을 구분했다. Robin 두 seed·세 경로 모두 TUNE에서 ZERO를 선택했다. MSE 0.569546544와 MAE 0.447338898는 원 MAIN의 성능이다. 이전 직접 E33K readout의 MSE 0.924에서 되돌아왔다는 것을 새 표현 학습의 개선으로 세지 않는다. 원 MAIN에는 단순 직접 readout이 보존하지 못한 유용한 예측 결과가 있었지만, Chronos만이 이를 제공할 수 있다는 검사는 아니다.

[확인] Beijing 두 seed 평균은 다음과 같다. 학습과 checkpoint/계수 선택의 주지표는 사전 고정한 정규화 채널 macro MSE다.

```text
방법                     MSE             MAE
압축 없는 RAW-F          0.5895754138    0.4079165085
원 MAIN                  0.6619571979    0.4700102317
공유 FIT 평균 보정        0.6627945472    0.4760787260
원 C 과거 RAW33C 보정     0.6546750713    0.4753505010
과거 K 요약 E33K 보정     0.6575606665    0.4765983790
전체 K 과거 E512K 보정    0.6612625765    0.4724813984
```

E33K는 MAIN 대비 MSE를 약 0.66% 줄이지만 MAE는 약 1.40% 늘렸다. RAW33C의 MSE가 더 낮지만 추가 원 C 과거 정보와 더 많은 계수가 있으므로 encoder만의 인과 효과를 뜻하지 않는다. E33K seed92601의 TUNE 개선은 약 1.12e-5로 매우 작다. 최종 평가값을 보고 방법을 다시 선택하지 않았다. 반복 VAL30·기존 노출 EVAL146·두 E seed의 조건부 결과이며, 창의 시간 중복과 선택 편향이 남는다.

## MSE 감소와 MAE 증가가 함께 생긴 이유

[확인] Beijing E33K−MAIN의 실제 오차 기여를 채널별 관측 수로 가중한 뒤 두 seed 평균을 구했다. 아래 값은 각 구간을 새로 정규화한 오차가 아니라 전체 점수 변화에 대한 기여다. 음수는 개선이다. 구간은 원 MAIN의 실제 정규화 절대 오차로 나눴으며 추론 입력이나 새 선택 규칙에 사용하지 않았다.

```text
원 MAIN 절대 오차       MSE 변화 기여      MAE 변화 기여
[0,0.25)               +0.0061165988      +0.0130939681
[0.25,0.5)             +0.0017110432      -0.0010644977
[0.5,1)                -0.0002798469      -0.0021005588
[1,2)                  -0.0034415905      -0.0019709221
[2,inf)                -0.0085027361      -0.0013698421
합계                   -0.0043965315      +0.0065881473
```

큰 오차 감소가 MSE를 낮췄지만 원래 작은 오차의 악화가 MAE를 높였다. 채널 index9의 MAE 악화 기여는 +0.0049126051로 전체 악화의 큰 부분을 차지했다. 채널 이름이나 물리적 원인은 이 집계만으로 단정하지 않는다. 네 윈도우 순서 블록 모두 MAE는 증가했고, 첫 블록의 MSE는 증가했다. 따라서 모든 채널·구간의 개선으로 설명할 수 없다. 실제 개별 예측이나 학습 목표를 바꾼 결과가 아니라 저장된 동일 예측의 설명이다.

집계 검증 v1은 CSV·개별 조건 합계를 통과했으나 부가 해석의 블록·오차 구간 평균에서 채널 수로 한 번 더 나누는 오류가 있었다. 원 v1 소스·결과를 보존하고 새 v2에서 채널을 먼저 합산한 뒤 두 seed를 평균하도록 고쳤다. v2에는 각 부가 해석의 합이 전체 점수 변화와 같아야 하는 검사와 synthetic fixture를 추가했다. 원 예측·CSV·실험 선택은 수정하지 않았다. [v1 기록](../../validation_v1/MAIN_ERROR_DIAGNOSIS_FINAL_VERIFICATION_v1.json)은 이 한계를 포함한 역사적 기록이며 해석 수치는 v2를 사용한다.

## 무엇을 아직 원인이라고 말할 수 없는가

[판단] 과거 요약을 전체 과거로 바꿔도 작은 K의 핵심 성능 문제가 해결되지는 않았다. 이번 residual 학습은 실제 Y−MAIN 예측 오차를 직접 최소화했다. 단지 재구성 목적을 예측 목적으로 바꾸면 해결된다는 설명은 이 결과로 지지되지 않는다. 현재 고정 E/F/D, 선형 보정의 용량·규제·FIT256, 학습 구간과 평가 구간 차이가 함께 남아 있으므로 학습 오류·정보 부족·방법의 보편적 한계 중 하나로 확정하지 않는다.

실제 미래 Y는 FIT 손실과 점수 계산에 사용했고 추론은 과거와 과거에서 생성한 MAIN 예측을 받았다. 이 생성 계보와 산술 검사 통과를 모든 종류의 누출 부재로 확대하지 않는다. 이번 비교는 다른 채널의 지연 정보 유용성이나 대조학습·동적 그래프의 필요성을 새로 식별하지 않았다. Bi-Hash 적용 실험과 ExoTimer의 문장·LLM을 포함한 전체 재현도 구분한다.
