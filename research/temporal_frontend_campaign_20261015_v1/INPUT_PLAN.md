## 1. Phase 0: 목적과 상담에서 확인된 범위

### 1.1 최상위 목표

**고정된 단변량 TSFM이 이용할 과거의 시간·채널 정보를 적응시켜 원채널의 미래 예측을 개선할 수 있는지, 그 이득을 소수의 시계열과 저비용 보완 경로로 유지할 수 있는지 검증한다.**

결과를 보는 사람은 민재와 지도교수다. 결정은 (a) 시간 전처리로 충분함, (b) 학습형 시간 표현이 필요함, (c) 표현의 효과는 있으나 작은 K 압축은 아직 안 됨, (d) 현재 조건에서 추가 가치가 없음 중 무엇인지다.

실험의 우선순위는 `원채널 미래 예측에 대한 추가 가치 → 소수 표현·결합에서 유지 여부 → 실제 시간·메모리 절충`이다. 정확도가 크게 나쁜 결과를 얻은 뒤 속도만 주목적으로 바꾸지 않는다. K=C 대조는 압축 제약을 제거하는 진단이지 원래 작은-K 목표를 몰래 버리는 목표 변경이 아니다.

## 2. 현재 확인한 사실과 이번에 남는 공백

[확인·저장소 보고서] `publication_main_20261015_v1`에는 PCA/ForeCA 원리, 고정/창별 D, lag0/lag7, 실제 F 입력 gradient를 통한 E/D 학습, E-only, F-gradient 차단, 같은 E/D native 대조가 있다. 예측 목적 E/D 학습을 이번에 처음 하는 것으로 쓰지 않는다.

[확인·최신 v2] `publication_main_20261015_v2`에는 잠재 보정, ridge, horizon STATIC/RAMP, FIT 내부 purged readout까지 추가됐다. 마지막 purged 비교는 **추가 readout만 A-only**이고 scaler/E/기존 D는 full-FIT였다. 후단 보정만 더 반복해도 전체 학습 일반화 질문에 답하지 못한다.

[확인·학습 범위 메타데이터] 최근 FIT256에서 Robin의 미래 정답 고유 시점은 1,081개이고 최대 12회 중복된다. Beijing의 미래 정답 고유 시점은 12,288개이고 최대 중복은 1회다. Robin의 문제를 Beijing 전체에 복사하지 않는다. 같은 기간의 더 촘촘한 감독과 더 넓은 실제 관측 기간은 구분한다.

[확인·PPT] 4시점 평균으로 시간축을 줄인 단순 대조는 예전에도 있었다. 따라서 이번의 단순 pooling 자체가 새 실험 원리라고 쓰지 않는다. 새 공백은 새 시간 경계·동일 원미래 target·시간 단위 복원·Raw C와 작은 K를 나눈 비교 및 학습형 시간 앞단이다.

**이번 핵심 공백:** TSMixer/TimeMixer에서 가져온 시간 구조를 실제 frozen Bolt의 앞단에서 학습하고, 단순 전처리·점별 어댑터·동일 용량/정보의 대조 및 결합 경로와 비교한 근거. 반드시 기존 코드 검색 후 실제 중복을 표에 표시한다.

## 3. 선행연구와 세 가지 인접 원리

### 3.1 직접 참고·비교해야 할 연구

1. **TSMixer: An All-MLP Architecture for Time Series Forecasting (2023/TMLR)**
   - 시간 혼합과 피처 혼합을 번갈아 적용. 기본 모델의 최종 Temporal Projection은 L→H 예측부다.
   - 가져올 것은 과거 정보를 혼합하는 앞단이다. L→H 예측부를 그대로 붙여 놓고 그 출력을 과거 잠재 시계열이라고 부르지 않는다.
   - 교수 첨부는 Google의 TSMixer다. IBM의 동명 KDD 논문으로 바꾸지 않는다.
2. **TimeMixer: Decomposable Multiscale Mixing for Time Series Forecasting (2024/ICLR)**
   - 평균 pooling으로 여러 시간 해상도를 만들고, 각 해상도에서 성분 분해. 계절성은 fine→coarse, 추세는 coarse→fine 혼합. 이후 별도 예측부가 있다.
   - 첨부판 Figure 1(4쪽), Figure 2(5쪽), Appendix F(16쪽)를 기준으로 모듈 대응표를 만든다.
   - PDM에 대응하는 과거 혼합만 사용하고 FMM을 Bolt로 대체하는 것은 원 논문의 성능 재현이 아니라 **Bolt용 변형**이다. 다중 해상도가 채널 수 축소를 자동으로 보장하지 않는다.
3. **AdaPTS: Adapting Univariate Foundation Models to Probabilistic Multivariate Time Series Forecasting (2025/ICML)**
   - 고정 단변량 FM 앞뒤의 학습형 잠재 어댑터가 이미 존재한다. pointwise E/D 예측 목적 학습은 표준 대안이지 신규성 주장이 아니다.
4. **See More, Forecast Better and Faster: Enhancing Time Series Foundation Models via Inference-Time Plug-and-Play Downsampling (2026/ICML), SPRINT**
   - 2026-10-15 조사에서 새로 확인한 직접 인접 선행연구다. 추세/계절성 분해·다운샘플 공간의 예측/보간·계절 패턴 반복을 사용한다.
   - 이번 계획 작성자가 확인한 범위는 PMLR 서지·초록 및 공식 `models/SPRINT.py`, `models/Chronos.py`다. **본문 PDF는 접근 실패하여 미열람**이다. 논문 수치/모든 실험 설정을 확인했다고 쓰지 않는다.
   - 공식 Chronos wrapper의 기본 경로는 `chronos-t5-small`이다. **SPRINT-on-Bolt는 백본 이식 대조**이며 공식 Bolt 성능 재현이 아니다.
   - 구현은 주기/길이 조건을 요구한다. 잘 나온 TEST로 주기를 정하지 말고 허용 학습 구간/기존 메타데이터만 사용한다. 기존 라이브러리 부재 시 전체 패키지 설치를 몰래 하지 않는다.

### 3.2 관계 구조로 본 인접 원리

- **다중률 신호처리/SPRINT:** 동일 신호를 다른 해상도로 표현하는 문제. 비용을 줄일 수 있으나 위상·표본 간격·복원 오차가 바뀐다. 공간 압축과 시간 재표본화를 혼동하지 않는다.
- **과제 지향 표현/AdaPTS:** 원본 복원에 충분한 정보와 미래 예측에 유용한 정보가 다를 수 있다. frozen F를 통과한 원미래 손실을 사용하되, 표현 붕괴/원채널 복원 제약/추가 감독량을 점검한다.
- **통계적 추정/시간순 평가:** 적은 창의 많은 특징이 불안정할 수 있으며 선택 구간 성능은 미래 구간 성능과 다를 수 있다. 모든 upstream을 앞 구간에서 다시 적합하는 rolling-origin 원리를 적용한다. 새 모델 필요성으로 바로 비약하지 않는다.

원문 분야에서 성공했다는 사실과 현재 Bolt 조합에서의 성공 가능성을 분리한다. `다중해상도+TSFM`, `E/D 예측학습`, `공통+잔차` 자체를 새 기여로 주장하지 않는다. 남는 기여 후보는 **같은 정보/자원 아래 표준 대안보다 유리한 조건과 실제 이유를 확인하는 것**이며 현시점 미검증이다.

## 4. 데이터·분할 계약: 구조보다 먼저, 그러나 끝없는 감사로 대체하지 말 것

### 4.1 자료 역할

- **Beijing Aotizhongxin: 주 실험.** 긴 FIT/TUNE 원 단위 관측값·mask를 가진 safe payload가 있다는 SOURCE/메타데이터 근거가 있다. 실제 경로/키/시간 경계는 읽기 전 계약과 실행 환경에서 재확인한다.
- **Jena: 두 번째 주 실험 후보.** 기존 실험과 연결되는 기상 자료이며 safe TRAIN 경계·원관측값 계보를 실제 확인한 뒤 포함한다. 완전한 raw A-only를 주장할 자산이 없으면 조건부 재구축임을 표시한다.
- **Robin: 기존 실패 경계/짧은 기간의 스트레스 진단.** 장기 학습의 대표 자료로 삼지 않는다. 첫 무학습 묶음과 선정 모델 비교에 유지한다. 원래 safe archive는 전체 TRAIN 통계를 거친 FP32 x를 역변환하는 계보가 남는다. 이를 무손실 원시 A 데이터라고 부르지 않는다.
- Jena 불가 시 계약이 확인된 Appliances로만 사전 대체 가능하도록 승인표에 미리 명시한다. 점수를 보고 더 잘 나오는 자료로 교체하지 않는다. 두 번째 자료가 준비되지 않으면 해당 실험을 BLOCKED로 보고하고 Beijing 핵심은 진행한다.
- 새 대형 자료·기존 보호 TEST·전체 원본 CSV 무차별 읽기는 포함하지 않는다. 많은 C에서의 실용 검증은 별도 승인 후다. 기존 Electricity 접근 이력의 문제를 현재 성공으로 덮지 않는다.

### 4.2 새 시간 분할

[추정·합의용] 허용된 **학습용 관측 구간 내부**를 시간순 A/B/C=60/20/20으로 나누는 것을 기본안으로 한다. 비율은 표준 상수가 아니라 충분한 앞 구간 학습·두 뒤 구간 판단을 위한 초기 배분이다. 실제 주기/길이/관측수를 확인하고 결과를 보기 전에 경계를 고정한다. 필요한 512/1024/2048 과거가 없으면 길이 조건만 INFEASIBLE로 남기고 짧은 자료를 임의 확장하지 않는다.

- A: scaler, 결측 초기값, 주기/필터 설정, PCA/whitening, E/D 초기화, 학습, 잔차 G, 모든 통계 적합.
- B: checkpoint/규제/설계 내 선택·자율 분기. 모든 분기 근거는 A/B까지만 사용.
- C: 핵심·후속 설계와 모든 선택을 잠근 뒤 일괄 점수화. C를 본 뒤 같은 C로 방법을 다시 조정하지 않는다. 수정이 필요하면 이후 결과는 별도의 탐색 결과로 격하하고 새 평가 범위를 합의한다.

첫 미래 시점을 o라 하면 history=[o−L,o), target=[o,o+H). `max_A(o+H−1)<min_B(o)`, `max_B(o+H−1)<min_C(o)`를 검산한다. 뒤 구간의 history가 이미 관측된 앞 구간을 포함하는 것은 허용한다. L+H 전체 창을 무조건 분리해 표본을 불필요하게 버리지 않는다.

**scaler/E/기존 D가 full-FIT 상태인 채 추가 readout만 A에서 적합해서 전체 A-only라고 쓰지 않는다.** 학습 감독으로 A의 실제 미래를 사용하는 것은 정상이다. 실제 예측 입력에 o 이후의 정답/관측 mask를 넘기는 것은 금지다. label 미관측 값은 채움 후 정답으로 세지 않는다.

C가 예전에 어떤 실험에서 이미 사용됐으면 이번 알고리즘에서 잠가 두더라도 새 독립 holdout은 아니다. `algorithmically_held_out_this_run`과 `historically_unseen`을 별도 기록한다. 최종 독립 검증은 별도 단계다.

A의 모든 합법 origin을 스트리밍하거나 시간 전역을 고르게 덮는 목록으로 사용한다. 기존 256창을 유일한 학습 정보로 강제하지 않는다. 비교군은 같은 origin schedule을 공유하고, 고유 input/target 시점 수·시점 범위·중복·관측수를 기록한다. 자료 기간, 표본 추출 밀도, update 수를 각각 구분한다.

### 4.3 빠른 정확성 점검

계약 읽기→작은 no-op/shape/시간좌표 검사→하나의 실제 Raw batch parity→핵심 실행으로 이동한다. 공통 계약/코드는 한 번 검증하고 새 오류가 없는 한 모든 모델마다 수십 개 보고서를 복제하지 않는다. 새 입력/E/정규화에서 옛 Bolt 예측 캐시를 재사용하지 않는다. 캐시는 모델·입력·통계·origin·dtype·output summary가 모두 일치할 때만 재사용한다.

## 5. 고정할 공통 예측 인터페이스

기본 L=512, H=48. frozen Chronos-Bolt-small의 실제 revision·forward·normalizer·q0.5 사용을 재확인하고 모든 비교에 동일 적용한다. q0.5 점예측의 MSE 비교이지 조건부 평균·확률예측 우위를 주장하지 않는다.

**학습형 핵심:**

`X의 과거 → 시간 앞단 Pθ(과거→과거) → 채널 투영 Eφ(C→r) → frozen F → 같은 클래스의 Dψ → 현재 원채널 값 보존 → 원채널 미래`

- P 출력은 원 시간격자의 L개 행이다. 다중 해상도는 내부에서 사용하고, 전체 해상도를 원격자에 맞춰 융합한 뒤 **r개 시계열만 F에 입력**한다.
- coarse와 fine를 시간축에 단순 연결해 동일한 시간 간격이라고 가정하지 않는다. 스케일마다 F를 별도로 호출하는 방식은 `총 stream 수 = Σ r_s`와 호출 수를 따로 세며 주 경로와 섞지 않는다.
- r=C 대조와 작은 r=K 대조를 함께 수행한다. K는 기존 대응을 기준으로 Robin4/Beijing2/Jena5를 초기안으로 쓰되 실제 C·계약을 확인한다. K=C는 압축 아님.
- D는 모든 핵심 방법에서 **같은 origin-reference lag-linear 클래스**를 사용한다. 기존 lag[0,1,2,4,8,16,32] 구현을 재사용 가능한지 확인한다. 시간 prefix·각 lag의 기준값·current-C를 동일하게 유지한다. E/D가 달라지면 수치 공간 하한도 새로 계산해야 한다.
- 선형 공간 제약을 전체 방법 불가능성으로 만들지 않도록 r=C가 함께 있다. 작은-K 단독이 실패해도 아래의 동일 잔차 결합은 별도 실행한다.
- 초기 r=C는 항등 투영, r=K는 A-only PCA 출발점을 기본으로 한다. 비교 P는 no-op에 가깝게 출발하도록 최종 잔차 층을 초기화한다. 여러 연속 층을 모두0으로 만들어 gradient가 막히지 않는지 확인한다. 초기 실제 동등성은 FP32 허용 오차로 검사하고 비트 동등성을 임의로 주장하지 않는다.
- 원 TSMixer/TimeMixer의 전체 과거 혼합은 origin 시점까지의 정보만 쓰면 그 자체가 미래 정답 누출은 아니다. 다만 각 과거 시점 표현의 prefix invariance는 별개다. 원격자 행과 표본 의미·추출 규칙을 기록한다. causal mask/conv로 변경할 경우 원논문 변형으로 표시하고, 그 변경 하나를 성능 원인으로 확정하지 않는다.

## 6. R1: 무학습 시간 조작 — 필수 저비용 묶음

[추정·미검증 설계] 아래 14설정은 최대3자료에서 먼저 평가한다. 의미/조건이 다른 연산을 하나의 방법이라고 뭉치지 않는다. 이 결과가 나빠도 R2를 취소하지 않는다.

| ID | 설정 | 답할 질문 |
|---|---|---|
| A0 | Raw Bolt, L512 | 공통 기준 |
| A1/A2 | 같은 L에서 완만한 성분만 F로 예측, 원 마지막 잔여값 보존; 필터 폭5/25 | 세밀한 변동을 약화하면 도움이 되나? |
| A3/A4 | 같은 L에서 잔여 성분만 F로 예측, 마지막 완만한 수준 보존; 폭5/25 | 반대로 완만한 흐름을 분리하는 것이 유리한가? |
| A5/A6 | 완만한 성분·잔여 성분을 각각 F로 예측한 뒤 합침; 폭5/25 | 둘의 역할 분리가 이득인가? 추가2배 streams는 명시 |
| A7/A8 | 원표본의 균일 endpoint 추출, 간격2/4; 같은 물리 미래로 복원 | 시간 해상도 변경 효과 |

| A12/A13 | Raw L1024/L2048, 가능한 공통 origin | 더 긴 관측 범위 자체가 원인인가? |

기본 필터는 **과거 전용 trailing moving average**로 두고 T(x), R=x−T를 정의한다. 폭5/25는 약한/강한 평활을 빠르게 검사하는 [추정] 두 설정이며 주기·최적 bandwidth가 아니다. 원 TimeMixer의 대칭 이동평균과 동일 구현이라고 쓰지 않는다. A1은 F(T)+R_last, A3은 F(R)+T_last, A5는 F(T)+F(R)다. T/R은 운영적 분해이며 R이 실제 계절성만 담는다거나 고주파가 잡음이라고 가정하지 않는다. 정답 Y는 원자료 그대로다. T+R를 F 입력 전에 합하면 Raw가 되는 무연산 대조도 unit test한다.

시간 단위는 필수 계약이다. H48을 간격4로 다루면 12개 coarse 미래가 원래 48시점을 대표한다. endpoint 예측은 실제 coarse 시각 좌표에 두고 현재 관측과 선형 보간한다. block 평균 예측은 해당 미래 block의 평균이므로 endpoint로 오인하지 말고 block 반복을 기본 복원으로 둔다. 이 복원 오차도 실제 Y 평가에 포함한다. 평균값과 끝점의 phase 차이를 숨기지 않는다. 모든 방법은 같은 원미래 H48의 동일 관측 mask로 채점한다. target 자체를 평균내서 MSE가 작아진 것을 예측 개선으로 세지 않는다.

SPRINT는 공식 period/길이/보간 조건과 현재 설치 상태를 확인한다. 공식 T5 wrapper를 Bolt로 교체한 차이, 주기 추정 방식, 좌측 절단으로 바뀐 유효 lookback을 기록한다. 동일 유효 lookback Raw를 같이 제공한다. 주기를 허용 과거만으로 신뢰성 있게 정하지 못하거나 의존성 설치가 필요하면 해당 대조만 BLOCKED/조건부로 남긴다. 다른 R1/R2를 중단하지 않는다. 본문 미열람 상태에서 공식 결과 재현 성공이라고 쓰지 않는다.

A12/A13은 L별 공통 origin 부분집합의 Raw512를 별도 재계산한다. L2048 부족 시 데이터를 붙여 만들지 않는다. 같은 물리 범위 비교와 같은 모델 입력 길이로 더 오래 보는 비교는 별도 실험이며 혼합하지 않는다. Bolt의 실제 head가64를 동시에 내놓으면 crop을 줄였다고 그만큼 계산이 줄었다고 주장하지 않는다.

## 7. R2: 실제 학습형 앞단 — 핵심 비교를 끝까지 수행

[추정·미검증 설계] 두 주 자료 × r∈{C,K} × 아래5개 × 두 초기화/학습순서 seed = **최대40fit**. 기존 값은 새 A-only 계약과 완전히 같을 때만 재사용한다. 무학습 전처리나 SELF/JOINT 실패를 이유로 특정 가족 전체를 취소하지 않는다.

| ID | Pθ | 비교가 필요한 이유 |
|---|---|---|
| B0 | identity, pointwise E/D만 예측 목적 학습 | 표준 외부 어댑터 기준; 시간 모듈이 정말 추가로 필요한지 |
| B1 | 단일 해상도·채널별 공유 시간 혼합 | 시간 정보 재구성 자체의 효과 |
| B2 | TSMixer 원리의 시간/피처 교대 혼합 | B1 대비 채널 상호작용의 추가 효과 |
| B3 | 다중 해상도 혼합, 추세/잔여 분해 없음 | 다중 해상도 자체의 효과 |
| B4 | TimeMixer PDM 원리의 성분별 다중 해상도 혼합 | B3 대비 성분 분리/혼합의 추가 효과 |

B1의 '채널별'은 앞단 temporal mixing에 대한 말이다. 후단 C→K 투영 자체도 채널을 섞는 연산임을 숨기지 않는다. B2는 Google TSMixer의 과거 믹서 원리를 사용하되 최종 L→H head를 제거한다. B4는 FMM을 제거하고 과거 혼합의 원격자 표현을 C→r로 투영한다. 이들은 **TSMixer-front/TimeMixer-front 변형**이지 전체 원논문의 정확한 재현이 아니다.

[추정] 첫 구조는 잔차 블록1개, hidden32, 내부 해상도{1,2,4}를 기본 후보로 한다. 단일 해상도 대조와의 실사용 parameter/FLOPs/activation 차이를 기록한다. 무의미한 사용 안 하는 파라미터로 수만 맞추지 않는다. B4가 B3보다 좋을 때 효과가 모델 크기만으로 설명되는지 가장 가까운 폭의 B3를 한 번 더 비교한다. 이 한 대조 없이 성분 분해만의 인과 효과라고 쓰지 않는다.

학습 손실은 모든 경로에서 **원 관측 미래 Y에 대한 A 통계 기반 채널 균등 normalized MSE**다. 새 contrastive/spectral/latent teacher 손실을 첫 묶음에 더하지 않는다. 기존 mask-aware 손실의 관측수 정의를 확인하고 동일하게 사용한다. F parameter는 optimizer에서 제외하되 입력 gradient는 유지한다. `no_grad()`로 F를 감싸 E 학습을 끊지 않는다. 모듈명에 RECON이 있다는 이유로 재구성 목적 학습이라고 오해하지 않는다.

[추정·합의용 학습량] 공통 batch4, 첫600update, CP0/100/200/400/600. 학습률은 기존 matched 절차의 .001을 첫 기준으로 하되 작은 probe에서 유한성/gradient 범위를 확인한다. 최선이 마지막 CP이거나 B 곡선이 계속 낮아지면 해당 후보와 지정 비교군을 함께1200까지 연장하고, 같은 현상이 남으면2400까지 한 번 더 연장한다. 이것은 충분 수렴의 보장이 아니라 `600에서 끝났으니 방법 실패`라고 쓰지 않기 위한 절차다. 2400까지도 하강하면 UNDERTRAINED_OR_UNRESOLVED로 남긴다. clipping 지속·발산 시 같은 비교군에 동일한 사전 보조 learning rate .0001을 한 번 적용할 수 있다. 더 잘 나온 C를 보고 optimizer를 바꾸지 않는다.

seed는 무엇을 바꾸는지 명시한다. 새 앞단의 무작위 초기화와 minibatch 순서를 둘 다 바꾼 경우와 동일 초기값의 순서만 바꾼 경우를 구분한다. 모델 간에는 matched seed/schedule을 공유한다. 최소2회는 선별용이고 통계적 확증으로 쓰지 않는다.

## 8. R3: 공통 경로와 개별 정보를 합칠 때도 직접 검사

[추정·미검증 설계] B2/B4의 작은-K 결과를 가족별로 B에서 선정하고, **단독이 Raw보다 나빠도** 각 가족에서 최소 하나의 결합 경로를 평가한다. 현재값 보존만 있는 경로와 학습 잔차를 더한 경로를 구분한다.

같은 작은 residual G 클래스로 아래를 맞춘다.

1. Raw Bolt + G.
2. B0 작은-K + G.
3. B2 작은-K + G.
4. B4 작은-K + G.
5. 현재값 + G만 사용(F 없음).

처음에는 이미 학습한 P/E/F/D를 동결하고 G만 같은 A 과거/미래에 학습한다. 동일한 G 입력은 원 C 과거에서 현재값을 뺀 값으로 통일한다. 모든 비교에서 같은 정보·용량·학습 기회를 준다. 필요하면 기존 LEVEL의 복원 잔차 입력을 별도의 입력 대조로 한 번만 추가한다. 서로 다른 입력을 주고 G 클래스가 같다는 이유로 순수 압축 효과라고 말하지 않는다.

G의 0 초기 출력과 no-correction 후보를 유지한다. 무보정이 선택되면 개선0이다. 각 가족의 이득을 `full−같은G만`, `front+G−Raw+G`, `front+G−B0+G`로 분리한다. raw+G보다 나쁘면 '보정하면 좋아졌다'만으로 기여를 주장하지 않는다. 기존 G에 같은 데이터/정보로 충분한 이득이 나면 더 복잡한 G를 추가하지 않는다.

## 9. R4: Bolt의 추가 가치·표준 직접 예측과 비교

[추정·미검증 설계] 핵심 B2/B4 후보를 B에서 정한 뒤 다음 두 질문을 따로 검사한다.

- **대체 진단:** 같은 선정 E/D를 동결하고 F만 저비용 latent temporal head로 바꾼다. 표준 linear/ridge와 현재 수용영역에 맞는 head를 사용한다. 이전 L7-native가 이미 답한 동일 조건은 재학습하지 않는다. 선형 전체 출력식이면 직접/정규화 최소제곱도 검토해 Adam/clipping만의 실패와 구분한다. 거대한 dense 행렬을 무조건 만들지 않는다. 잘 안 풀리면 수치/학습 미확정이지 모든 native의 한계가 아니다.
- **실용 비교:** TSMixer/TimeMixer 원래 예측부를 포함한 작은 직접 예측 모델을 같은 A/B/C·정보·학습 예산으로 비교한다. F용으로 최적화된 E/D를 동결한 비교만으로 모든 다른 모델보다 F가 우월하다고 하지 않는다.

교수의 기존 비교군 의견을 반영해 Raw와 기존 LoRA를 실용 비교에 유지한다. LoRA는 저랭크 적응이며 내부 파라미터 적응 대조다. 현재 설치/기존 SOURCE가 지원하는 사전 지정 구성1개를 새 A-only 조건으로 맞추고 튜닝 탐색을 늘리지 않는다. 이것은 제안 경로의 frozen-F 제약을 바꾼 것이 아니라 별도 비교군이다. 원 데이터 Ridge/NLinear는 연구의 동급 방법 주장용이 아니라 '복잡한 F가 필요한가'를 확인하는 하한비용 대조이므로 삭제하지 말고 목적을 명시한다. Raw mini/tiny가 이미 로컬에 있고 승인 범위에 맞으면 동일 비용 대안으로 추가하되 새 다운로드가 필요하면 미실행으로 남긴다.

## 10. R5: 반드시 함께 할 분석

### 10.1 원미래 성능

Primary: A-only 표준화, 원 관측 target mask, 채널별 MSE 후 활성 채널 동일 가중 평균. Secondary: 같은 MAE, 채널별 원단위 오차. 단위가 서로 다른 raw MSE 평균을 새로운 주지표로 삼지 않는다.

모든 표에 Raw, 같은 temporal-free B0, 선정 후보, 동일 G 비교가 있어야 한다. 서로 다른 구간/표본의 숫자를 하나의 순위에 섞지 않는다. 상대 변화와 퍼센트포인트를 구분한다. cross-dataset 요약은 각 자료의 Raw 대비 비율을 동일 가중 평균하되 원수치/자료별 반례를 함께 보인다. Raw 오차가 수치적으로0에 가까우면 비율 대신 절대 차이를 사용한다.

### 10.2 시간 이전과 학습 타당성

A/B의 학습곡선, 초기CP0, 선택CP, 실제 처리한 고유 시점, label 관측수, gradient·clipping·rank·latent variance를 함께 기록한다. finite/nonzero gradient만으로 충분 학습을 주장하지 않는다. A/B 개선과 C 악화는 분리하며 C를 보고 다시 학습하지 않는다.

선정 모델/기준선에 대해서만 두 번째 시간 cutoff의 전체 upstream 재적합을 수행한다. cutoff는 첫 결과 전에 정한다. 두 fold도 같은 시계열의 조건부 반복이며 새 독립 자료 두 개가 아니다. 이전 fold의 미래 자료를 사용해 만든 scaler/PCA/필터/초기D를 앞 fold로 가져오지 않는다.

### 10.3 어떤 패턴에서 도움/손해가 있는가

과거에서만 계산한 trend strength, 변동 크기, 주기성, lag 관계 지표를 설명 변수로 사용한다. 공식 정의/기존 구현을 먼저 확인하고 임의 새 지표를 만들지 않는다. A로 그룹 경계를 고정하고 모든 그룹의 크기·오차를 보고한다. 높은 상관·분해 후 낮은 엔트로피만으로 미래 예측 신호가 충분하다고 주장하지 않는다. 입력을 정렬/평활하면 스파이크·변화 시작 시점이 지연될 수 있으므로 예측 시차 및 진폭 오차를 진단한다. 실제 이벤트성 고주파를 잡음으로 삭제했다고 미화하지 않는다.

H48에서는 [1,12], [13,24], [25,48] 세 구간을 사전 진단용으로 보고한다. 목표 horizon을 바꾼 실험이 아니라 같은 예측의 부분 점수다. 채널별·시간구간별 악화도 모두 보존한다. 큰 미래 오차를 보고 나눈 집단은 사후 설명이지 배포 selector의 입력이 아니다.

### 10.4 성분·모듈 기여

B4에서 분해/각 혼합 가지를 제거한 matched 재학습 대조를 우선한다. 학습한 가중치 크기만으로 중요도를 확정하지 않는다. 제거 전후가 모두 필요하고, 단순 inference ablation은 입력 분포 변화의 영향이 섞인 진단이라고 표시한다.

R1처럼 정확한 가법 T+R 분해라면 같은 mask·scale에서 `e_total²=e_T²+e_R²+2e_T e_R`의 점수 분해를 사용할 수 있다. 미래 T/R은 평가 시에만 정답으로부터 정의하며 입력이나 선정에 누출시키지 않는다. 이 항등식은 구성 성분의 인과 효과가 아니다. learned arbitrary latent마다 가짜 정답 T/R를 만들지 않는다.

### 10.5 복원 한계 진단은 꼭 필요한 경우에만

새 D/offset에서 구조상 가능한 출력 범위와 실제 예측의 차이를 검사할 때만 실시한다. 과거의 static rank-K 하한을 temporal/창별/비선형 D로 재사용하지 않는다. 원시 E(Y)는 최적 잠재값이 아니다. 미래 정답을 아는 수치 최소를 배포 방법/학습 목표/기여 점수로 쓰지 않는다. 이 진단에 또 여러 날을 쓰느라 실제 앞단 학습과 결합을 생략하지 않는다.

### 10.6 전체 비용

C score를 해석하기 전에 후보의 B1/B8 실제 전체 추론을 같은 장치·dtype·출력·입력·실행 세션에서 측정한다. Raw→전처리→P/E→실제F→D/G→원단위 CPU 반환·동기화를 포함한다. cache 반환 시간을 F 추론시간으로 세지 않는다. 각 단계의 시간과 whole을 함께 보여 병목을 구분한다.

정확도 동등성이 확인되는 Raw 채널 microbatch 실행도 비교해, Raw를 일부러 큰 배치로만 실행해 메모리 차이를 만들지 않는다. 모델 weights 메모리는 K가 줄어도 유지된다. peak allocated/reserved, resident weights, activation/작업 memory를 분리한다. **E까지 gradient를 흘리는 학습은 F weight가 동결이어도 activation memory가 필요할 수 있다.** frozen=no-backward/no-memory라고 주장하지 않는다.

일반 속도 측정에서는 F1개를 유지하되 활성 후보의 E/D/G만 두며, 순서를 교대한다. 독점 peak-memory 비교는 경로별 별도 process로 측정한다. [추정] warmup5 후10회 반복을 초기안으로 쓰고, 후보 수가 q이면 q의 완전순환으로 올려 위치 편향을 줄인다. 최고속값이 아니라 중앙/분산 및 원표본을 보고한다. 여러 장비/날짜의 절대 시간을 합치지 않는다. 차이가 측정 변동 안이면 속도 우위 미확정이다.

### 10.7 통계 해석

첫2seed는 선별용이다. 중첩 forecast window/채널/seed를 독립 표본처럼 모아 t검정하지 않는다. 우선 시간순 차이와 seed별 방향·원수치를 보인다. 최종 불확실성 추정은 모델/프로토콜 고정 후 시계열 의존성을 반영하는 별도 설계가 필요하다. 임의의1%·3/4블록 gate를 유의성/방법 불가능성 기준으로 만들지 않는다.

## 12. 빠르게 끝내는 실행 구조와 최대 범위

[추정·합의용] 완료시간을 확정할 근거가 없으므로 '몇 시간 안에 전부 끝난다'고 약속하지 않는다. 승인 직후 각 학습 클래스의 작은20update smoke와 추론 batch를 재고 아래 예상치를 계산한다.

`예상 GPU 시간 ≈ Σ(남은 update × 실제 update 중앙시간) + checkpoint 평가 + 전체 비용 측정`

초기 커버리지: R1 최대14설정×3자료(학습 없음), R2 최대40fit×600update. 조건부 연장은 지정 대조쌍과 함께 최대2400update. G5경로×2자료×2seed 최대20의 작은 추가fit, 직접 모델/선정 F-swap과 기존 LoRA는 합계최대16fit로 제한한다. 같은 조건의 cache/결정적 fit를 seed로 중복하지 않는다. 모든 항목을 최대치까지 실행할 의무는 없고 해당 질문에 필요한 것만 사용한다. 새 learned 가족을 무제한 추가하지 않는다.

같은 GPU에서는 학습/정밀 latency를 동시 실행하지 않는다. SOURCE 정리·CPU 분석은 독립적으로 수행하되 비용 측정 중 경쟁 부하를 기록한다. 다수 실험은 한 campaign queue에 넣고 학습은 순서대로, 공통 model load/입력 준비/선형 분해 캐시는 조건 일치 때만 공유한다. full-F-gradient 모델을 바꿀 때 이전 latent cache를 재사용하지 않는다.

메모리 여유는 장치의 실제 가용량을 확인해 안전 예약량을 남기고 정한다. OOM이면 해당 비교군 모두 동일 effective batch 조건으로 재실행하거나 BLOCKED로 기록한다. 환경 설치·새 데이터 범위·전체 목표 변경·사용자가 정한 비용/시간 상한 초과가 필요할 때만 다시 승인받는다. 자원 상한 때문에 중단한 것을 방법 실패로 기록하지 않는다.

- `PROFESSOR_BRIEF.md`: 7장 설명안: ①문제 ②교수 제안/표준 연구 ③단순 시간 변환 ④학습형 시간 앞단과C/K ⑤같은 잔차·Bolt 대조 ⑥시간 이전/실제비용 ⑦남는기여·다음판단.

그림은 유효 원수치가 있는 6종만 먼저 만든다: Raw 상대오차, temporal×r 대조, 모듈+G 분해, 학습/시간 이전, 정확도–시간–메모리, 사전 고정/대표 실패 사례. method/axis/legend는 영어, 설명문은 한국어다. 예측 곡선은 사전 origin 목록과 중앙/큰 악화 사례를 함께 써서 좋은 사례만 선택하지 않는다. 모델 내부 가중치나 UMAP 모양만 보여주는 그림은 첫 보고에서 제외한다.

기록 상태: COMPLETE_VALID / REUSED_VERIFIED / NO_GAIN / HARMFUL / INVALID / UNDERTRAINED_OR_UNRESOLVED / BLOCKED / NOT_RUN. 감사 PASS와 성능 NO_GAIN은 동시에 가능하다. 수치 검산은 작은 수학식·저장 예측·mask·선정 재계산을 검증한 범위를 정확히 적는다. 타이머/학습 전체 독립 재실행을 하지 않았다면 했다고 쓰지 않는다.

## 14. CLI에 전달할 시작 문장

> 이 문서의 목적과 실험표를 기준으로 현재 저장소·상담·기존 실행과 중복을 먼저 확인해. 새 시간 혼합 앞단과 표준 비교를 실제 실험해야 하며, 선형 기준선/단순 평활 실패를 전체 연구 중단 조건으로 쓰지 마. 아직 승인되지 않았다면 실제 자료 접근 범위·예상 비용을 포함한 계획 전체를 한 번만 승인받아. 승인 후에는 R1/R2 핵심과 명시된 R3/R4 분기를 결과에 따라 이어서 수행하고, 최종 C를 보기 전에 선택을 잠가. 기존 실패를 지우거나 성공 기준을 바꾸지 말고, 방법별 실제 이득·반례·미해결을 Raw와 같은 보정 대조까지 포함해 보고해. 코드·실험·검산·그림은 한 campaign으로 관리하고, 보호 TEST나 새 외부 서비스 비용은 건드리지 마. commit/push는 별도 요청 전에는 하지 마.
