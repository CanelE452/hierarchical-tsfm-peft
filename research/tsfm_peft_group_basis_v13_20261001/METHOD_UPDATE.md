# V13 method: fixed channel groups with a matched residual-input control

This document describes the fixed development comparison in [PLAN.md](PLAN.md) and [protocol.json](protocol.json). It makes no accuracy or cost conclusion. The hypothesis is that a different compression representation can improve a frozen univariate backbone's forecasts while retaining the existing trainable capacity. Signed PCA cancellation is a possible motivation, not an established failure cause.

For each dataset, retain the existing standardized data, columns, masks, origins, context L=512 and horizon H=48. The fixed C/K pairs are Robin 17/5, Jena 21/6, Hog 32/8 and Peacock Education 13/4. Compute Pearson correlations on pairwise observed values within the original TRAIN segment only. Use distance `sqrt(max(0, 2-2*clip(rho,-1,1)))`; undefined correlation becomes zero and is recorded. Deterministic average linkage merges the clusters with the smallest mean original between-member distance, with lexicographic leaf-index tie breaking, until exactly K groups remain. No absolute correlation, sign flip, group-size search or VAL/TEST-dependent grouping is used. Source: [prepare_v13.py](prepare_v13.py), `train_window` line 342, `pairwise_distances` line 352 and `average_linkage_groups` line 403; per-dataset `data_contract_group_basis_*.json` records TRAIN bounds, pair counts, memberships and basis hashes.

For group S_j of size n_j, set U[c,j]=1/sqrt(n_j) for members and zero otherwise. Then U^T U=I, P=UU^T is an orthogonal projection, and `(XU)[:,j]=sqrt(n_j)*mean(X[:,S_j])`: these are scaled group means, not unscaled averages. The encoder U and decoder U^T remain fixed. Normalized grouping uses standardized coordinates and does not make Jena's original physical quantities commensurate. Source: [prepare_v13.py](prepare_v13.py), `group_basis` line 426, and [model_v13.py](model_v13.py), `GroupModel` line 31.

Let F0 be the pinned Chronos-Bolt-small median forecast, using its native instance normalization and inverse scaling, cropped to H=48. Let `repeat_T` copy the last-time vector over T steps:

```text
b    = F0(XU) U^T
r    = X - XP
ell  = last(r)
dX   = X - repeat_L(last(X))

GROUP_RES = b + repeat_H(ell) + G(r - repeat_L(ell))
GROUP_RAW = b + repeat_H(ell) + G(dX)
```

G is the same shared, bias-free, activation-free temporal map `512 -> 32 -> 48`, with 17,920 trained parameters. Its output layer starts at zero. Both families therefore start at exactly the same function `b + repeat_H(ell)`, share the same original-channel information and receive each dataset/seed's verified original **untrained** LEVEL G tensors. Trained PCA G and latent LoRA weights are not transferred. RAW retains the same residual-level term; it does not add the full raw level a second time. Since G is a shared linear time map, the RES correction stays in the new Q=I-P subspace up to floating-point error. RAW can alter both P and Q. Source: [model_v13.py](model_v13.py), `initial_g` line 17 and `correction` line 92; original tensor extraction is [prepare_v13.py](prepare_v13.py), line 454.

The paired fit policy is fixed: seeds 92601/92602, LR 1e-3, AdamW with no weight decay, clip norm 1, batch 4 and 512 phase-balanced TRAIN origins per epoch. Sampling uses `SeedSequence([seed,epoch])`, period 24 except Jena 144, and matched schedule hashes. Selection uses complete VAL masked channel-macro MSE, including epoch zero; exact ties retain the earlier checkpoint. Maximum 120 epochs, strict nonimprovement patience 6, and the original ReduceLROnPlateau policy are retained. An epoch-zero selection can be valid even after nonzero gradients and parameter updates; it does not by itself diagnose a disconnected optimizer. Sources: [train_v13.py](train_v13.py), `optimizer_for` line 52, `fit` line 197 and `select_all` line 368; numeric sampling/loss primitives are explicitly reused from [runtime_v11.py](../tsfm_peft_internal_vs_subspace_v11_20260930/runtime_v11.py), lines 406 and 420.

Only frozen `b` is cached for TRAIN/VAL; G fitting remains CUDA FP32 with the original inputs, target masks and loss. F0 is deterministic in evaluation mode and normalizes each latent row separately, so changing its surrounding batch does not introduce a batch-statistics dependency. The cached tensor has no trainable upstream parameter. Deployment always computes F0 online and cost measurements must include that computation. Cache/source hashes and initial online/cache comparisons are recorded; those finite checks do not establish bitwise equality of an independently rerun full online training trajectory. Selected-head replay uses the cached route. Sources: [train_v13.py](train_v13.py), `cache_main` line 82 and `cached_main` line 128; [model_v13.py](model_v13.py), `backbone_point` line 73, `forecast_from_main` line 99 and `restore_model` line 147. The installed scaling implementation is `.venv/Lib/site-packages/chronos/chronos_bolt.py`, `InstanceNorm`, `encode` and `forward`.

Interpret the comparisons within these bounds:

- GROUP_RES versus the reused PCA LEVEL reference primarily tests the changed fixed compression representation under the same F0/K/G recipe. It changes subspace, locality, signs and grouping together, so it cannot isolate signedness as a cause. PCA and the older alternatives have different historical tuning opportunities; v13's fixed LR and two seeds do not equalize the earlier search budgets.
- GROUP_RAW versus GROUP_RES tests whether feeding centered raw history rather than centered projection residual to the same-capacity G matters. If RAW suffices, a residual-specific benefit is not established. RAW is not an independently trained no-Q ablation.
- Reused A, full-MSE LoRA, native-loss LoRA, F0 and direct NLinear are separately named external or nearby alternatives. Beating PCA LEVEL alone does not close their accuracy gaps or establish a useful deployment tradeoff. Epoch-zero equality cannot support an internal-LoRA learning claim.
- U has nonnegative entries and signed-rho distance favors positive correlation, but fixed-K average linkage does not guarantee every within-group pair is positively correlated. It also permits highly unequal groups and singleton channels. This changes how the fixed K latent paths cover channels; it is an outcome of the rule, not evidence that imbalance helps or harms forecasting. The rule can lose anti-correlated and cross-group information.
- All four datasets, including Peacock after v12, are exposed development evidence. TRAIN-only grouping prevents within-run grouping leakage; it does not undo previous evaluation exposure or establish a new-domain or pretraining-disjoint result. Paired intervals do not include repeated development/selection uncertainty. Self-checks and agent review are not independent reproduction.

Channel grouping itself is existing work. The targeted prior-art reading recorded in [PLAN.md](PLAN.md) describes CCM as learning assignments/prototypes and cluster-specific feed-forward weights; this experiment instead fixes TRAIN average-linkage groups, uses orthonormal scaled means and shares one residual G. That distinction is not a full CCM reproduction or a novelty claim, and CCM does not establish a compressed-TSFM benefit for this design. See Chen et al., *From Similarity to Superiority: Channel Clustering for Time Series Forecasting*, NeurIPS 2024, sections 4.1–4.3 ([official paper](https://papers.nips.cc/paper_files/paper/2024/file/eb9b18ccb76a1156af5779ffdca1d91f-Paper-Conference.pdf)).
