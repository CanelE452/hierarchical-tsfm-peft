**3. 비교한 접근과 개발 대상**

**A — 주력: 압축 잔차를 보존하는 입·출력 PEFT**

- **문제:** 다채널 입력을 적은 잠재 채널로 줄이면 TSFM에 투입하는 계열 수는 줄지만 정보 손실이 생깁니다. [확인] 로컬 GPU는 12GB급 RTX 4070입니다. [추정] 압축에서 빠진 정보 일부가 미래 예측에도 유용할 수 있습니다. 이 마지막 부분은 아직 실험 근거가 없습니다.
- **가까운 선행:** AdaPTS는 동결 TSFM 앞뒤의 특징 변환과 잠재 차원 축소를 이미 다룹니다. ICML 2025 게재를 확인했고, 이번에는 원문 §3·§4·§5.2와 학습 설정, 저자 저장소를 읽었습니다. 공식 전체 재현은 하지 않았습니다. [논문집](https://proceedings.mlr.press/v267/benechehab25a.html), [원문](https://arxiv.org/html/2502.10235v1), [저자 코드](https://github.com/abenechehab/AdaPTS)
- **가져올 원리:** 공통 요인과 개별 성분을 나눠 예측하는 요인모형의 원리입니다. 다수 예측변수를 저차원 요인으로 요약하는 발상 자체는 오래된 선행입니다. [Stock–Watson 원문](https://www.princeton.edu/~mwatson/papers/Stock_Watson_JASA_2002.pdf)
- **작은 변경:** 압축 경로와 별도로, 입력의 재구성 잔차만 받는 작은 시간 예측기를 공동 학습합니다.
- **단순 대안:** 압축 차원 증가, 압축 없는 LoRA, 원입력을 받는 일반 잔차 보정, PCA+선형 예측.
- **실패할 이유:** 버려진 성분이 잡음일 수 있고, 단순 선형 예측기가 전부 해결할 수 있습니다. 잠재 계열이 사전학습 분포와 달라질 위험도 있습니다.
- **최소 판별:** 동일 압축 경로에서 잔차 경로의 유무와 입력 종류만 바꿔 비교합니다. TSFM을 선형 예측기로 교체한 대조도 포함합니다.

**B — 제외: 불확실성에 따라 개인화를 공유 LoRA 쪽으로 축소**

짧은 계열에서 개인화 추정의 변동을 줄이려는 접근입니다. 계층 Bayesian PEFT인 LiFT와 고정 저랭크 공간 적응이 가까운 선행이고, 단순 대안은 공통 ridge·고정 축소입니다. LiFT의 ICLR 2025 게재와 공식 초록을 확인했습니다. [LiFT](https://proceedings.iclr.cc/paper_files/paper/2025/hash/27e5626cabdbb6cd5c56ce4114ff93e4-Abstract-Conference.html)

그러나 이 프로젝트에서는 블록별 변동을 이용한 축소와 관련 대조를 이미 실행했고 추가 가치를 확보하지 못했습니다. **현재는 다시 판별할 새 근거가 없어 개발 대상에서 제외합니다.**

**C — 보류: 이벤트 설명의 의미를 공유하는 공변량 어댑터**

범주별 충분한 반복이 없을 때 설명 텍스트를 통해 반응을 공유하려는 접근입니다. 작은 변경 후보는 이벤트의 실제 적용 범위 마스크와 공유 반응 형태를 분리하는 것입니다. 단순 대안은 달력·지역·이벤트 범주만 쓰는 어댑터입니다.

가까운 UniCA는 이미 공변량을 동결 TSFM에 연결합니다. ICLR 2026 공식 논문집과 초록을 확인했지만, 이번 조사에서 전체 구현을 검증하지는 않았습니다. 텍스트를 사용한다는 사실만으로 차별점이 되지 않습니다. [UniCA](https://proceedings.iclr.cc/paper_files/paper/2026/hash/0b5eb45a22ff33956c043dd271f244ea-Abstract-Conference.html)

최소 판별은 같은 정보·백본에서 UniCA류 대조와 제안 변경을 직접 비교하는 것입니다. 다만 현재는 방법 미실행에 더해 차별화와 평가 계약이 덜 구체적입니다. **이번 24시간 안의 자동 예비 개발에는 넣지 않습니다.**

따라서 **실제 개발은 주력 1개, 예비 0개**를 제안합니다. 정상 음성이 나온 후보를 되살리거나, 수를 맞추려고 예비 방법을 만들지 않겠습니다. A가 소진되면 이번 회차는 미확보로 끝냅니다.

**4. 최소 방법과 최초 실제 비교**

[제안] 백본은 기존 로컬 가중치가 있는 `amazon/chronos-bolt-small`로 고정합니다. 현재 receipt의 revision은 `772f3d25…`입니다. 설치 코드와 설정에서 native 예측 길이 64, 직접 모델 호출의 미분 경로를 확인했습니다. 따라서 첫 과제는 **과거 512시간 → 미래 48시간**으로 하여 다단계 rollout을 피합니다. [가중치 기록](E:/CODING/proj/hierarchical-tsfm-peft/results/hier_peft_screen_v1/MODEL_SOURCE_MANIFEST.json)

방법의 초기 형태는 다음입니다.

\[
Z=E_\theta(X),\qquad
R=X-D_\theta(E_\theta(X)),\qquad
\hat Y=D_\theta(F_0(Z))+G_\phi(R).
\]

- \(F_0\): 가중치를 동결한 사전학습 TSFM. 잠재 계열의 시간 예측을 담당합니다.
- \(E,D\): 작은 선형 채널 압축·복원 어댑터.
- \(G\): 채널 간 공유하는 작은 저랭크 시간 예측기.
- 새 변경은 **재구성 잔차 \(R\)의 별도 예측 경로**입니다. 압축과 일반 residual 자체를 신규성으로 주장하지 않습니다.
- PCA 초기화는 TRAIN만으로 계산합니다. 잔차 출력은 0에서 시작하되 전체 경로가 영구적으로 gradient를 잃는 초기화는 피합니다.
- 첫 구현에서는 내부 LoRA를 제안 방법에 추가하지 않습니다. 효과가 나왔을 때 무엇이 기여했는지 구별하기 위해서입니다.

첫 개발 자료는 기존 Electricity의 **파일 순서상 첫 32개 대상 채널**로 고정합니다. 성능을 보고 채널을 고르지 않습니다. 처음에는 잠재 채널 8개를 사용합니다.

최초 비교는 다음과 같습니다.

```text
F0             압축 없는 미적응 Bolt
LoRA           압축 없는 표준 LoRA
COMPRESS       학습형 채널 압축·복원만 사용
RESIDUAL       COMPRESS + 재구성 잔차 예측: 제안 방법
RAW-BYPASS     같은 크기 보정기에 잔차 대신 원입력 제공
FACTOR-LINEAR  TSFM을 선형 시간 예측기로 바꾼 대조
SEASONAL       계절 반복 참조
```

`COMPRESS`가 핵심 절제 대조이자 가까운 입력·출력 PEFT 기준선 역할을 겸합니다. AdaPTS의 전체 확률모형 재현이라고 부르지는 않습니다. `RAW-BYPASS`는 단순 용량 증가 설명을, `FACTOR-LINEAR`는 사전학습 모델 없이도 되는 방법이라는 설명을 검사합니다.

[제안] 주장은 우선 **점예측 정확도**로 한정합니다. 잠재 예측을 선형 혼합한 값을 원공간의 정확한 분위수라고 해석하지 않습니다.

**5. 공통 학습·평가와 자율 개발 권한**

Electricity의 앞 70%를 TRAIN, 다음 10%를 검증, 마지막 20%를 **이미 노출된 개발 평가**로 표시합니다. 검증과 개발 평가는 각각 연속된 두 기간으로 나눠 기간 의존성을 함께 봅니다. 마지막 20%를 새 test라고 부르지 않습니다.

- 정규화·PCA·결측 처리 통계는 TRAIN만 사용합니다.
- 학습 원점은 TRAIN 전체의 합법적인 창에서 추출하고 시작 위상을 편중시키지 않습니다.
- 비교군은 같은 원자료·과거 정보·예측 원점·목표 구간을 사용합니다.
- 주 지표는 **TRAIN 표준편차로 정규화한 채널별 MSE의 동일 가중 평균**입니다. MAE, 기간별·채널별 손익은 보조 보고입니다.
- 차이는 같은 원점에서 대응 비교합니다. 시간 블록을 재표집할 때 모든 채널을 함께 움직여 공통 충격을 보존합니다. 겹치는 창이나 학습 seed를 독립 데이터셋 수로 세지 않습니다.

학습은 기존 검증 코드와 AdaPTS의 어댑터 학습 설정을 출발점으로 삼되 그대로 복사하지 않습니다. 최초에는 방법별 학습률 두 개와 seed 두 개를 제공합니다. 예를 들어 LoRA는 `1e-5/1e-4`, 입·출력 어댑터는 `1e-4/1e-3`에서 시작합니다. **이는 검증할 초기 설정이지 최적값이라는 주장이 아닙니다.**

점예측 어댑터는 원공간 MSE로 학습합니다. 표준 LoRA에는 native quantile loss를 우선 제공하고, 목적함수 차이가 비교를 좌우하면 MSE 학습도 개발 예산에서 대조합니다. 모든 방법에 정확히 같은 학습률을 강제하지 않습니다.

학습량은 처음부터 64/100 step으로 끝내지 않습니다. 초기 운영 설정은 최대 40 epoch, 검증 정체 6회 시 조기 종료입니다. 상한에서도 개선 중이면 학습 부족으로 표시하고, 예산 안에서 해당 방법과 관련 대조를 연장합니다. epoch 수만으로 수렴을 선언하지 않습니다.

승인 후 구현 검사는 다음에 집중합니다.

- 압축기까지 이어지는 gradient와 실제 파라미터 갱신
- backbone 동결, 잔차 제거 시 COMPRESS로의 환원
- 직접 모델 호출과 공식 추론 출력의 정합성
- 손실의 축·정규화·마스크, 원점 추출과 미래 정답 차단
- checkpoint 저장·복원 후 동일 예측 재생

개발 루프는 **구현 → 비교 → 관찰 기록 → 원인 가설 → 한정된 수정 → 관련 대조 재비교**입니다. 예를 들면 다음과 같습니다.

- 잔차 경로가 움직이지 않음 → gradient·초기화 검사. 이를 곧바로 방법 실패로 세지 않음.
- TRAIN만 개선됨 → 정규화·용량·학습량 조정. 일반화 실패를 자동으로 버그라고 부르지 않음.
- RAW-BYPASS와 같음 → 재구성 잔차 분리의 추가 가치가 약함.
- FACTOR-LINEAR와 같음 → TSFM 중심 방법을 계속할 근거가 약함.
- 큰 압축 차원의 COMPRESS로 충분함 → 잔차 모듈의 필요성과 비용을 다시 판단.

같은 질문 안에서 압축 차원, 잔차기의 선형/작은 비선형 형태, 초기화, 학습률, 정규화, 학습량을 바꿀 수 있습니다. **최초 비교 후 근거 있는 구조·목적 수정은 최대 두 차례**로 제한합니다. 이것은 음성 결과 두 번이면 무조건 탈락한다는 규칙이 아니라 무제한 구조 탐색을 막는 운영 상한입니다.

버그는 원본 실패와 diff를 보존하고 고칠 수 있습니다. 데이터·평가에 영향을 준 오류는 관련 결과를 무효로 표시하고 대조도 다시 계산합니다. 두 수정 이후에도 단순 대안으로 충분하거나 다음 실험이 같은 질문의 반복이면 중단합니다.

**7. 자원·실행량·대기 상한**

[확인] 현재 머신은 RTX 4070 12,282MiB, RAM 약 32GiB이며, 조회 당시 E 드라이브 여유는 약 457GiB였습니다. 이는 실행 때의 가용 자원 보장이 아닙니다.

```text
구현 검사·GPU smoke                 1시간
최초 실제 비교                      7시간
원인 진단·수정·재비교                8시간
```
