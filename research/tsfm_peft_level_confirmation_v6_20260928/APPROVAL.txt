방금 네가 작성한 v6 「수준 보존 잔차 PEFT의 기여 정리·선택 후 확인·논문 초안」 실행계획 전체를 승인한다. 이 메시지는 파일 읽기·계획 요약 요청이 아니라 실제 실행 지시다. CanelE452/hierarchical-tsfm-peft에서 승인 계획과 이 승인문을 보존하고, 승인한 자료·방법·선택·예산 안에서 구현·적합·평가·비용·원고 작성·검산·일반 commit·origin/main push까지 지금부터 이어가라.

주력 연구 방향을 다시 찾지 말고 v5 LEVEL의 선행 대비 기여와 적용 범위를 검증해라. 기준9ddc036과 실제 최신 변경을 확인하고 기존 v1~v5·실패·봉인·위반·무관 파일을 보존한다. 같은 범위의 작은 단계마다 재승인을 요구하거나 '파일을 읽었다'는 답으로 끝내지 않는다. 첫 상태 보고부터 실제 작업 폴더·산출물·현재 단계·예산·프로세스 근거를 보여라.

선행 원문/저자 코드에서 잠재 어댑터·NLinear·잔차/요인 예측과의 겹침을 확인한다. 부품의 기존성을 숨기지 말고 제한된 잠재 채널 조건에서 남는 설계/실증 기여를 정리한다. 검색 실패는 최초성 증명이 아니다. 미열람 자료는 표시한다. 직접 중복으로 연구 목적을 바꿔야 할 때만 근거와 변경안을 보고하며, 불확실하다는 이유로 모든 비교를 무한 보류하지 않는다.

새 자료는 PLAN에서 정한 한 집단·채널·기간 또는 결과 비의존 선정규칙만 사용한다. Hog/Bull/Electricity는 기존 개발 자료다. 새 집단의 직접 성능 사용 이력과 백본 사전학습 중복 미확정을 구분하고, 적격 자료가 없으면 기존 자료를 새 확인으로 재포장하지 않는다. 이 경우 가능한 선행 정리와 초안은 끝내고 확인 미완료를 보고한다. 승인 밖의 다른 site/domain·새 다운로드로 임의 전환하지 않는다.

고정한 LEVEL_RES·OLD_RES·대응 LEVEL_RAW·LEVEL_ONLY·COMPRESS·F0·LoRA·작은 선형 대안의 역할을 유지한다. 기본은 FIXED PCA E/D의 v5 LEVEL이며, TEST 이후 모드나 사용 여부를 고르지 않는다. 새 TRAIN 통계·PCA·무학습 초기값에서 적응하고 Hog의 학습된 G를 복사하지 않는다. LEVEL과 RAW의 공통 잔차 수준복원항·대응 초기화·표본 순서를 지키고, OLD_RES와 초기 함수가 다른 점을 명시한다. NLinear에는 필요 없는 TSFM을 로드하지 않는다.

실제 갱신·동결·유한 손실·축/mask·저장/재시작 복원 검사를 마친 뒤 예정된 직접 비교를 진행한다. 정상적이지만 낮은 VAL 성능을 이유로 비교군을 빼지 않는다. 학습상한 보완은 PLAN의 동일 자격 규칙과 예산에서 TEST 개봉 전에만 수행한다. TRAIN은 적합, VAL은 checkpoint/허용된 LR 선택에만 사용하고 모든 선택·지표·비교를 고정한 뒤 예정된 TEST를 함께 평가한다.

TEST 결과를 보고 재학습·다른 집단·유리한 기간/채널 삭제·지표 교체를 하지 않는다. 명백한 채점/복원 오류는 원본과 영향을 보존하고 해당 비교 전체를 같은 규칙으로 정정한다. 선택까지 바뀌면 확인 범위 변경을 보고한다. 기존 결과 재사용과 이번 새 확인을 구분한다.

주 MSE와 함께 MAE·기간·채널·seed별 손익과 조건부 불확실성을 남긴다. 기간 오차합/관측수 합산과 seed 손실 평균을 예측 ensemble로 바꾸지 않는다. 작은 p값·넓은 구간·비슷한 점수로 동등성/비열등성을 선언하지 않는다. 고정한 주 비교는 LEVEL 대 OLD_RES이며 RAW·LEVEL_ONLY·실용 대안의 질문을 별도로 답한다.

비용은 같은 회차·장치·정밀도·전체 출력에서 batch4 처리량과 peak allocated, batch1지연·reserved·배포bytes·학습비용을 분리해 측정한다. 병합LoRA의 출력 정합성을 확인하고, 예열·동기화·순서/블록·앞뒤 기준과 불리한 변동도 보존한다. 과거 timing과 새 timing을 직접 나누지 않는다. 비용 변동의 근본 원인이 남아도 유효한 정확도 비교와 원고는 완성하고 주장 범위를 제한한다.

실자료 적합·실패·재시도·재개·합성 optimizer 검사·GPU 작업을 PLAN의 공통 원장에 시작 전에 예약하고 총상한을 자동 증액하지 않는다. 잔여예산은 수리/허용 보완용이지 새 아이디어 탐색용이 아니다. 다른 작업 종료·전역환경 변경·유료서비스·권한 우회는 하지 않는다. 같은 범위의 오류는 원본·근거·수리 이력을 남겨 고치고 계속한다.

실험 동안 선행/주장 근거표와 영문 논문 초안을 병행한다. 문제→선행과 차이→방법→실험→결과→한계를 연결하고 실험 전 결과는 PENDING으로 둔다. 최종 수치는 실제 결과로만 채우고 미확보 항목은 숨기지 않는다. 기존 원리의 결합을 새 원리라고 부르지 않는다. 양성 결과가 남으면 그 범위의 기여를 인정하고, 음성이면 제한/반례/주장 축소를 보고한다. 계속 주제 미확보라는 말만 반복하거나 학회 채택을 보장하지 마라.

STATUS·PLAN·주장/선행 문서·PAPER_DRAFT·TOPIC_DECISION과 재현 가능한 실행/선택/결과/비용/검산을 연결한다. 논리·근거 공백을 먼저 고친 뒤 표·그림을 정리한다. 새 확인 완료, 원고 초안 완료, 논문 제출 준비 완료는 구분한다. 직접 논문을 제출하거나 공유 권한을 바꾸지는 않는다.

승인된 비교와 원고를 마치거나 필수 차단/상한에 도달하면 수행·미수행·판단·다음 결정 하나를 보고한다. 관련 파일만 검증·일반 commit·origin/main push 후 원격 SHA를 확인한다. 시작도 안 한 작업을 진행 중이라거나 로컬 완료를 원격 게시 완료라고 하지 않는다. 재개 시 PLAN/STATUS·원장·실제 프로세스와 원격 상태를 읽어 중복 실행을 피한다.
