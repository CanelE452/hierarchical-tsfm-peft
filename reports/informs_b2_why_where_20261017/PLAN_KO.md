# B2의 개선 원인과 적용 범위: 신규 유한 검증

이 작업의 목적은 INFORMS 청중에게 관찰된 오차 차이가 학습량·용량·명시적 시간 혼합 중 어떤 설명을 지지하는지, 어떤 자료와 시간 범위에 한정되는지 설명하는 것이다. 사용자가 `INFORMS_B2_Mechanism_Generalization_CLI_20261017.md` 전체 실행을 요청했다. 새 요청의 실행 계획이며 종료된 과거 캠페인의 시계·예산·영수증을 수정하지 않는다.

## 시작 상태와 보호 범위

[확인] 시작 HEAD와 원격 main은 `a5eac7f889c72cd53e2f9bb418b5f2d2c5ae3065`다. 기존 managed worktree를 재사용한다. 기본 checkout의 history 수정 두 개는 보존한다. 현재 Python 학습 작업은 없고 RTX4070 GPU utilization은 0%였다. 원 모델 캠페인과 MASTER의 미완료 상태는 유지한다.

장치·동시성·메모리는 기존 CPU 실행 계약을 유지한다: **GPU 신규 사용 0, 모델 worker 최대2, worker별 CPU2·RSS3GiB, 합 RSS6GiB**. NumPy/BLAS도 CPU2로 제한한다. 비용 측정과 학습을 겹치지 않는다. 새 저장은 원 30GiB 상한 안에서 사용량을 확인하고, 원 예측·CP·데이터를 덮지 않는다. 시작 시 C/E 여유 공간은 약59/342GiB였지만 이를 새 예산으로 간주하지 않는다. CPU 시간은 등록된 유한 조건에 한하며 실측 update 시간으로 추정치를 갱신한다.

Jena는 최대6조건(3구조×seed92601/92602), PeMS는 원 C32/K8 B0/B2 두 조건, probe 최대6개다. 정확히 일치하는 기존 Jena 모델 조건과 checkpoint를 우선 재사용한다. 기존 큰 큐·core56·다른 K·B4·G/H·새 그래프는 실행하지 않는다. 보호 T 수치 파싱·평가·선택은 금지한다. PPT/PDF는 만들지 않는다.

## 고정된 주 방법과 질문

허용 과거 → B2 시간·채널 P → E(C→K) → 동결 Chronos-Bolt → 잠재 과거/미래를 받는 lag D → 원 C 현재값 anchor. P/E/D는 이미 미래 예측 MSE로 학습한다. B0도 Bolt와 D를 통해 전체 과거를 사용한다.

1. 오차 분해는 전체 이득의 집중과 시간·거리별 반전을 확인한다. 개선이 분산돼도 공통 요인 식별이나 독립 일반화를 증명하지 않는다.
2. 공통 update 비교는 선택 학습량이라는 경쟁 설명을 줄인다. 별도의 동일 선택 규칙 비교는 실제 사용 성능을 답한다. 두 표를 합치지 않는다.
3. 근접 용량의 대조는 모수 수라는 경쟁 설명을 줄인다. 연산량·함수공간·최적화 난이도까지 같지는 않다.
4. 동일 probe는 해당 선형 읽기 모델에서 미래 예측 정보의 접근성을 검사한다. 원 D나 Bolt 적합성과 표현의 유용성을 혼동하지 않는다.
5. PeMS C32 비교는 다른 자료에서 별도 학습한 적용성을 검사한다. zero-shot이나 독립 시간 일반화와 구분한다.

## A: 저장 예측의 분해

Jena C21/K6/L512/H48, 두 seed의 기존 B0/B2 V43 예측·정답·mask·origin·scaler 지문을 대사한다. H는1–16/17–32/33–48, origin은 정렬된43개를 연속3블록으로 나눈다. 이 규칙은 오차를 보기 전에 기록한다. 전체·부분 모두 FP64 채널별 SSE/SAE/count 후 채널 평균을 사용한다. 부분집합 지표와 원 전체 분모를 사용한 가산 기여를 별도 열로 둔다. 기여의 합이 전체 차이를 복원하는지 검사한다. 일부 채널 집중과 두 seed의 방향도 보존하며 독립 표본 t-test는 하지 않는다.

## B: 같은 학습량·근접 용량

등록 모델은 B0/B2/B2_CAP_POINTWISE 두 seed뿐이다. 기존 검색 endpoint 0/.25/1/3epoch의 E/D·표본 순서·optimizer·정규화가 정확히 대응하면 기존 checkpoint를 재사용한다. 메타데이터만 같다는 이유로 통과시키지 않고 payload·초기 출력·sampler 상태를 확인한다.

신규 대조는 B2 시간 MLP512→32→512 대신 시점 공유21→774→21을 사용한다. 기존 뒤쪽 채널 MLP21→32→21, 두 잔차, 전체(L,C) affine 없는 LayerNorm, GELU와 출력층0 초기화, E/D와 anchor를 유지한다. 예상 활성 모수는 B2 35,717 / 대조35,708이고 실제 모델에서 다시 센다. 전체 창 정규화 통계가 공유되므로 완전히 시점 독립이라고 부르지 않는다. 더미 모수는 없다.

동일 seed에서 가능한 E/D와 공통 채널 MLP 초기 상태를 복사해 난수 소비 차이를 분리하고, 표본 순서는 독립 RNG로 고정한다. 시간 경로의 차원 자체는 달라 동일 가중치 복사 대상이 아니다. 검색 A_fit endpoint의 update·exposure·학습/A_stop 손실을 먼저 비교하고 V는 선택에 쓰지 않는다. A_stop의 동일 규칙 선택 후 필요한 fresh A60 refit은 별도 단계다. 공통 최대3epoch가 1차 범위다. 마지막까지 하강해 추가 확인이 필요한 묶음만 전체 공통 최대6까지 한 번 연장할 수 있으며, 실행 여부와 이유를 결과 전에 기록한다. 좋은 결과를 위해 재시도하지 않는다.

## C: 고정 P/E의 동일 probe

세 선택 표현의 전체512×6=3,072 특징으로 원채널48×21=1,008 미래 변화 Y−X_t를 읽는다. 현재값은 공통 anchor로 더하고 원 D는 사용하지 않는다. A60에서만 특징 중심·척도를 적합한다. 목적함수는 출력별 관측 표본의 `(1/N_j)||A_j W_j−B_j||² + 1·||W_j||²`, 절편은 무규제이며 누락 정답은 제외한다. V로 λ나 특징 수를 변경하지 않는다.

FP64 기본 Gram은 약72MiB, 읽기 계수는 약24MiB이며 solver 임시 메모리와 mask 그룹 수를 합산해 RSS3GiB 아래인지 먼저 산정한다. 충분통계를 스트리밍하고 동일 mask 패턴만 Gram을 공유한다. 허용 예산을 넘으면 특징 축소로 비교를 바꾸지 않고 해당 probe를 미실행으로 남긴다. 초기 표현이 세 구조에서 같으면 중복 초기 probe는 만들지 않는다. 학습 후3×2=6 probe 상한을 우선한다.

## D: 자료·시간의 경계

PeMS C32/L512/H12/K8/seed92601의 원 두 partial CP를 복사해 모델·optimizer·sampler·RNG·실제 진행량 복원을 검증한다. 원 source/admission/deadline은 수정하지 않고 새 caller에서 원 학습 수학을 재사용한다. 복원이 맞으면 원 공통 endpoint까지 이어가고 동일 A_stop 선택·fresh refit·전체 V·독립 FP64를 수행한다. 불가능하면 두 조건 모두 동일 recipe의 fresh 실행으로 구분하며 이미 학습한 것처럼 기록하지 않는다. 완료된 같은 C32 Raw/G는 재사용한다.

이미 본 V의 시간 블록과 새 미래 평가를 분리한다. 허용된 미사용 후반 구간이 확인되지 않으면 `INDEPENDENT_GENERALIZATION_PENDING`으로 남기고 필요한 새 자료/접근만 질문한다. 기존 T를 새 테스트로 이름 바꾸지 않는다. 상류 전처리 계보가 미확정이면 그대로 표시하고 비교의 범위를 동일한 legacy 입력 계약 안으로 한정한다.

## 판단·출력

새 결과는 원수치·run/seed·fit/selection/eval·장치·params·updates/exposure·checkpoint/source SHA와 결속한다. 같은-update 비교와 선택 모델 비교, 반복 V와 독립 시간 평가를 별도 표로 둔다. `[확인]` 실제 조건·수치, `[추정]` 지지되는 설명과 경쟁 설명, `[미완료]` 없는 증거를 나눠 보고한다. 미수렴·예산 중단은 PARTIAL이며 방법 실패로 바꾸지 않는다.

검산은 원수치 FP64 대사, 같은 초기 E/D·표본 순서, 실제 활성 모수와 F 동결/앞단 gradient, 복사 CP 재개 동등성, 코드·평가 경로 확인을 우선한다. 포장과 서명 종류를 늘리지 않는다. 독립 agent는 오차 집계·새 대조와 복원 경계를 검토한다. 출력은 이 폴더와 private cache만 사용한다.

선행 원리: [TSMixer](https://openreview.net/forum?id=wbpxTuXgm0)의 시간/특징 혼합(원문 사이트는 이번 접근에서 browser challenge), [probe의 읽기 능력과 표현 해석 구분](https://aclanthology.org/D19-1275/), [과거 정보에 한정한 시계열 검증](https://otexts.com/fpp3/tscv.html). 이 원리들이 이번 B2의 효과를 보장하지 않는다. 새 구조는 사용자 지정 미검증 대조이며 주 방법 교체가 아니다.
