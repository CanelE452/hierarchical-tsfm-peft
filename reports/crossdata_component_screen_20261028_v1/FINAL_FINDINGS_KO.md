# 교차 데이터 탐색: 완료 범위와 최종 해석

이번 캠페인은 **전체 완료가 아닌 부분 완료**다. 기본 16개 중 9개(교통 PeMS32의 8개, Beijing의 Full 기준 모델 1개)가 끝났다. 선택 실행 8개는 완료되지 않았다. 실제 비교 가능한 결과는 PeMS32의 같은 두 seed로 구성한 네 모델이다. Beijing은 대조군이 없어 구성요소 효과를 판단할 수 없다.

## 어떤 근거가 추가됐나

PeMS32는 C=32, K=8, 입력 길이 512, 예측 길이 12의 개발 검증 구간 V를 평가했다. 모든 차이는 **제거·고정한 모델의 중앙값을 전체 모델의 중앙값과 비교한 비율**이다. 양수이면 전체 모델의 오차가 낮다.

- **추가 lag:** lag0만 남기면 MSE가 1.50% 높았다. 두 seed 모두 전체 모델의 MSE가 낮았다. 이 조건에서 추가 lag가 MSE에 도움이 될 가능성을 보여 주는 제한적인 탐색 근거다. MAE 차이는 −0.011%로 불명확하므로, 모든 오차 지표가 좋아졌다고 말할 수 없다. 직접 마지막 값 더하기는 양쪽 모두 유지했다.
- **채널 분기:** 채널 MLP를 제거한 시간 분기 모델의 MSE가 1.17%, MAE가 0.60% 낮았다. 두 seed 모두 같은 방향이었다. 이번 결과는 채널 분기의 추가 이득을 뒷받침하지 않는다. 공동 LayerNorm은 유지하므로 채널 상호작용 전체를 없앤 실험도 아니다.
- **E 학습:** PCA E를 고정했을 때 MSE 차이는 +0.13%였고, 두 seed의 방향이 서로 달랐다. 등록 규칙상 불명확하다. E를 반드시 학습해야 한다거나 두 방식이 동등하다는 근거가 아니다.

**PeMS32의 네 구성 모두 두 seed에서 6 epoch 상한을 선택했다(8/8). 따라서 모든 비교는 n=2 PILOT이면서 학습 상한에 걸린 잠정 결과다.** 같은 학습 상한에서의 관측 차이일 뿐, 충분히 학습한 후에도 차이가 유지된다는 보장은 없다. 등록된 추가 연장은 수행하지 않았다.

전체 모델의 V MSE 중앙값은 0.09090872, 시간 분기만은 0.08984324, lag0만은 0.09227396, E 고정은 0.09103120이다. 각 seed와 MAE는 [RUNS.csv](RUNS.csv), 중앙값·사분위 범위는 [SUMMARY.csv](SUMMARY.csv), 대응 차이는 [PAIRED_DIFFERENCES.csv](PAIRED_DIFFERENCES.csv), 등록 규칙 판정은 [CONTRASTS.csv](CONTRASTS.csv)에 모두 남겼다. 불명확하거나 불리한 결과도 제외하지 않았다.

## 이 결과로 아직 말할 수 없는 것

- 채널 분기·E 학습·추가 lag가 모두 필수라는 주장은 성립하지 않는다. 이번에 더해진 긍정적 근거는 PeMS32에서 추가 lag의 MSE 방향에 한정된다.
- K는 과거 설정인 8/6을 고정했다. K 또는 Kτ 규칙의 최적성이나 정보 보존 메커니즘을 검증한 실험이 아니다.
- 데이터와 질문은 과거 결과를 알고 선택했다. 개발 V를 사용한 탐색이고 보호 T를 열지 않았으므로, 독립 테스트 일반화 결과로 부를 수 없다.
- PeMS32는 PEMS08의 고정 32개 센서 부분집합이다. 서로 독립인 두 교통 데이터셋으로 세지 않는다.
- 기존 Jena·ETTh1 등과 데이터·예측 길이·학습 상한이 다르다. 이전 결과를 새 두 seed와 합쳐 표본수를 늘리거나, 유리한 결과만 모아 보편적 우월성으로 표현하지 않는다.

## 왜 나머지를 끝내지 못했나

15:50 KST에 종료됐다. 시간 마감 17:30 때문이 아니라, 새 GPU 프로세스 PID 26048이 등록된 실행 환경에 없어서 이후 11개 작업이 시작 전에 차단된 것이 최종 원인이다. 확인 당시 프로세스 이름은 `rustdesk.exe`였다. 해당 프로그램을 종료하거나 허용 정책을 바꾸지 않았다.

11개 작업은 각 첫 시도와 허용된 기술 재시도 1회, 총 22회에서 같은 환경 검사에 막혔다. 이들은 학습을 시작하지 않았으므로 모델의 성능 실패로 해석하지 않는다. Beijing의 선택 seed 4개는 기본 비교가 미완료라 실행하지 않았다. 시간 예산으로 제외된 실행은 없다. 자세한 근거는 [EXECUTION_DISPOSITION.json](EXECUTION_DISPOSITION.json)과 [JOB_STATUS.csv](JOB_STATUS.csv)에 있다.

이전에 발생한 NUL import 오류와 임시 폴더 오류는 별도 복구 기록에 보존했다. 완료된 학습은 반복하지 않았다. `EXECUTION_COMPLETION.json`의 `stop_reason` 문자열에는 과거 임시 폴더 오류가 남아 있으므로 최종 중단 원인은 `EXECUTION_DISPOSITION.json`을 기준으로 읽어야 한다.

기존 등록의 재시도 한도는 소진됐다. 나머지를 다시 수행하려면 실패 기록을 보존한 채 호스트 신원 문제와 추가 시도 범위를 사전에 정해야 하며, 현재 봉인의 실행 제한을 임의로 완화하지 않는다. 이 묶음은 완료된 범위의 공개·검증 기록이지, 남은 실험을 완료했다는 표시가 아니다.

발표 파일과 대본은 생성하거나 수정하지 않았다.
