# ETTh1 추가 시차 참조: 검증된 중간 결과

이 문서는 발표 파일이나 대본이 아니라, 결과 전달용 수치·해석 자료다. 캠페인 전체는 아직 실행 중이다.

- 구성: 기존 Full(직접 마지막 context 가산 + lag 0/1/2/4/8/16/32) 대 lag0만 유지한 구성. 두 구성 모두 마지막 context 직접 가산을 유지한다.
- 데이터/seed: ETTh1 개발 V, 같은 5개 seed 92601–92605. 기존 10seed 표와 합치지 않는다.
- Full 중앙값 MSE: 0.278652397; Q1–Q3 0.277681951–0.282601651.
- lag0 중앙값 MSE: 0.281025077; Q1–Q3 0.274168607–0.293308426.
- lag0 − Full: +0.85%. 등록 판정은 **UNCLEAR(차이 불명확)**다. Full이 낮은 seed3/5, lag0가 낮은 seed2/5다.
- 학습 파라미터: Full 34,023, lag0 33,855; lag0에서168개가 줄어든다.
- 같은 cap3 탐색 규칙을 사용했다. Full 선택 epoch는 [0.25, 0.25, 0.25, 0.25, 0.25], lag0는 [1.0, 1.0, 0.25, 0.25, 1.0]다. lag0 cap3 선택0/5로 등록된 연장 조건에 해당하지 않아 추가 학습은0회다.

설명할 수 있는 범위:

**ETTh1에서 직접 마지막 값 경로를 유지한 상태에서는, 추가 여섯 시차 참조가 주는 이득이 이번 5seed 실험에서 명확히 확인되지 않았다.** 차이가 없거나 동등하다고 증명한 결과는 아니다.

별도의 마지막 값 가산 제거 실험은 +189.35%의 중앙값 MSE 증가와 Full 우세5/5를 보였다. 두 대조를 함께 보면 직접 수준 보존 경로의 기여와 추가 lag의 기여를 분리해 설명할 수 있다. 기존 A4의 전체 디코더 교체 손해를 lag만의 효과라고 해석하거나, 기존10seed와 신규5seed 변화율을 빼서 기여 비율을 계산하면 안 된다.

제한: 반복 확인한 개발 V의 탐색 결과이며 독립 테스트 결과가 아니다. n=5이고 파라미터 수와 실제 선택 epoch가 다르다. 개별 lag마다의 필요성, 실제 인과 시차, 모든 데이터에서의 효용을 검증한 것이 아니다. 입력 history와 latent 차분은 계속 사용한다.

검증: 신규5+기준5의 예측10개를 archive SHA·shape·origin 경계 확인 후 FP64 math.fsum 방식으로 재계산했다. targets/mask/channel/origin/scaler가 일치했고 최대 지표 차이는 7.22e-16였다. 보호 T 수치는 읽지 않았다. 실행·선택·fresh refit·bundle·worker 영수증도 일치했다.
